# FIND YOURSELF v23｜独立した店舗内装・描画検証版

Godot **4.6.3**で、このフォルダの`project.godot`を開き、初回インポート完了後にF5で起動します。データの結合、追加ZIP、EXEは不要です。`.godot`は再生成するため含めません。

**F9**の先頭にv23の10代表店舗（入口・中央・奥）と3館の共用部を追加しました。既存の検証地点・トイレ選択・独立水景シーンも保持しています。

WASD移動、Shift速歩、Fで扉・EV、Mマップ、F10画面設定、F11催事、F12NPC切替。F4/F6の構造比較、F7ES検討、F8店舗選択、N人物比較、P表情を保持。初期1080p、144FPS上限、VSync ON、物理60Hzです。保存済みの画面設定があればそちらを復元します。

## 今回の変更

- 480店舗のID・ブランド・元業種を監査し維持。商品形状コレクションを業種とブランド別に分け、青果台・靴台などの商品支持規則を補正。
- アパレル、靴・バッグ、化粧品、生活雑貨、家電、書店、食品、レストラン、カフェ、アーケードの10店で役割別レイアウト・専用什器を改修。
- 新しい服、靴、バッグ、化粧品、本、家電・生活用品と専用什器をBlenderで制作。プリクラは撮影室・入口・出口・背景・編集台の配置のみ。撮影機能はありません。
- 商品63342件と什器7157件を管理。最適化ON/OFFは同じv23内容で比較。同一材質・テクスチャの共有、店内表示板のまとめ描画を実施。商品の陳列結合は視点により負荷が増えたため、標準では元のSKU別MultiMeshを維持し、`--v23-stock-packets`の試験機能に限定しています。
- `source/v23`に将来の買い物用のID参照・設備・接近候補・検査キャッシュを用意。購入、AI、機嫌、荷物持ちなどは未実装です。

## 完成と扱わない部分

全480店の美術完成ではありません。470店は既存の暫定配置を保持し、商品コレクション・支持規則を適用した段階です。代表店にも無地の壁、照明・売場密度・専用商品造形の不足が残っています。AAA品質の達成は主張しません。

遠距離商品は既存の簡易シルエットLODを継承しています。切替の見え方、透明物の並べ替え、Windows GPUでの性能、人間による実操作は未確認です。ソフトウェアGPUでの描画時間をWindowsの実FPSとして扱わないでください。

構造マスター、NPCモデル・アニメーション、スキャンゲーム本体は変更していません。構造別案と統合候補の既存状態を継承し、専門的な構造安全性を承認したものではありません。C館水上庭園は独立シーンのままです。

## データと再生成

`retail-plan.json.zst`はFYJZ＋元サイズ＋Zstandard。Godotは標準機能で読みます。Pythonの再生成にはnumpy・Pillow・Shapely・zstandard、モデル制作にはBlender4.3系が必要です。通常起動にこれらは不要です。

制作順序は`authoring/v23_assets.py`→`v23_apparel_assets.py`→`v23_dining_assets.py`→`v23_book_finish.py`→`v23_footwear_finish.py`→`v23_arcade_finish.py`（Blender）→`v23_retail.py`→`v23_mount_labels.py`→`v23_shopping_index.py`です。最終配置は収録済みです。再生成後の圧縮・接近位置検査キャッシュの再生成も必要です。

買い物データの唯一の配置元は`retail-plan`です。`shopping-index`は商品ID・什器IDの参照、`shopping-candidates`は候補、`shopping-physics`は実衝突検査結果です。未確定点をNPCスポーンとして使用しないでください。実行時の互換`instances`は同じfixtures/productsから生成し、独立配置を二重管理しません。

詳細な実画面・全店監査・検査範囲・残課題はReview ZIPの`index.html`をご覧ください。
