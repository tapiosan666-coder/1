# FIND YOURSELF v30 独立検証プロジェクト

Godot 4.6.3で `project.godot` を開いてF5。新しいフォルダへZIP全体を展開してください。EXE、追加Data ZIP、分割ファイル、旧版の上書き展開は不要です。初回は素材インポートが走ります。

F1=A館、F2=B館、F3=C館。WASD移動、マウス視点、Shift速歩、F=扉・EV、M=館内マップ、Esc=設定。初期1920×1080、上限144、VSync ON、物理60Hz。通常起動では旧比較キーを無効にしています。開発者確認が必要なときだけ `--developer` でF8/F9/F10/F11/F12等を有効化します。旧F4/F6/F7構造は通常版へ再出現しません。

今回の施工
- 全館を起動時に組み上げる方式から、事前生成した48m区画を周辺ロード・実アンロードする方式へ変更。建築、売場、照明、物理、NPCで範囲を分けています。動くES・EV・扉の状態は保持します。遠方をvisible=falseにするだけの方式ではありません。
- ナビを37タイルへ分割。静的形状・商品モデル・材質を共有。実際の不透明壁・床の三角形から遮蔽用データを生成し、正規の開口は残します。視覚内容を欠落させた初期キャッシュは破棄し、実レンダラーで再生成・撮影しています。
- B館西ESの旧デッキ・囲い・接続床を協調して置換。上下6本、公共接続幅4.2m、上階乗り継ぎ7.53m×2。旧シャフト撤去跡は床・天井・衝突面を一体修復。安全柵は実際に残る開口に設置。B1は既存EV・階段接続を維持。ESの滑らかな移動処理は変更していません。
- C館中央の箱状風除室を撤去。A/Bの外壁上の二重自動ドアを保持。
- 全15層の共通誘導を横並びに統一し、表裏の距離表示を廃止。48面165案内先を物理経路と照合。C館屋上の1面は支持場所がWC内になるため設置せず、同階の他2面を保持。
- 1F139店（A52/B69/C18）へ業種・ブランド別の床、実壁上のパネル、元ブランド広告、支持確認済みの照明と店頭造作を施工。既存の売場・商品・ブランド・入口を保持。追加展示は既存什器と既存経路を検査し34組を採用、干渉等4組は配置しません。
- A館341.5m、B館503.0m、C館905.1mの連続主動線を記録。C館は6店舗棟18店の正面をつなぐ経路です。近道と広場は維持しています。これらの長さは施工・自動歩行対象長であり、人間による美術承認済み長ではありません。

検証と未確認を区別
275既存経路のカプセル掃引・床支持、B西ES上下6本、乗り継ぎ2本、公共接近6本、安全柵3か所、3館主動線、外部入口3か所、各館の地下/RF/1FへのEV乗車を自動検証。ESの最大1フレーム高さ差は60Hzで約0.023～0.026m、0.12m超の跳躍なし。自動コントローラ検証を、人間の実操作とは報告していません。

Windows GPUの中央値60FPS・1%low45FPS目標は未検証です。Linux llvmpipeで撮影・診断した数値はWindows性能を示しません。144は設定上限です。全139店の店内奥までの美術完成、全館の人手操作、美術承認は未完了・未承認として台帳に区別しています。したがって全完成ゲート承認済みとは名乗りません。

全15層・480店舗ID・7,349什器レコード・69,897商品レコード・43人のNPCデータを保全。既存スキャンゲームのNPC大量処理・AP・セーブ等には統合していません。RF-SUPPORT-16などの構造工学上の未承認は引き続き未承認です。

再生成・性能測定
通常のF5起動ではビルダーを再実行しません。制作者向けに `authoring/native_world_bake_v30.gd` と `authoring/cache_occlusion_v30.gd` を用意。MultiMeshデータの再生成は**実レンダラー必須**です。GodotのDummy/--headlessではMultiMeshの読出しが空になるため再生成を拒否します。素材の新規インポートを先に終えてから実行してください。
`authoring/benchmark_v30.gd` は描画対応環境で、6地点の10秒以上暖機＋各60秒以上を記録する測定ツールです。通常F5では起動しません。使用例：
`Godot.exe --path プロジェクト --script res://authoring/benchmark_v30.gd -- --trial=1`
NPCなしは `--NPC-off`、通常VSync条件は `--VSync-on`。1/2/3の3回を別に実行し、Windows GPU実測として記録できます。旧版比較は同じスクリプトを旧版パスで `--side=v29.4 --cameras=新プロジェクト/source/v30/benchmark-cameras.json` として実行できます。OSコールド起動の条件は別途記録が必要です。

素材と保護
外部素材の新規取得なし。既存のモデル・PBR・Notoフォント等のライセンスは `licenses/` を継承。追加コード・配置・造作は独自制作。元ZIPの固定SHA256は `76add1d790efd9c0dc17eb372cb5537c7daa70cdd7b8859b451bf6e0d1116716`、元版固定コミットは `7e5aef5fdaa18bd232c3c34822fda6d018ecc03b`。切り戻す場合はその元ZIPを新しいフォルダへ展開します。

生成規則の追加修正：以前定義のなかったB館28店舗で、3Dの入口経路をX/Y平面として投影していた誤りをX/Zへ修正。店頭造作・広告面と撮影位置を同じ正式データから再生成しています。

同じ座標投影の誤りが再発しないよう、2D/3D経路を明示的にXZへ揃える補助処理を追加しています。既に床・天井支持、干渉、経路検査で採用した展示・照明の座標は今回維持し、新規候補の生成規則を修正しています。

既存の複合的なブランド入口がある28店舗は、元の正面を保全し、新しい横梁や枠を二重に追加しません。139店すべてを新しい入口モデルへ置換したという意味ではありません。
