# FIND YOURSELF v33｜独立建築・ES・起動検証版

Godot **4.6.3（Forward+）**で、完全に展開したフォルダの `project.godot` を開き、初回インポートの完了後にF5を押してください。追加データのダウンロードやZIPの結合は不要です。Windows EXEは含みません。

## 操作

- WASDで移動、Shiftで速歩、マウスで視点。画面をクリックするとマウスを捕捉します。
- F1＝A館、F2＝B館、F3＝C館。M＝館内マップ、Esc＝設定。F＝対応する扉・EV。
- ESは歩いて乗ります。入力を放しても、実際の床接触を保って運転方向へ運ばれます。乗車中の歩行・逆向き入力は搬送速度と合成します。自動的な視点回転や階の座標ワープは行いません。
- 初期設定は1920×1080、FPS上限144、VSync ON、物理60Hzです。144は上限設定であり、達成FPSではありません。

## v33の変更

- 西ES6本の位置・対応階・方向を維持。踏段・手すりと搬送速度を共通の0.50m/s定義へ統一し、描画側の位相を物理時間に合わせました。歩き始め・停止・逆入力の加減速、館移動やマップ表示後の入力状態も調整しています。
- 可視形状と同じ位置の内側スカートを追加。各乗降口には進行方向表示を設置し、2F・3Fには次の上り・下りを示す横長の天井吊り案内を設けました。通路内に案内板の床支柱を残していません。距離表示はありません。
- 既存の約7.53mの乗継は維持。機械を無断移設したり、Nav線だけを短くして距離を改善したことにはしていません。
- A館の初期表示に必要な**同じ119区画**の描画・衝突を事前生成データから読み込みます。署名が一致する場合にだけ採用し、不一致なら元の区画データを使います。これは配布用の建築データであり、`.godot`インポートキャッシュではありません。
- 起動時に不要だった旧商品計画約46MBの展開・解析を必要時に変更。全480店の元データは削除していません。
- 全42本のES定義を保持し、近くの機械モデルだけを生成。踏段メッシュを共有します。B館西の再構成床・Navはその地域へ入る前に準備し、初回Nav同期も行います。
- 初期読込は処理済み区画数をウィンドウタイトルに表示し、必要な床・壁・店舗がそろうまで操作を止めます。途中の2D読込画面がソフトウェアGPUでシェーダー初期化を増やしたため、初期データがそろってから実画面を描画します。8msはバッチの目安であり、単一PackedSceneの読込を強制分割できる上限保証ではありません。実測の超過は確認資料に記載します。

## 検証範囲と残件

同一環境での起動測定、ESの実コントローラ操作、自動歩行・衝突検査の結果はReview ZIPのPDF・Excelへまとめています。計測ログは `--startup-profile` を付けた場合だけ詳細を収録します。

自動検査は人間による実操作・完成承認ではありません。独立版にはプレイヤー進行のゲームセーブが実装されていないため、そのセーブ→ロード直後のES検証は未実施です。設定保存とは区別しています。NPC試験では必要に応じて既存43人中1人を試験時だけ乗降口脇へ配置し、43人の自律乗車や群集を検証したことにはしていません。

Windows GPU、Windows EXE、実際のWindowsエディタF5の性能は未測定です。Linux llvmpipeはソフトウェア描画です。初回インポート時間と、プロジェクト起動・最初の実画面が出るまでの時間を混同しません。30％短縮目標を達成したかどうかは、反復測定の結果をご覧ください。

今回はP0のESと起動に集中しました。139店の美術承認、B1-032入口、既存案内板3か所の遮蔽、C館景観は未完成のままです。RF-SUPPORT-16などは未承認状態を維持しています。現実建築の耐力認証は行っていません。

15層・480店舗ID・43人・店舗配置・元の広告・NPCモデルを維持しています。既存スキャンゲームのNPC大量管理・スキャン・AP・セーブ・購入処理・会話AIへは統合していません。旧比較構造を通常版へ再統合していません。

既存素材・モデルのライセンス資料はそのまま収録しています。今回、新しい外部ブランドや作品の資産は使用していません。
