# FIND YOURSELF v21｜店舗内装・館内誘導 独立検証版

Godot4.6.3でこのフォルダのproject.godotを開き、初回インポート後にF5。Windows EXEや追加Data ZIPは不要。1920×1080・144FPS設定上限・VSync初期ON。

全480店舗を監査し、代表12店舗の什器・商品・売場を再構成しました。残る468店舗は既存v20の内装を保持。代表店舗も美術品質は未完成で、FF16級に達したとは評価していません。既存の15層・480ID・ブランド・43人・v20女性モデル・動作は保持しています。既存スキャンゲーム本体とは独立しています。

F9の確認地点から代表店舗・サインへ移動。WASD移動、F扉/EV、Mマップ、F10設定、F11愛知県フェア、F12人物切替。F4=C館構造別案、F6=B館ES別案は未承認で、通常版へ統合していません。旧人物比較N・表情Pなどはv20を維持。

サインはMマップと同じ建築データ・実在する設備位置から経路を作り、起動時に実衝突と床支持を再検査します。建築ソースのSHAが一致しない場合は古い矢印を表示しません。未確認経路の行は非表示です。新しい出入口・授乳室の案内は、実装確認が不足しているため追加していません。

各起動時のscene構築と案内経路検査には時間がかかります。LinuxソフトウェアVulkanによる動作検査であり、Windows GPUや144FPS達成は未確認。自動検査は人間の実操作検証ではありません。

データ容量削減のため一部の新JSONは可逆Zstandard形式（.json.zst、FYJZヘッダ）です。実行時のread_jsonで自動読込します。Godotの初回インポートは完了まで待ってください。v20の元の実行アセットをすべて保持し、人物の持ち物・旧環境モデル・建築パックも省略していません。ファイルとSHA一覧はrelease-manifest-v21.json。

Review ZIPのindex.htmlに同一視点比較、480店舗台帳、12店舗の配置図、物理検査、残課題、素材ライセンスを収録。
