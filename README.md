# FIND YOURSELF v29.2｜人物イラスト広告・店舗継続改修

Godot 4.6.3でproject.godotを開き、初回インポート完了後F5。Windows EXE・分割ZIP・追加Data ZIPは不要です。

## 今回の確認方法

F9先頭に人物広告の確認地点を追加。コスメ、ファッション、カフェ、キッズ向け家族の4種類の人物イラストを、8店舗の8面に掲出しています。すべての広告を同じ人物絵にせず、既存の商品広告も残しています。F9で選ぶと参照画像の位置・画角を反映します。

既定のcombined配置で新しい地点が表示されないF9の絞り込み、タイトル未設定データの扱い、画角の反映を修正しました。新しい13確認地点は検査済みのcombined配置向けです。F4/F6による別配置では、その配置向けの既存確認地点を利用してください。

C1F-CE-3（キッズ店）の成人体型の中央展示マネキンを、子どもサイズの衣類・靴の展示に置換。B1-040（ベーカリー）入口には人物広告と、実際のレジ経路に対応する案内を追加しました。L字の建物形状は維持しています。

## 既存機能

15層・480店舗ID・43人の試験用NPC、人物モデル、店舗区画・入口・ブランドを保持。WASD移動、Shift速歩、F扉/EV、Mマップ、F4/F6構造比較、F9確認地点、F11催事、F12NPC、N人物比較、P表情。初期1920×1080、FPS上限144、VSync ON。144FPS達成を意味しません。

原版v29.1と既存スキャンゲーム本体は変更していません。RF-SUPPORT-16・水上庭園など既存の未承認事項を引き継ぎます。

## 制作と未完成

人物広告画像は本制作で新規生成した架空のイラストです。元のPNGを収録し、領域選択と店名・コピーの合成はGodotで行います。外部画像のダウンロードは起動時に必要ありません。素材の出典はlicenses/v292とsource/v292/asset-provenance.json。

これは全1Fや全480店舗の完成版ではありません。A館の大型店全体の密度、広域の無地壁、他店舗の内装、人物モデルの品質は継続課題です。人間の実操作・Windows GPU性能測定は未実施。

主要233区間・店舗内42経路の自動衝突検査と、変更したキッズ店の実プレイヤー自動往復を確認。F9など操作15項目の自動検査を通過。自動検査は美術完成や人間操作の合格を意味しません。詳細と実Godot比較26枚はReviewのindex.htmlを参照してください。

`--v291-baseline`で同じプロジェクトから元のv29.1の景観を比較可能。通常起動にPythonやBlenderは不要です。
