## 改修

全480店舗を監査し、ID・ブランド・元業種・建築区画を保持。10代表店の役割別内装、83種のSKUモデル（表紙差分等を含み、83種の独立形状を意味しません）、業種/ブランドの商品コレクション、商品支持規則を改修しました。53個の新規モデルを収録していますが、追加数を美術完成の証明にしません。玩具店6店の336書籍を音楽ジャンルから児童図鑑へ補正。化粧品店のレジ用PC1件は販売商品候補から区別しました。

7157什器・63342商品/展示物レコードを保持。v22との差525件は10代表店のレイアウト再編によるもので、最適化のための大量削除ではありません。470店舗の個別美術仕上げは未実施です。

描画は元のSKU別MultiMeshを標準とし、同一材質/画像・店内表示板を共有。陳列パケット結合はCPUメモリ増と視点別のdraw増が見つかったため、試験オプションへ戻しました。実測値はperformance-notes.md。全館高速化・Windows60/144FPS達成とは主張しません。

買い物用の配置/参照データを用意しましたが、購入、会話AI、機嫌、荷物持ち、撮影機能は未実装です。商品位置は単一原本を参照し二重入力を避けています。155設備の安全な接近位置は未確定です。

## 検証の範囲

全480店の入口と指定売場主通路、7157什器の支持、通常商品59510件の自身の什器支持、平積み46件を実衝突/接触規則で検査。吊り衣類3786件は底面支持と別扱いです。全体積干渉や衣服ハンガー接触を完全検査したことにはしません。

代表店主要設備と試着/撮影室内部の44経路は実際の既存プレイヤーCharacterBody3Dで自動歩行。43人NPCを90秒自動実行し床支持・1935カプセル重なりサンプルを記録。EV119乗降、ES/乗継等17経路、開口端46入力、操作12項目、F4/F6切替4項目も記録しています。これらは人間の実操作ではありません。

館内誘導48面/165経路の実衝突検査、原本・人物モデル・既存ゲーム本体の保護を確認。主要構造マスター、NPCモデル/動作、スキャン/AP/セーブ本体への統合は行っていません。未承認構造の専門安全性を確定していません。
