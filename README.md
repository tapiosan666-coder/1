# FIND YOURSELF v27 — ES外装・芝生ドッグラン 独立検証

v26公開版（8b1f0f0）を基準にした独立Godotプロジェクトです。既存ゲーム本体・正式建築原本には統合していません。Godot 4.6.3でZIPをすべて新規フォルダに展開し、ルートの`project.godot`を開いてF6ではなくF5で通常起動してください。初回はGLB/画像のインポートを待ってください。

通常起動はA/B/C統合構造候補。F6はB西ES単独の構造別案、F4はC単独の構造別案へ切り替えます。もう一度同じキーで通常候補へ戻ります。いずれも正式建築採用ではありません。

- B西の旧ES4基の退役を維持し、新連続ES6基と中央・東側の独立ES8基を維持。座標・開口・既存支持面を移設していません。
- 可動ES全42基に下面カセット・側面・乗降端の連続外装を追加。B西の低天井側面へガラス安全区画、各階へ乗場案内を追加。
- Cドッグランの既存柵・二重ゲートと設備をL-3緑地へ一体移設し、再生成した接近経路と実床に追従する芝生地盤・短い草葉・外周緑地を制作。Fキーでゲートを開閉し、一方が開いている間は他方を開けられません。
- 15層、480店舗、43NPC、店舗内装、既存EV、v26二重自動ドア・館内案内・防災設備を維持。新しい買い物AIは含みません。

`source/v27/equipment-inventory.json`に設備判断と座標、`review_v27.gd`に実画面撮影、`qa_movement_v27.gd`と`qa_dog_v27.gd`に実CharacterBody検証があります。Review ZIPの`index.html`はネット接続不要です。実GPU/WindowsでのFPSや人による操作試験、法規/構造計算の認証は別途必要です。詳細結果と未完了事項はReviewの検証記録を参照してください。
