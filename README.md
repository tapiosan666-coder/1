# FIND YOURSELF v34｜独立検証版

ZIPをすべて展開し、Godot **4.6.3** で `project.godot` を開いてください。初回インポートが完了したら **F5** で起動します。配布はGodotプロジェクト一式です。

- **WASD** 移動、**Shift** 速歩、マウスで視点。クリックでマウスを捕捉します。
- **F1 / F2 / F3** A館 / B館 / C館へ移動。移動先の床と周辺区画を読み込んでから切り替わります。
- **F** 対応する自動扉・エレベーターなどを操作します。エスカレーターは矢印側から歩いて乗り、階に着いたら歩いて降ります。
- **M** 館内マップ。店名・施設・店舗IDを検索し、目的地を選ぶと地図にピンが立ちます。**Esc** で閉じます。
- **Esc** 画面設定。既定は1920×1080、144 FPS上限、VSync ONです。144 FPSは上限値です。

| 描画品質 | 設定 |
| --- | --- |
| 標準（初期値） | 3D描画90%、FXAA、遮蔽の陰影を使用 |
| 高画質（v33相当） | 3D描画100%、4× MSAA、画面空間の反射と間接光を使用 |
| 軽量 | 3D描画75%、FXAA、画面空間の反射・間接光・遮蔽の陰影を省略 |

画面設定はローカルに保存します。各プリセットで画面出力の解像度、床や棚の位置、物理更新60 Hzは同じです。

v34では各エスカレーターの形状と乗り口表示、搬送時の接地、描画と区画読み込み、館内マップと案内、一部の代表店舗とC館北広場を見直しました。全体のデータは既存のA・B・C館15層と480店舗・43人の独立検証版を基準としています。変更点、画像、実測値、未検証・未施工の範囲はReview ZIPを参照してください。

既存のスキャンゲームへの統合は行っていません。進行セーブ、Windows専用GPUの実測、人間の通しプレイによる最終判定は今回の検証範囲外です。
