# FIND YOURSELF v32｜独立建築検証版

Godot 4.6.3（通常のForward+版）で、展開先の `project.godot` を開き、初回インポート完了後に F5 で起動してください。データの追加ダウンロードやZIPの結合は不要です。Windows EXEは収録していません。

## 操作

- WASD：移動／Shift：速歩／マウス：視点。画面クリックでマウスを捕捉します。
- F1：A館／F2：B館／F3：C館。
- M：館内マップ。表示中は移動を停止します。
- F：対応する扉・エレベーターを操作。ESは歩いて乗降します。
- Esc：設定・マウス解放。1920×1080／2560×1440／3840×2160、FPS上限30・60・120・144・無制限、VSyncを選び、保存できます。

初期値は1920×1080、144FPS上限、VSync ON、物理更新60Hzです。144は設定上限であり、達成FPSではありません。通常版のキー構成はv31を継承しています。旧比較構造を通常版へ再統合していません。

## 主な変更

- B館西ES：機械部・滑らかな移動・6本の上下運転と7.53mの乗継を維持し、2F・3F・RFに幅3.6mの斜め接続を設けました。床・ガラス柵・支持部・衝突・マップ・経路データを合わせて更新しています。
- 旧ES跡地は実データを調査。調査点の床高は既に連続していました。今回取り替えた現在のギャラリー形状と、旧跡地の残骸を混同していません。
- 139店：店舗ID・営業カテゴリ・区画・面積を保全。IDから再現する什器仕上げ、商品キットの材質単位のまとめ描画、書籍の種類、業種別の薄型壁面展示を改善しました。レジへの自動商品陳列は行いません。
- 書店16店：旧商品パネルが薄板保護で残る原因を修正。うち15店・230台の中央什器を、同じ1.8×0.78mの占有範囲で高さ1.28～1.32mの両面書棚へ更新しました。広告・ガラスは別に保護しています。
- B1-N01：細い区画に合わなかった大型展示を、小型オーディオ体験展示へ変更して接近経路を改善しました。
- B1-032：入口付近だけだった検証経路を既存売場の奥へ延伸。固定比較カメラは変更していません。元のentry視点は店外の共用廊下を向いており、改善済みの画像として一括承認していません。
- 48か所・62パネルの案内は横並び・距離表示なしを維持し、太字とコントラストを改善。C館では店舗に接続する庇・日よけを9か所に制作し、主要905.1m経路を保全しました。
- 一部の旧キャッシュに保存されていた空メッシュを識別し、有効な元区画から再構成。半径0.31m検査でプレイヤー自身を障害物と誤判定する問題も修正しました。床・壁等の衝突は無効化していません。

## 検証と限界

検査の最終結果、同一視点比較、全店の個別点検は別のReview ZIPにあるPDFとExcelをご覧ください。自動歩行、図形検査、画像による内部評価、人間の実操作・承認を区別しています。

LinuxのソフトウェアVulkan（llvmpipe）で検証しました。Windows GPUの60秒×3回測定と中央値60FPS／1%low45FPSの達成は未測定です。ソフトウェア環境での数値をWindows性能へ換算しません。

全139店の美術完成、重点12店の人間による完成承認、AAA品質を宣言する版ではありません。反復感や細部の仕上げは残ります。RF-SUPPORT-16、屋上水景等の未承認事項は未承認のままです。新しい支持部の耐力計算・現実建物の安全認証も行っていません。

15層・480店舗ID・43人の試験NPCは保持しています。元のスキャンゲームのNPC大量管理・スキャン・AP・セーブ、買物AI・購入処理へは統合していません。設定保存はこの独立検証プロジェクトのものです。

## 素材

新しい薄型什器と庇はBlenderで制作したオリジナルモデルです。商品・既存建築素材はv31同梱資産を継承し、既存ライセンス資料を保持しています。今回、新しい外部3Dモデルのダウンロードや実在ブランドのロゴの流用は行っていません。追加の素材情報は `licenses/v32/` に収録しています。
