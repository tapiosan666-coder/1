# FIND YOURSELF v25 代表5店舗・実画面レビュー

この提出版はv24完全ZIPだけを基準とした独立検証版です。全480店舗の一括小改修を止め、代表5業種の専用什器と内装・照明・ブランド表示を制作しました。全館美術完成、写真同等、FF16級達成とは報告しません。

## 今回改修した範囲

- A1F-039 FERNELL WORKS：246.66㎡。ブランド付きワードローブ、曲線レール、袋物ギャラリー、段差付き畳み台、専用レジ、コーディネート展示、ルーバー照明。
- A1F-051 ORIENNE BOOKS：901㎡。六段壁面書棚、両面ジャンル棚、雑誌展示、検索端末、読書席、木質線照明。正面主通路と設備接近点を残して壁面と中央売場を構成。
- B1-046 ALVENE EDIT：245.32㎡。専用ダイニングチェア、ラウンジ、窓側カウンター、返却口、乳白ペンダント、コーヒー・メニュー・焼菓子の壁面ギャラリー、木床。
- A2F-018 VELORIA COLLECTIVE：169.07㎡。ミラー付きテスター、専用壁面棚、香水台、コンパクト・香水、植物系ブランド配色、楕円照明。
- A3F-012 TERRUNE STORE：179.57㎡。音楽・レース・景品・カプセル・メダル・撮影・編集の異なる筐体とオリジナル画面。TERRUNE PLAYは館内プレイコーナーの副表示、元店舗ID・台帳ブランドと既存店舗正面は維持。
- 共用部はA館既存案内筐体1、B館瀬戸焼ブース1、C館キッズ広場の既存ベンチ2を専用仕上げに置換。配置、施設用途、案内内容、催事切替は維持。全館の通路や中庭を再完成させたものではありません。共用部遠景では変化が小さいため、同一視点の近景も併記します。

## 不具合を修正した原因

床高さの検出が小三角形を除外し、薄い既存タイルを拾えず、新仕上げが隠れていました。また什器の低い台座まで床と認識すると仕上げが三角形ごとに異なる高さになり白い線が出ました。v25用検出を建築の石・タイル床面に限定し、各店で連続する一枚の仕上げ高さへ統一しました。新しい構造床や透明衝突壁は追加していません。

畳み台の低い天板の左右、化粧品テスターの既存商品支持高さ、香水台天板の中心が未閉塞だったメッシュ、音楽ゲーム画面が外装内部に入っていた位置を修正。ゲームセンターに家電画像が出る旧広告分類も専用オリジナル広告へ変更しました。天井や壁は既存躯体の実レイ確認後に仕上げ、従業員扉のある長辺を全部捨てず扉幅だけ分割する方式へ変更しています。

## 実画面の評価と未完成

5業種の素材・什器・照明の違いは実Godot画面で確認しました。一方、書店の広い前面やカフェの中央には平坦な床が残り、アパレルの商品にはシルエットの反復、書籍には遠景の白い背の反復が残ります。細部の材質・衣服・商品密度・壁の接合表現はAAA環境品質に未達です。通行確保のため棄却した追加什器候補も記録し、旧接近点を潰して物量を増やしてはいません。

改修した5店舗も美術最終完成とはしていません。残る475店舗はv24状態を維持。地下・屋上・駐車場を今回新しく完成させたとは報告しません。RF-SUPPORT-16等の未承認項目と、構造別案のv24時点の扱いを維持し、今回新たな承認や本編統合はしていません。

## 検証の区別

全480入口・指定主通路、什器支持、非吊り商品の自身什器支持、192経路の実CharacterBody自動歩行、17移動経路、46床端入力、119EV、43NPC、操作キー、F4/F6切替、読取専用カタログを再検証。詳細はverification.jsonと生結果参照。これは人間の実操作ではなく、自動入力・実物理による検証です。全ての自由経路、手指・衣服の細部衝突や吊りハンガーの全接触面は未検証です。

## 初回インポートの対策
