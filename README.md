# FIND YOURSELF v31 — 独立した売場施工・歩行検証版

Godot **4.6.3** で `project.godot` を開き、初回インポート終了後に **F5**。ZIPの中身を新しいフォルダへすべて展開してください。追加Data ZIP・結合・Windows EXEは不要です。

## 通常操作

- F1 / F2 / F3：A / B / C館。WASD移動、マウス視点、Shift速歩。
- M：館内マップ。表示中は移動停止。Esc：設定。F：扉・EV操作。
- 初期1920×1080、上限144FPS、VSync ON、物理60Hz。保存済み設定があれば優先されます。
- 通常版では旧F4・F6などの比較キーを無効化。旧案のデータ・ソースは削除せず保持しています。必要な開発者確認は `--developer` で有効化します。

## 今回の範囲

1Fの139店舗へ、業種別の壁面・中央・入口展示とレジ配置を施工。重点12店は売場奥まで対象にしています。他127店は入口から約23mの見える範囲が主対象です。店名・業種・売場領域・バックヤード・480店舗IDは維持しました。

重点店：A1F-007 / A1F-015 / A1F-023 / A1F-038、B1-017 / B1-040 / B1-043 / B1-N01、C1F-CW-1 / C1F-CNW-1 / C1F-CNE-1 / C1F-CSW-3。入力Excelの「候補」からの選定差はReviewのExcelへ明記しています。

面と線が混在していた領域データを面積を変えず正規化し、旧売場表示・衝突の整理を共通化しました。レジ用キットのキャッシュが別業種の商品を持ち込む不具合も修正しています。レジは自動商品補充の対象外です。棚・設備の衝突はモデル形状に沿う共用リソースへ更新しました。

横並び・ピクト・矢印・距離表示なしの案内を48か所／62パネルに施工。屋外の既存自立式支持は維持しています。B館西側ESの滑らかな移動、7.53m乗継、床復元と安全柵を保持し、6基の下面パネルを追加。新たな移設や乗継短縮は行っていません。

## 完成していない事項

本版は施工・検証版です。**139店の売場美術、重点12店の奥までの最終品質をすべて完成承認した版ではありません。** 棚・商品の反復感、店舗ごとの細部仕上げ、美術評価が残ります。Reviewには全139店4視点の実Godot画像と進捗・検査を収録します。

A1F-003は実プレイヤー半径0.30mの自動歩行と、余裕を含む半径0.31m検査の結果が異なります。後者の警告を残しています。重点12店の展示前への追加検査では、B1-N01の壁面展示1点の接近が未確認です。レジまでの自動歩行合格とは区別します。自動歩行は人間による実操作ではありません。Windows GPU性能は未測定であり、144FPSや性能目標の達成を保証しません。

全15層・480店舗・43人の試験NPC・女性モデル・催事・地下／屋上を保持。RF-SUPPORT-16等の構造承認を変更していません。NPC・スキャン・AP・セーブを含む既存ゲーム本体には統合していません。買い物AI・購入処理も追加していません。
