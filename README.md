**全館1Fの完成版ではありません。** 既存ゲーム本体・建築原本には統合していません。取得済み公開v28（dd2571993fdfc84ab71f495aaaeced81f8237d01）を保護した作業コピーです。

## 今回の範囲

- 1FのA52・B69・C18、計139店舗を監査。135店舗へ業種別展示コレクションのデータ適用。422基の既存什器更新／追加。これらは完成店舗数ではありません。
- 既存の作り込まれたv25什器を保持。26種類の業種別コレクション（衣装、畳み物、バッグ、靴、書籍、化粧品、家電、食品、飲食など）を専用制作・組合せ。
- 重点24店舗に125か所の天井支持された照明・表示ステーションを設置。既存照明を残し、不足箇所に75灯と30の部門表示を追加。部門内の細かな商品構成や売場全体の完成は未達です。
- 既存の壁三角形を用いた1F面材仕上げと、実店舗・実壁面に対応する分岐付近の広告展示10か所を追加。新しい壁・床・衝突は作っていません。
- 1Fの床仕上げ、実天井に支持された共用部の専用モジュール360か所、店舗入口上部の意匠、実壁面のオリジナル広告29面を更新。
- 1F吊り下げ案内7基を横並びのピクト・矢印・施設名へ変更。距離表示なし。矢印は既存の実衝突で確認した経路から継承。既存の屋外自立サインの距離表記も除去。
- 233区間の経路台帳と277視点を定義。Reviewは実撮影できた画像数・検査範囲を明記します。

## 操作

WASD移動、Shift速歩、F扉・EV、Mマップ、F9確認地点。F9の先頭にv29の1F通路・店舗視点を追加。F4/F6構造比較、F11愛知県フェア、F12 NPC、N人物比較、P表情、F10設定は継承。

初期1920×1080、FPS上限144、VSync ON。**144FPS達成を意味しません。** Linux llvmpipeによる撮影結果はWindows実GPU性能の証拠ではありません。
