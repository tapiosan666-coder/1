# 実装範囲と残課題

**今回実装**：独立プロジェクトの共用施設・催事・休憩・案内・展示の重点エリア。専用32モデル、198配置、通常45面＋F6別案2面の掲示、二重ゲート、F11催事切替。これらの数だけで建築品質を合格にしていません。

**未完成**：15層・480店舗全体のグラフィック刷新。B館3Fの追加休憩候補は配置不成立で未実装。A/B地下の追加青果棚各1候補、C屋上の追加テーブル1・パーゴラ1は歩行帯・既存配置との両立を確認できず省略。Cキッズ・キッチンカーの独立型案内機は省略し、遊具側・車体側への掲示に変更。正式な店舗サービス、犬・こどものNPC、販売・チケット処理は未実装です。

**継続する品質課題**：通常版C館の大きな上階デッキ、既存の長い無表情な壁、店舗奥の密度、植栽モデルの自然さ、光沢・天井設備などは全館で仕上がっていません。今回のモデルにも専用のプロップや実店舗相当の精密ディテールが不足する部分が残ります。FF16級には達していません。

**未承認**：C館F4の構造別案、B館F6の連続ES敷地別案、RF-SUPPORT-16、B館屋上の支持未確認箇所、C館RF水上庭園。新しい承認やゲーム本体への統合は行っていません。

**未検証**：人間による実操作、Windows GPUでのFPS、全天候の営業運用、遊具・ドッグランの製品安全性、キッチンカーの搬入・旋回・営業設備、建築耐荷力・避難・防火・排水。自動歩行検査に合格しても、これらの合格を意味しません。

**省略の詳細**：`source/layout-rejections.json`。用途を説明できない倉庫・通路や、駅方面の新設道路で埋めていません。既存のスーパー・地下51店舗・屋上22区画・60トイレを増設施設と誤認させないよう区別しています。
