# FIND YOURSELF v16 レビュー

`index.html`をブラウザーで開くと、v15とv16の同一視点比較を確認できます。画像は実際のGodot 4.6.3 Forward+ Viewport・1920×1080です。別案は通常版と区別しています。PDFと配置図も同梱します。

v15を維持していた共用空間に、次の用途をまとめました。

- A館：西広場の案内・休憩、専門店街の週末クラフト展示、既存映画館・ゲームセンターの入口、既存書店前の待合。
- B館：時の広場に愛知の食6店・工芸3店とステージ。光の広場に植栽と休憩、翼の広場に季節展示。F11で催事を消すと屋台の衝突も解除。
- C館：キッズ広場、二重ゲートのドッグラン、メロンパンキッチンカー・屋外席。既存の主通路に用途を持つ舗装で接続。草・低木は新しい利用区画から除き、雨庭や残る植栽を保護。
- 地下・屋上：3館とも既存店舗・サービス・庭園の一部を充実。スーパーやロッカーを重複新設していません。

専用32モデル・オリジナル看板を追加しています。ただし、**全15層・480店舗全体の仕上げ完了ではありません。FF16級の品質にも未到達です。** 更新場所は`source/v16-施設と実装範囲.csv`、変更していない階を含む現状は`source/15層-現状と追加範囲.csv`に区別しています。

通常版の建築パック19個と主要な移動処理・店舗IDの原本を保護しています。C館F4、B館F6、RF-SUPPORT-16、水上庭園などの承認・通常版への統合はしていません。水上庭園の画像は**生成コンセプト、Godot実画面ではありません**。

`検査結果.json`は各検査の方法・結果・出典をまとめたものです。図面検査、自動衝突・歩行検査、キー入力注入による検査を、人間の実操作と混同しないでください。人間による実操作とWindows GPUのFPSは未検証です。llvmpipeでの撮影時FPSは参考値であり、RTX 4060や144FPS達成の根拠にはしません。

`未完成・未承認.md`に残課題、`使用素材とライセンス.txt`および`licenses/`に素材情報、`proposals/`に未承認案を収録しています。添付資料は設計参考として目視確認しました。外部施設のリンク先を今回新たに確認したという報告はしていません。

Godotプロジェクトは別の**FIND_YOURSELF-v16-Godot.zip**です。単独で全展開・起動でき、Review ZIPのデータを追加する必要はありません。Windows EXE・分割ZIPは作っていません。スキャンゲーム本体のNPC・AP・セーブなどには統合していません。
