# B館F6の乗り継ぎ検討

配置はv15の未承認別案を保持。通常版へ移設していません。1F→2F→3F→RFは同じ西広場の設備で移動し、2F・3Fの次の上りまで各8.4mです。今回は逆方向の下りも実W入力で検査し、各8.4mの経路を確認しています。橋の既存手すりに別案専用の案内を追加しました。

同じ側へ降り口・次便の乗り口を寄せる案も考えられますが、機械の重なり、床開口、乗降ロビー、店舗・広場との干渉を別に再設計する必要があり、今回の優先課題に対して配置変更の根拠は不足しています。短縮効果を実測した案とは扱わず、現配置の維持と案内を選びました。

B1への同一設備の延伸候補は車路と4台分の駐車に干渉します。地下の既存階段・EV・ESを保持し、無断で開口を増やしていません。建築・構造安全や営業運用の承認は未取得です。図面の局所経路とW入力検査は、人間による実操作とは区別します。
