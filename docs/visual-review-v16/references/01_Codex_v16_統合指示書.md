# FIND YOURSELF｜v16 3段階統合開発指示書
## 全館の通路・広場・地下・屋上の賑わいと、商業施設らしい空間密度の改善

v15の完全なGodotプロジェクトを基準にしてください。同時に添付した `FIND_YOURSELF-v16-Instruction-and-Images.zip` を展開し、`04_画像資料一覧.md` と**画像ファイルそのもの**を参照してください。URLの閲覧を前提にしないでください。画像中の文字より本指示書を優先してください。

**目的：** 空間をオブジェクトで無理に埋めるのではなく、実際の大型ショッピングモールのように、店舗の見え方・広場の用途・休憩・広告・公共設備が自然に組み合わさる環境を実装する。長期グラフィック目標はFF16級だが、今回達成したとは主張しない。

### v15の評価と保護するもの
- **C館F4の新構造別案は好印象**。これを改良候補の基準とし、屋外らしい開放感、デッキ支持部、接続先、3階と屋上へのアクセスを磨く。ただし**未承認のまま比較用シーンを維持し、通常版へ勝手に統合しない**。
- **B館F6の1F～RF連続エスカレーター配置案も方向性は良い**。乗継ぎやすさ・上り下りの配置・各階の着地点・柵・床開口の形を追加検討し、別案として残す。地下は既存車路・駐車4台分と干渉するため無理に貫通させない。既存の滑らかな視点移動を維持し、落下防止と物理検証を行う。
- 全15層、480店舗ID、地下51区画、屋上22区画、60トイレ、各階EV/ES/階段、地図とF4/F6/F8/F9などの検証機能、v15の正常動作は保護する。新規の不自然な隙間・行き止まりを作らない。
- 構造耐力・新規水盤の支持・RF-SUPPORT-16・未設置の屋上植栽槽は勝手に承認しない。

## 第1段階【最優先・最も工数を使う】通路・広場・地下・屋上を充実
最初に既存店舗・設備台帳を読み、重複施設を把握。全館の主要景観と現在の空白の**用途**を調査し、基準画像を撮影する。広さを「埋める」のではなく、歩行帯・滞留帯・店舗側の3領域を分け、自然に用途を持たせる。十分な歩行幅・視線・吹き抜け・消防上の空間を維持する。

**A館：都市型屋内モール**
- メイン通路の単調な壁・空白を、店舗前のディスプレイ、ショーウィンドウ、館内サイン、植栽、ベンチ、小型の催事ブースなどの組み合わせで改善する。
- 既存区画を確認してから、独立した客席・厨房・入口を持つ**レストラン街**、シネマ、ゲームセンター／ガチャ、玩具・家具・大型スポーツ・書店＋読書ラウンジなどの候補を適切に割り当てる。フードコートは共有席であり、個別レストランとは異なる。
- 小規模イベントスペースと、必要なら大型水槽を**別案**として提案。構造を壊して無理に追加しない。

**B館：3つの広場を使い分ける**
- 「時の広場」では**愛知県うまいもの・ものづくりフェア**を開催中の状態を重点制作。味噌カツ、手羽先、きしめん、ひつまぶし、ういろう、小倉トースト、常滑焼・瀬戸焼・有松絞りの紹介を、架空の店名と独自グラフィックで表現。催事ステージ・のぼり・可搬ブース・小規模客席・案内を配置し、通路と吹き抜けの見通しを維持。イベント未開催モードにも切替可能なデータ構造にする。
- 別の広場は水景／屋内庭園、もう一つは休憩・季節の展示など、重複しないランドマークを持たせる。
- 大型フードコート、サービス設備、ガチャ・ゲームセンター等は既存用途を照合して配置。壁と店舗の見た目を変え、単一什器の均等配置だけで完成としない。

**C館：屋外アウトレットの1F中庭**
- **キッズ広場**：低い遊具・滑り台・安全舗装・保護者ベンチ・日よけ。
- **ドッグラン**：芝生・適切なフェンス・二重ゲート・給水・清掃設備・ベンチ。キッズ広場と分離。犬・子どものAI/NPCを今回は必須実装しない。
- **メロンパンのキッチンカー**：架空のブランド、調理販売用車両、販売窓、焼きたてパン展示、メニュー、電源・ゴミ箱・待機列・屋外席。数を増やしすぎず、車両進入と歩行者動線の両立を図る。クレープ等は状況次第。
- 屋外に布張りの室内ソファを置かない。建物外観・回廊・花壇・舗装・屋外照明を一体設計する。F4別案は通常版とは別に保護する。

**地下（A/B/C）**：既存51店舗を保護。食品スーパー、惣菜、青果、冷蔵棚、地下専門店、ATM、ロッカー、サービスカウンター、軽飲食、案内サインに用途別のまとまりを与える。設備・搬入区域に客用施設を置かない。

**屋上（A/B/C）**：既存22区画・屋上庭園・歩行通路・駐車を維持。休憩テラス、展望、花壇・屋外ベンチ、必要なら屋外飲食を追加。支持床・落下防止・排水と干渉を確認。
- **C館屋上「オアシス21の水の宇宙船」着想の水上庭園**は、独自デザインの浅い反射水盤＋歩ける周回路＋ガラス手すり＋展望テラスの**別案画像・構造計画のみ**。F4別案と混ぜて無断実装せず、重量・排水・床支持が未検証であることを明記。

## 第2段階【重点】店舗の個性・ポスター・案内・広告
- 施設別の架空ブランド名・ロゴ・看板・商品展示を店舗IDへ紐付ける。アパレル・化粧品・書店・家電・食品・飲食・家具・玩具などの内装・什器・商品ラインナップに明確な差を出す。
- 愛知県フェア、店舗セール、季節イベント、映画案内、レストランメニュー、駅方面の方向案内（**駅への道路新設はしない**）などの**オリジナルポスター**を制作。架空ブランドのデジタルサイネージ、柱広告、吊りバナー、ショーウィンドウ、EV/ESの方向案内も自然な頻度で配置。
- インフォメーション、ATM、ベビーカー置き場、授乳室、ロッカー、宅配ロッカー、100円ショップ、ドラッグストア、眼鏡・携帯ショップ、クリニック、美容・サービス店等は既存店舗・設備と重複させず用途に適した場所に設ける。
- 同一ポスターやベンチを等間隔に大量複製しない。ポスターを読める向き・高さ・照度・スケールにする。外部参考写真や実在ブランドのロゴをゲーム用素材として無断転用しない。

## 第3段階【検証・改善】品質・性能と操作
- 主要地点の修正前後の同一視点Godot実画面（A/B/Cの通路・広場、地下、屋上、フェア、Cのキッズ・ドッグラン・キッチンカー）を残す。**参考コンセプト画像は実装スクリーンショットとして使用しない**。
- v15で改善された滑らかなエスカレーター移動を維持。F4/F6の別案が原本に上書きされないこと、床開口・手すり・EV・ES・C館回廊・店舗境界の物理衝突、マップを再検証する。
- 1920×1080、144FPS上限、VSync初期ON、物理60Hzを維持。LOD・共有メッシュ・距離に応じた表示などで性能を最適化する。Windows GPUで測れない場合は測れないと報告し、llvmpipeの数値を実GPUのFPSと混同しない。
- 3段階を1回の依頼で実施するが、**第1段階の空間品質を優先し、第2段階は重点箇所を実装、第3段階のテストは必須**。未完成範囲を完成したと主張しない。FF16級を達成したと報告しない。

## 今回の対象外
- 駐車場自体の大規模再設計、外周の直角道路の再配置、駅へつなぐ新設の歩道・連絡デッキ。
- 既存のゲーム本体、NPC・スキャン・AP等のゲームロジックの実装や本体への統合。

## 提出条件（厳守）
1. **FIND_YOURSELF-v16-Godot.zip**：完全な単独起動可能なGodot 4.6.3プロジェクト。必要なモデル・テクスチャ・ライセンスを収録。
2. **FIND_YOURSELF-v16-Review.zip**：変更前後の実画面、実装箇所一覧、代表施設の根拠、未実装・未承認の一覧、検査結果。画像を貼っただけの成果は不可。
3. 必要なら短いPDF。**Windows EXE不要・分割ZIP禁止・別Data ZIPでの補完禁止**。
4. A/B/C全館の共用通路・広場・地下・屋上の**現状と実装範囲**を区別して報告。v15から変更していない場所も分かるようにする。

**最終判定：** 歩いていて店舗・休憩・催事・情報・景観に変化があり、開放感と用途のある余白を両立できているか。広告・遊具・屋台の数ではなく、実際の大型モールとして自然かで判断します。
