## 0. 必ず区別すること
- **確認できた外部事例**：以下の公式サイト・施設運営者が公開する情報を要約したものです。本文や写真、店舗ロゴの転載素材ではありません。
- **FIND YOURSELF向け提案**：下記の配置案・デザイン案は創作上の提案であり、現実の施設の設計図を再現したものではありません。
- 写真や画像、実在店舗ロゴを許諾なくゲーム内アセットとして流用しないでください。
- 添付のv15 Godot/Reviewは**現状の正本**。v15で変更されたC館F4・B館連続ES F6は**未承認別案**であり、通常版に自動採用しないでください。

## 2. FLOOR別・館別の「何があれば自然に賑わうか」（以下は設計提案）

### A館：都市型・洗練・買い物の中心
- 1F：インフォメーション、A館の小型ポップアップ催事、案内看板、店前ショーウィンドウ、ガラス越しの商品展示、カート置場。
- 2F：大型書店と読書ラウンジ、家具・スポーツ用品・家電・玩具など、業種の違いが一目で分かる大型区画。既存店舗用途と重複しないよう台帳で調整。
- 3F：フードコートと別に、個店客席・厨房・待合を持つレストラン街候補。映画館やゲームセンターの候補も既存区画を先に確認。
- 中央吹き抜け：既存の見通しを残す。大型水槽・フォトスポットは**別案**とし、床荷重や通行への干渉が大きければ無理に設置しない。

### B館：3広場の個性・催事の賑わい
- 時の広場：**愛知県うまいもの・ものづくりフェア**。独自屋号の味噌カツ、手羽先、きしめん、ういろうなどの展示販売、常滑焼・瀬戸焼・有松絞りをモチーフとするパネル。実在ブランドは複製しない。大型見出し・小ステージ・ポップアップブース・休憩イス・観覧余地を混ぜる。常設化したら通常時にも使えるモジュールにする。
- 他の広場：水景または屋内緑化を中心とする静かな広場、撮影スポット／季節催事を中心とする広場として差別化。少なくとも一つは空間の余白を残す。
- 専門店街：店舗入口の演出、天吊りバナー、モール案内、迷惑にならない少数のカート置場やベンチ、柱沿いの広告を、等間隔でなく機能に応じて設置。
- ファミリー・娯楽用途：大型玩具店、ガチャ、ゲームセンター、インフォメーション、クリニック、美容室などの候補。既存480店舗の再割当案として扱う。

### C館：屋外アウトレット、1Fの中庭
- 中庭：**キッズ広場／ドッグラン／メロンパンのキッチンカー**を独立した小区画に分け、花壇・耐候性ベンチ・低い柵・案内標識と結びつける。
- キッズ広場：小さな滑り台・低い登り遊具・衝撃緩和床・保護者席。見通しを遮らず、犬の区画とは柵と緩衝帯で分ける。
- ドッグラン：フェンス・二重ゲート・水飲み設備・清掃用ゴミ箱・ベンチ。動物NPCを新たに必須実装しない（ゲーム方針の変更は別件）。
- 屋台：耐候性の販売窓口・看板・屋外テーブル・順番待ちスペース。車が出入りできるかは既存地形を見て無理のない案にする。
- 1F〜RF：v15のF4構造別案は未承認。屋外の支持柱・連絡橋・手すり・照明を先に自然にしてから装飾密度を調整する。
- RF：オアシス21の水の宇宙船から着想を得た**独自意匠の展望水景**は比較用の設計案のみ。F4の床改変と混ぜて無断採用しない。

### 地下と屋上（全館）
- 地下：食品・日用品・サービス・搬入設備を混同しない。既存51店舗は保持。市場風の惣菜・野菜・冷蔵棚、カート置場、案内、ロッカー、軽飲食、サインを選んで強化。地下が全域レストラン街にならないようにする。
- 屋上：既存22区画と駐車場・歩道を保持。屋上庭園、休憩テラス、展望デッキ、売店／フードトラックは日射・風・転落防止・支持床の有無を確認して配置。B館植栽槽の支持床未承認箇所は無断に増築しない。

## 3. 通路・広場の密度設計の型
- **店舗寄り**：店舗の敷地内にショーウィンドウ、入口付近の販促、ガラス越しの什器。共用通路へ商品ラックを無造作にはみ出させない。
- **歩行帯**：主な歩行ルートを連続して確保。休憩イスや植木鉢で左右から狭めない。
- **溜まり**：広場端・分岐点・EV前の広い余剰部分に休憩・サイネージ・小規模サービスを配置。
- **視線**：20〜40m先を見たとき、ブランド看板・店舗ファサード・ランドマークの変化が分かる。数値は設計目安であり現実施設の規格値ではない。
- **分散**：1種類のベンチを整列させない。各ゾーンは用途・素材・色・高さ・広告の文言が異なる。
- **空白の意味**：イベントの準備床・避難動線・視線の抜けなどに役割があれば、埋めない。

## 4. 広告とサイン（架空制作の方向性）
- イベントポスター：『愛知県フェア』『週末マルシェ』『新作映画』『今月のイベント』。
- ブランド広告：架空の衣料・化粧品・スポーツ・家具・飲食店。既存の店舗IDとブランド台帳を使う。
- 情報サイン：階・館・方向・トイレ・EV・ES・映画館・フードコート・レストラン・屋上庭園・ドッグラン。
- 形式：天吊りバナー／柱広告／店舗窓ステッカー／イベントパネル／自立看板／デジタルサイネージ。過剰な同じ画像のコピーを禁止。
- **画像が必要な広告は、後で専用のオリジナル絵柄を作る想定で、v16では配置・サイズ・文字・表示面を先行**。実在人物・実在商標・権利未確認の写真を勝手に使わない。

## 5. 進行と検査
1. v15データ台帳で既存設備・店舗用途の重複を調べる。F4のC別案／F6のB ES別案は通常版と明確に分ける。
2. 主要通路・広場、地下、屋上の「改善前」キャプチャを固定カメラで保存。
3. 第1段階は共用部・広場・地下・屋上の用途と空間密度を改善。必ずGodot本体で実装する。
4. 第2段階は看板・販促・代表業種の店舗外観・イベントテーマを統一させる。
5. 第3段階は反射・照明・LOD・描画負荷、歩行・衝突テストと同一視点比較を行う。無理な場合は未実施を明記。
6. Windows EXEは提出不要。単独起動可能なGodot ZIPを1つ、Review資料ZIPを1つ。分割ZIP・別途Dataを要求する構成は禁止。
7. **駐車場間の外周道路・駅連絡通路は今回は設計対象外**。既存ルートを壊さず、後で別に検討する。
