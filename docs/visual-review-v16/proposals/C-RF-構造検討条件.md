# C館RF 水上庭園 — 未承認・設計検討のみ

この案はF4別案と別管理です。通常版・F4のシーン、床、通路、店舗IDへ反映していません。生成コンセプト画像はGodot画面ではありません。既存屋上の正確な設置位置は未決定です。

構成案は、浅い反射水盤、乾いた周回路、ガラス手すり、展望・休憩テラスです。オアシス21の「水と空・都市を眺める公共空間」という考え方を参考にし、固有の意匠・形状を複製しません。

仮検討値：水面240㎡、深さ80mmなら水だけで19.2t、面荷重は約0.785kN/㎡です。これは設計条件を考えるための計算であり、既存床が支えられることを示しません。水盤躯体、防水、床仕上げ、機器、利用者、積雪、地震・風による荷重は別途必要です。寸法・水深は実施設計値ではありません。

次段階で必要な確認：

- 実際のRF床・柱梁・基礎の支持経路、耐荷重とたわみ、建物ごとの構造分離。
- 既存の階段・EVから周回路までの避難・バリアフリー経路、混雑時の幅員。
- 主排水と独立したオーバーフロー、ドレン・防水立ち上がり、漏水検知・点検経路。
- ガラス手すりの構造、滑り抵抗、水際の落下防止、風環境、保守・清掃方法。
- 屋上店舗・既存22区画・駐車・設備機器との干渉、搬入・交換の経路。

RF-SUPPORT-16やBRF-GARDEN-2-BED-4の承認、支持床補完の根拠には使いません。上記を実証するまでは施工・実装を保留します。
