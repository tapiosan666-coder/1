# FIND YOURSELF v18 検証資料

`index.html` をブラウザで開くと、実Godot画面を同じ視点で比較できます。画像をクリックすると1920×1080の元PNGを開きます。左右比較は表示方法だけを変え、撮影画像そのものは加工していません。

## 実装した範囲

- 代表8店・7業種の売場を組み直し。新しい店内203配置＋共用休憩11配置、計214配置。
- 試験用買い物客43人（A14/B15/C14）。歩行15、着席10、商品閲覧6、会話6、催事4、案内閲覧2。F12で描画・衝突・更新をまとめて切替。
- 480店舗ID、15層、v17のブランド・正面・広告、館間連絡、プレイヤー／ES移動処理を維持。
- 旧什器を除去した後にも残っていた120mm以下の陳列台台座の孤立衝突を、対象8店の売場に限って除去。床・壁用の構造材料は除外。
- 書店等で壁面什器の向きが逆になっていた配置規則を修正。C館の会話役は植栽台上から実床へ移動。腕の向きと着席姿勢を修正。

## 完成扱いにしない範囲

- 全館の景観・全480店舗の内装が完成した版ではありません。代表8店を再構成し、残る472店は従来内装を維持しています。
- 人物は試験用の造形・手続きアニメーションです。服装の形状差、顔・手指・髪の質感、着席時の細かな接触や自然な演技は未完成です。商用品質の人物完成とは扱いません。
- 屋上、遠景の長い壁、白い天井、大きな空白は残っています。屋上の新休憩家具1組を屋上全域の完成とはしていません。
- 食品パッケージや書籍のデザインは反復が多く、棚を越えた売場演出と商品種類は追加制作が必要です。
- NPCは1Fの短い指定経路のみです。EV・ES・階段への乗降は未実装で、経路を機械周辺から離しています。高度な群衆回避や長時間耐久は未検証です。
- C館F4、B館F6、C館水上庭園、RF-SUPPORT-16は未承認。通常版へ統合していません。構造耐力・水盤荷重を実証していません。
- 人間による手動操作、Windows GPUのFPSは未測定です。FF16級の環境品質、144FPS達成を主張しません。

## 検証の意味

`physics/` はGodotの実衝突判定を用いる自動検査です。`data/layout-check.json` は2D図面・什器配置の幾何検査です。両者を区別し、人間の操作テストや美術品質の合格とは扱っていません。店内40経路は実カプセルで再検査。人物は60秒のシミュレーションで床支持・移動・ON/OFFを確認しました。最初の店内検査で停止した経路や、植栽台に立った人物も、実画面・実物理で見つけて修正しています。

画像の人物位置・姿勢は、実際に20秒間シミュレーションしたスナップショットで固定しています。NPCなし／あり比較でカメラや床・照明は変えていません。性能観察も姿勢固定で描画差を比較しており、移動中の総合ベンチマークではありません。

## 未承認のF6候補

機械配置を変えず、7.532mの角を丸めた乗り継ぎ候補と左右0.35mの余裕を実歩行で確認。6ケースを確認しています。候補の通常版採用やES移設の承認ではありません。6.4m案の過去の手すり干渉は棄却のままです。

新規什器・包装・部門表示・髪・バッグは本プロジェクト向けのオリジナル制作。人物のMakeHuman由来加工素材はCC0。PBR素材・フォントは継承した条件を維持し、`licenses/` に原出典と条件を同梱しています。実在ブランドの広告や写真を新規の看板に流用していません。
