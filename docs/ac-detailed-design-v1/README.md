## 再現
同じリポジトリ入力とPython/Shapely/PyMuPDF/Blenderを用い、設計用toolsを実行。ZIPは完成図面/データ/検査を閲覧するためのものでゲーム一式や全依存ソフトは含みません。立体画像12枚は統合PDFに収録し、重複する個別PNGと中間描画メッシュはZIPから省いています（リポジトリには保存）。公式参考PDF原本は再配布せず、提供ファイルのSHAと目視参照ページを記録しています。
