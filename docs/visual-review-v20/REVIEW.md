# FIND YOURSELF v20｜人物制作の方式変更と検証

**提出区分：独立した人物検証版。『ソフィーのアトリエ2』級の完成品質は未達。**

`index.html`をブラウザで開くと実Godot画像を拡大し、v19との比較、6表情、連続動作画像を確認できます。人物確認シーンも同梱しています。ゲーム本体に統合していません。

## 今回実装したもの

既存43人のうちV18-A-01の1人だけをFY-F-01へ変更しました。ほか42人の顔・体を新モデルへ展開していません。旧女性モデル・元のv18人物群をNキーで比較できます。

MakeHumanの写実寄り素体を継続修正する方法から、許諾設定を確認したpixiv製アニメ調VRMサンプルを基にBlenderで再構成する方法へ変更。アニメ素体・顔トポロジーはライセンス付き原型であり、完全な新規スクラッチ造形とは表記しません。目・頬・顎の比率、瞳、髪のシルエット、私服、衣服分割・厚み・接合、リグ、9動作、シェーダーを変更しました。作品固有のキャラクターや衣装を複製していません。

成人の買い物客として約1.65m。濃紺系の髪、青緑の瞳、セージ色の短丈カーディガン、アイボリーのトップス、スレート色のパンツ、スニーカー。指のある人体メッシュを利用し、球・円柱の組合せの人体ではありません。

最終ランタイムGLBは**38,908三角形・54ボーン・57顔モーフ・9動作**。輪郭の追加描画パスは三角形数に含めていません。顔の元の57モーフを利用し、通常・笑顔・嬉しい・不機嫌・驚き・困ったの6プリセットをJSONで独立管理。会話AIや機嫌処理は未実装です。

## v19の原因調査

1. MakeHuman由来の写実的な人体比率が、求められるアニメ調の顔と合っていませんでした。ポリゴン・ボーンを増やすだけでは解決しません。
2. v19撮影の`AnimationPlayer.play(clip, .22)`後にseekする処理を再現したところ、MANUAL再生のブレンド時間を進めておらず、前の着席姿勢が次のクリップへ残りました。再現時の腰高は着席約0.531mのままで、正しく評価したIdleでは約0.858mでした。v19の旧館内ポーズ画像を動作完成の証拠として再利用していません。
3. v20の静止撮影はstop→play(ブレンド0)→seek→advance(0)と実ボーン更新で評価。実クリップ名・割当名・時刻・腰高を画像ごとに保存。通常再生はdtを進めるブレンドを残し、歩行位相は実移動距離と実クリップ長に同期させました。
4. 新素体の補助ボーンをそのまま置換すると袖の裂け・重なりが出たため、人体54ボーンへ重量を整理、法線方向の厚みと衣服の重量を再評価しました。位置から推測するウェイトでは胴の布まで上腕へ結び付くため、最終版は原型の衣服ウェイトを保持し、54ボーンへ再対応・正規化しています。なお、衣服の細部や座位の接触は完全には解消していません。

## 画像と検証の区別

- `character/`：1920×1080の実Godot Viewport。顔3方向、全身3方向、表情6種、歩行8位相、着席6時刻、立ち上がり6時刻、停止・旋回・閲覧・座位。スタジオの歩行はその場のクリップ評価で、実移動の証明ではありません。
- `mall/`：A館1F。自動物理検査中に記録した立位・歩行・着席・閲覧の状態を凍結再生した実画面。閲覧は同じ人物IDを既存書店の閲覧経路へ一時的に割り当てた独立シナリオです。通常の43人データは変更していません。
- `before-v19/`：以前の実Godotスタジオ画像。全身3方向は同じカメラ、顔は`character/v19-face-view.png`が旧座標と同じ。v20の通常顔アップは新しい顔位置に合わせた別フレーミングです。髪・身長・描画材質の差を含む比較です。
- `viewer/`：実際に操作できる人物確認シーンの実画面。自動で9動作・旧新比較・UI範囲を確認しました。
- **人間による実操作は実施していません。** 自動のキー入力・物理移動・状態再生です。全フレームの衣服自己交差、手の正確な接触、任意地形の足接地が保証されたわけではありません。

- 実歩行20秒：足首の接地期観測523件、1物理tickの水平ずれ中央値0m、最大約0.00653m。足首の観測であり、靴底の完全接地や任意地形IK、無滑りの保証ではありません。

近距離の衣装には肩・袖の開きやインナー露出が残ります。胴体が腕に引っ張られる変形は改善しましたが、肩の補正形状まで完成したとは扱いません。手は座位で腿に厳密に接触しておらず、靴と床にも微小な浮き・貫通が残る可能性があります。驚きの口形など、表情の誇張も調整余地があります。髪の衝突・揺れ、服のシミュレーションは未実装。高品質な基準モデルを43人へ展開する判断は保留します。

LinuxソフトウェアVulkan、各条件4フレーム。フレーム時間中央値は人物なし約4,838ms、旧1人約4,817ms、新1人近距離約4,451ms、43人移動約5,002msでした。すべて実時間の快適動作としては不合格で、Windows GPUの予測値には使用できません。描画callは3,904→旧1人3,947→新1人3,991→43人移動4,102～4,106。新モデルは輪郭パス等によりcallが増えています。ポリゴン削減だけで最適化完了とは扱いません。

移動ケースは4描画フレームで物理時間が約0.53秒のみ前進しました。描画が遅すぎる環境での短い観測であり、実時間の歩行や安定FPSを証明するものではありません。Windows GPU、長時間の安定性、新モデル43体への展開は未検証です。距離別LOD・輪郭描画の制御・材質統合・アニメ更新間引きが今後の課題です。
