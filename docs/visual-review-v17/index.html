FIND YOURSELF v17

v16を基準とした独立した景観・店舗品質の検証版です。Godot 4.6.3 / Forward+ の1920×1080実Viewportを、同一位置・向き・FOVで23組比較します。画像をクリックすると原寸PNGを開けます。ゲーム本体へは統合していません。

全館完成・FF16級の達成とはしていません。店舗正面の更新と代表業種の展示強化が中心です。広い無地面、周辺景観の密度、各店舗の個別売場計画は依然改善が必要です。人間による実操作とWindows GPUのFPSは未検証です。
