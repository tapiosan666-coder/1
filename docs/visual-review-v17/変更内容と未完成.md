# v17の変更と到達範囲

Godot 4.6.3の実Viewportをv16と同一視点で比較しています。全館完成・AAA品質の達成ではありません。

今回実装したもの

- 既存458店舗・909辺の実境界に沿う正面造作、480ブランドの独自図案・ロゴ台帳、商品CGを含む広告。屋上の開放型22店舗に浮いた正面壁は作っていません。
- 不透明壁の60区間に仕上げ・広告。粗い検査の58候補から、細い開口を見落とす4候補を除外。上階の客用通路側6面を追加。198レイによる照合は厳密な位相証明や建築品質保証とは区別します。
- 書店・化粧品・衣料・雑貨・家電・食品/カフェの専用什器、代表店舗と休憩エリアの80配置。16点は実什器の上に載せた小物で、床置き什器とは区別しています。全店舗の内装更新ではありません。
- 愛知県フェアの9既存屋台へ図案入り告知、F11連動。既存ステージ・食品工芸モデル・主通路は維持。
- C館キッチンカーの注文/受取設備とメニュー。屋上カフェ等のカフェ椅子を実接合モデルへ修正。樹木の葉と枝の接続・樹冠を改善。
- 自然光・店頭照明を調整。ベイクした間接光は四角い明暗差が現れたため不採用。既定表示にそのキャッシュを使わず、無効なキャッシュは配布していません。

維持したもの

- 15層、480店舗ID、建築パック19点、通路・床開口・館間接続、プレイヤー、ESの滑らかな搬送、EV・階段・扉。
- M、F4、F6、F9、F11。標準1920×1080、144FPS上限、VSync初期ON。
- 元ゲームのNPC・スキャン・AP・セーブは変更・統合なし。

未承認・提案

- F4 C館は別案のまま。v17は仕上げを更新し、通常版のデッキを無断で削除していません。
- F6機械配置は維持。既存8.4m、角を緩める7.53m、最短6.4mを比較。最短は中心の通行に成功しても片側35cmで手すり接触が発生し不採用。7.53mは中心・中間部の左右35cmを通過しましたが、人の見通しや混雑は未検証。次の確認候補であり承認済みではありません。
- C屋上水上庭園：実屋上の公開床と支持床を照合。指定した余裕を持つ12×16mの軸平行候補を確定できず、設置位置は未決定。これは全向きで不可能という証明ではありません。240㎡水盤のローカル詳細と、深さ40/80/120mmの水荷重を別案で提示。80mmなら水だけで19.2t。躯体・排水等は未検証で、通常版・F4とも未実装。
- RF-SUPPORT-16、支持未確認の屋上植栽は未承認維持。

まだ不十分なもの

- 一部看板の縦横比・遠距離での読みやすさ。
- 通路・広場に残る広い無地面、単調な天井、店舗ごとの素材/ディテール、広告の館全体での構成。
- 全480店舗の入口から奥までの個別売場計画。今回の専用什器が全店に置換されたわけではありません。
- C館通常版の過剰デッキ、屋外植栽と建物支持表現の全面仕上げ。構造別案の承認と設計見直しが必要です。
- 地下食品売場の全商品・部門別売場、屋上全域の景観、B館の他広場の新規水景・季節展示。既存施設を維持し、追加していない設備は完成扱いにしません。
- キッチンカーの実営業、催事運営、子ども・犬の挙動は未実装。
- 人間の実操作、Windows GPU性能、144FPS、構造安全・車両軌跡は未検証。

制作環境と素材

- Blender 4.3.2の専用モデル、オリジナルCG商品写真と図案、既存の商用利用条件が明記されたテクスチャを使用。新たな外部写真を確認済みとはしていません。
- 商品写真風のCGは広告の素材であり、Godot証拠画像とは別です。参考写真・他ゲームの固有資産・実在ブランドのロゴは転用していません。
- 使用条件・継承素材の出典はlicensesフォルダ。ブランド名の商標調査は未実施。

確認方法

Reviewを展開してindex.htmlを開くと、23組の実画面を拡大・スライダー比較できます。sourceのCSVは館・階・座標・実装範囲、plansは15層の更新位置、testsは自動検査、proposalsは未承認案です。検査の成功件数を景観品質の完成判定としていません。
