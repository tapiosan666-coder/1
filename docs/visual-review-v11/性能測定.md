# 描画性能の測定範囲

Linux／llvmpipe (LLVM 19.1.7, software Vulkan)・Forward+・LP_NUM_THREADS=2。1920×1080、3D描画スケール1.0、MSAA4、144FPS上限、VSync ON要求。NPC 0人。

他のGodot処理、インポート、検査、ZIP圧縮を終了してから測定しました。各視点4フレームのウォームアップ後、8フレームを壁時計で測定。固定FPSオプションなし。起動時の生成時間は除外。8フレームのみなので、統計的に十分なハードウェアベンチマークではありません。

|視点|平均FPS|中央値フレーム時間 ms|最大 ms|
|---|---:|---:|---:|
|A館1F|0.101|9835.9|11455.6|
|B館1F 時の広場|0.136|7376.3|8060.8|
|C館1F 通常版|0.107|9517.8|9750.1|

この環境では60FPSを達成していません。Windows／RTX 4060でのGPU実測はなく、その性能へ換算しません。低いソフトウェア描画速度は、そのままユーザーPCのFPSを示すものではありません。144FPS上限は設定値であり達成値ではありません。

GPU上での描画負荷、反射・GI・多数の売場／照明、店舗群の可視範囲とLOD、実プレイ中のフレーム時間を検証する必要があります。今回の更新頻度制御や共有メッシュを、60FPS達成の根拠とはしません。
