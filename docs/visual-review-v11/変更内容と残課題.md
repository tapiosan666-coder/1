## 品質上の残課題

- B1-008は壁面陳列を置換していますが、入口から見た中央が空いており、右手の設備ボリューム・看板の納まりも含めて内装未完成です。棚を追加しただけで完成扱いにしていません。
- 全480店の詳細内装は未完成。代表8店と既存代表売場のみ改善しています。特に大型店の奥までの商品構成、商品種類、レジ周辺の設備、入口のブランドごとの設計、POP・看板の納まりが不足しています。
- 店舗台帳には209店の指標フラグが残ります。短辺・形状比・大型店の裏方面積などを抽出したもので、209店をすべて欠陥と判定した数でも、修正済みの数でもありません。
- A1F-001の裏方は約46.5㎡に留まり、売場規模に対して共用物流・在庫・冷蔵庫の設計が不足しています。売場を無断で削って解決していません。
- C館では図面の手すり線と実3D床境界の差分が残ります。RFの初期12候補をすべて欠落と断定せず、全衝突材質と実床境界で再分類しています。金物仕上げは共通の実ガラス面だけに限定し、別案固有の縁や全地点の実操作検証は未完了です。
- C館未承認別案の上向き視点では、空に黒いぼかし状の表示と一部の黒い面が残っています。反射・間接光・マテリアルの切り分けは未完了で、修正済みとは扱いません。天井設備の反復や看板の納まりも美観の課題です。
- C館は開放感・支持構造が未解決です。通常版を「支持構造完成」と扱いません。縮小案でも2F・3F・RFの各店舗と設備への連続アクセス、荷重経路、排水、耐力・基礎・避難の検証が必要です。
- RF-SUPPORT-16は未承認。追加したRF手すりは構造支持の承認ではありません。
- 既存店舗写真・参考資料はv10の出典記録を継承。v11で新しい実地写真を取得・確認したとは主張しません。新規モデルはオリジナル制作で、写真相当・FF16級の品質に到達していません。

## 検査の区別

1. 図面：ポリゴン有効性・区画重複・ID維持・境界配分・入口と共用床の関係を検査。
2. 自動物理歩行：Godotの実コリジョンとCharacterBody3D。個別経路では開始点へ配置し、連続A→B→C検査では最初の1回だけ配置して約700mを歩行。途中ワープ・noclipなし。
3. F／M：イベント注入・実際の行先ボタン操作による自動検査。人間のマウス・キーボード操作ではありません。
4. 実画面：Forward+のGodot Viewportを1920×1080、描画スケール1.0で取得。図面やBlender画像を実画面と偽っていません。
5. 人間による実操作：未実施。Windows GPUでの性能測定：未実施。60／144FPS達成：未確認。

製作途中で、ES補助の修正が通常階段に影響する回帰不具合、RF内部開口の手すり欠落、C館残余の誤分類を検出して修正しました。RF手すりの初版は3基のEV開口にも干渉したため、実EVの扉幅・敷居・かごまでの乗降領域を保護領域に加え、乗降検査を再実行しています。提出時の検査と途中の検査を区別し、最終結果を `検査結果サマリー.json` に記録します。

C館別案の348件は、既存のID部分一致フィルター（C）で選択した経路です。C館の経路に加え、PUBLICを含む駐車場等の経路も含むため、348件すべてをC館固有の経路と扱いません。

指定経路945件では従業員扉を自動で開いた状態にして通行寸法を検査しています。全扉を人間がFキーで個別操作した検査ではありません。EVは別途Fイベントと実行先ボタンで呼出・乗降を確認しています。Vulkan描画終了時にはTexture RID警告7件を観測しており、終了処理と継続的なメモリ増加の切り分けは未完了です。
