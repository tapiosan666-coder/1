# Windowsで開発版をGodotから起動する

Smart App Controlで配布EXEがブロックされる場合の別の起動方法です。
セキュリティ設定を変更したり、ブロックされたEXEを許可する操作は必要ありません。
ただし公式Godot自体が端末のポリシーでブロックされる場合もあり、起動は保証できません。

1. https://godotengine.org/download/archive/4.6.3-stable/ を開きます。
2. Windows向けのGodot Engine「Standard」64-bit版をダウンロードします。.NET版やexport templatesは不要です。
3. GodotのZIPを「すべて展開」し、Godotの実行ファイルを起動します。
4. FIND_YOURSELF-Source.zipも、別のフォルダーに「すべて展開」します。
5. Godotのプロジェクト一覧で「インポート」を押します。
6. 手順4で展開したフォルダーの中にある FIND_YOURSELF フォルダー内の project.godot を選びます。
7. プロジェクト名「FIND YOURSELF（開発版0.11）」を確認して開き、読み込みが終わったらF5を押します。F6ではありません。
8. ゲーム画面で「探索をはじめる」を押します。

project.godotをWindows上でダブルクリックする必要はありません。
Godotの「インポート」から選択してください。
ゲーム用のPython、Node.js、APIキー、export templatesのインストールは不要です。
ソース版にはゲームのWindows用EXEを含めていません。
Godotにもブロック表示が出る場合は、そこで止めて表示された文面を確認してください。

## 署名付きEXEについて

現在のゲームEXEは未署名です。信頼されたコード署名証明書・署名サービスは開発環境に設定されていません。
正式な署名には証明書やサービスの契約、発行者の本人確認などが必要になる場合があります。
自己署名でWindowsの信頼を得たとは扱いません。正式な署名後もSmart App Controlの許可を保証はできず、Windows実機での確認が必要です。

## 0.11の確認

旧版とは別フォルダーへ展開・インポートしてください。タイトルに「日本語開発版 0.11」、探索開始時はA館1階です。中央広場（アトリウム）のエスカレーターから2階、さらに3階へ歩いて移動できます。上階も店舗に入れます。NPCに近づくと短い日本語の吹き出しが出ます。宝箱はG、バッグはI、選択アイテムはXです。

地下・屋上は中央入口後方の西側階段から移動します。西側階段の1階から外へ進むと西駐車場です。Mの案内図は現在の階を表示し、実際に近づいて訪問した地点だけ、スキル購入後に選択して移動できます。現在は300人版です。

A館2階の西側階段からガラス張りの連絡通路へ進むとB館2階へ着きます。1階の西駐車場からも歩行者通路でB館へ入れます。B館は1〜3階で、奥の売場は家電・生活用品・映画館です。

移動中に重い場合はEscを押し、画質を「軽量」へ切り替えてください。設定は次回も保持されます。同じ画面に使用中のGPU名が表示されます。NVIDIA製GPUを搭載している端末でもIntelと表示される場合は、Windowsの「設定→システム→ディスプレイ→グラフィック」で、使用するGodot実行ファイルを追加し「高パフォーマンス」を選び、Godotを再起動して表示を確認してください。

C館へはB館1階の西端付近（家電売場入口の手前）から北側の「C館 アウトレット」案内へ進んでください。屋根付き連絡通路を渡るとC館の屋外広場です。C館は現在1階のみ、8店舗と休憩席があります。人数は300人、Mの移動地点は18か所です。

Tabのスキル画面は上部の4系統から選び、カードをクリックして右側の効果・購入条件を確認し、右下の購入ボタンを押します。カードを選ぶだけではAPを消費しません。

「探索猫を配備」を購入したら「探索に戻る / Tab」でプレイへ戻ってください。画面左上に猫の探索・移動・スキャン状態と秒数を表示します。初期は接近してから20秒で、移動時間は別に必要です。スキル画面やポーズ中は猫も止まります。猫の発見だけではクリアせず、最後は初期スキャナーで確定します。

0.10では人物の顔・体格・材質とA館の天井・床・壁・照明を更新しています。A館北側のファッション店（看板SILHOUETTE）が最初の作り込み区画です。比較画像はdocs/ART_COMPARISON.mdを参照してください。Blenderや元モデルの読み込み操作は、プレイには必要ありません。

0.11では肌と服の質感、まばたき、視線と口元、歩行中の腕の動きを更新しました。近くのNPCを数秒見ているとまばたきします。スキル画面や一時停止中、時間停止時計の効果中は人物の動作も止まります。比較と動作プレビューはdocs/CHARACTER_COMPARISON.mdです。
