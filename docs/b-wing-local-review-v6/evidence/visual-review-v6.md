# 実画面の目視評価

17候補を局所修正。入口の枠と照明により、旧先端付近から直線の間口へ移した入口を確認しやすくした。床の遠景モアレも抑制。各店舗の個別内装・商品表現が完成したという評価ではない。

連絡橋では外壁を窓・腰壁・屋根へ区分。端の仮表示は他館内部が未施工であることを示す。A/C館内を完成させた、または全館を実操作で歩いたとは報告しない。

屋上庭園は「歩行可能な庭園ゾーン」と「固体の植栽枠」を区別。庭園ゾーンを巨大な立上りとして生成した旧検証処理は通行を妨げていた。元の庭園ゾーン面積を保ち、実際の植栽枠18個を歩行経路から離して配置。屋上と橋は接続床の外周にだけ手すりを生成する。

地下は上階を含む複合シーンで天井・床・入口を確認した。地下全内装・階段・EVは未施工で、指定経路外の全域の安全・使い勝手は未検証。

橙色の支持は検討位置の可視化。RF-SUPPORT-16は支持方式未決、全支持部の耐荷重・基礎は未検証。

28枚の保存画像と4個の自動歩行到達位置を確認した評価で、人間による実操作ではない。画質、個別内装、照明・外観の細部は未完成。FF15級の商業施設品質とは評価していない。
