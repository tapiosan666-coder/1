# FIND YOURSELF — ショッピングモール設計指示書 v1.0

**用途:** Codex に添付してマップを再設計・実装させるための仕様書。必ず `FIND_YOURSELF_MAP_LAYOUT.svg` とセットで渡す。

## 0. 原則

- **最優先はマップ品質。** NPC・スキルの追加を進める前に、実際に歩いて楽しい3館の骨格を完成させる。
- 現在のプロジェクトとレビュー資料をまず読む。既存の3館の接続関係（Aは東、Bは西、Cは北西、およびA/B・B/C間の2F連絡）を尊重する。
- **イオンレイクタウンは建築上の参考。** 実際の平面図を写すのではなく、回遊性・吹き抜け・上下動線・店舗の密度・現実の商業施設らしさを取り込んだオリジナルとする。
- 添付SVGの寸法は**ゲーム用の暫定設計寸法**であり、実在施設の測定値ではない。ユーザー確定の「3館×B1/1F/2F/3F/RF」「超大型」は変更不可。数値は移動試験で見直す。
- 図中の青は店舗、緑は歩行可能な回廊、金色は吹き抜け、朱色はエスカレーター、紺は建物間の橋。色は**図面上の凡例**でありゲーム内の色ではない。

## 1. マスタープラン

| 区分 | A館 | B館 | C館 |
|---|---|---|---|
| 形状 | 三角形に近い3辺回遊モール | 長大な中央通路＋上下2本の回廊 | 屋外型・湾曲するアウトレット棟群 |
| 建物外形の暫定寸法 | 300×220m相当 | 500×160m相当 | 260×200m相当 |
| 特徴 | 中央・角の複数広場、三辺に店が並ぶ | 3つの象徴的な広場と長い見通し、多様な近道 | 屋外中庭、半屋外アーケード、独立した店舗群 |
| 2階連絡 | B館へ | A館とC館へ | B館へ |
| 各階 | B1, 1F, 2F, 3F, RF | 同左 | 同左 |

敷地全体は単純な長方形や均等な格子にしない。AとBの長さ・曲率・視線の通り方を変え、Cは屋外空間として明確に異なる体験を作る。3館が離れ過ぎて移動が単調にならないよう、2F連絡橋を機能させる。

## 2. 通路の寸法／歩行体験

| 要素 | 暫定ゲーム設計値 | 配置ルール |
|---|---:|---|
| B館メイン通路 | 幅12m | 長距離の主軸。店舗や吹き抜けにより14–16mへ拡張 |
| B館南北回廊 | 幅8m | 複数の回り道・ショートカットを形成 |
| 回廊間の接続路 | 幅7m | 行き止まりにならないよう連結 |
| 小さな通路 | 幅5–6m | 店舗奥やサービス区画。ただし常用ルートは狭くしすぎない |
| 吹き抜け沿いの歩行部 | 幅おおむね8–12m | 手すり、休憩、店舗前の滞留を考慮 |
| B館の広場 | 直径／幅おおむね30–35m | 3か所。すべて形状と内装を変える |
| 1階層の床高さ | 約5.5m | 実装の整合性を優先。3D座標系で一貫させる |

**禁止:** 全館が幅4mほどの廊下／同じサイズの箱状店舗／四隅にだけ階段／壁沿いに貼り付けたエスカレーター／見た目だけで使えない吹き抜け。

## 3. 吹き抜けとエスカレーター

1. エスカレーターは主として**吹き抜けの縁**に上り／下りのペアを配置し、吹き抜け越しに見える構図にする。
2. 1F→2F、2F→3Fを連続して上下できる。上り口・下り口を対応させ、逆走や行き止まりを作らない。
3. 各吹き抜けでエスカレーターの向き・取り付け位置を少し変え、すべてを同じテンプレートにしない。
4. 手すり、落下防止、乗降口の平坦な踊り場、吹き抜け周回路、案内サインを設ける。
5. 地下と屋上へはエスカレーターだけに依存しない。階段・エレベーター・別の動線も用意する。
6. 吹き抜けは2F/3Fで**床が抜けていること**。見かけだけの穴や床の重なりを許容しない。
7. エスカレーターは移動可能なゲームオブジェクトとし、移動方向、端点、高さをテストする。

## 4. B館の基準フロア（最優先で作成）

- **光の広場**: 楕円形、約35×28m。中央付近。3階分の吹き抜け。イベント床、両サイド回廊、見やすいエスカレーター。
- **時の広場**: 円形、直径約30m。通路が分岐する場面。時計・ベンチ等の目印を置く。
- **翼の広場**: 角丸長方形、約35×30m。大きな店舗・イベントスペースへ接続。
- 1F/2F/3Fの店舗の形は少しずつ異なる。**上下階で吹き抜け位置は完全一致**させる。
- B1は駐車・倉庫・食料品・設備区画などで地上階との差を明確にする。RFは屋上広場・設備・テラス等を配置。
- 目安のB館店舗数はB1=15、1F=75、2F=75、3F=65、RF=0〜5。**計画目標であり、未完成の箱を数に入れない。**

### 店舗モジュールの目安

小型40%、中型40%、大型15%、特大型5%。正面幅と奥行きの候補例：6×10m、10×14m、18×20m、30×35m（いずれも仮）。単純な均等分割は禁止。角地、奥行き、2フロア店舗、折れ曲がった店、フードコート、トイレ、スタッフ動線を混ぜる。

### 店舗内部

店内の最低要件は入口、店頭、商品棚・什器、回遊路、奥側のゾーン。衣料、雑貨、書店、家電、飲食店で内装を変える。入れる店舗はNPCとプレイヤー両方が出入り可能。トイレも洗面、個室、出入口の曲がりを持たせ、単なる空箱にしない。

## 5. A館とC館の基準

**A館:** 外周3辺の連続ルート、中央の大吹き抜け、各角の異なる小広場を持つ三角回遊。一本の廊下で行き止まりにならず、近道が成立すること。各辺の見え方・店舗群・床材・天井を変える。

**C館:** 屋外の中庭を回る曲線・分岐路と独立棟。屋内モールのB館と同じ直線廊下を繰り返さない。屋根付きアーケードやテラス、植栽、屋外階段、上下の眺めを設ける。5階層はゲーム用に存在するが、階によって開放範囲・用途を変えてよい。

## 6. 42探索区画の考え方

区画数目標：A=12、B=18、C=12。**区画は矩形のグリッドではなく、吹き抜け／売場群／回廊のまとまり**で定義する。300人では連結した3〜4区画、1000人では連結した9〜12区画、5000人では全域。小モードはあらかじめテスト済みの複数の連結区画セットから毎回抽選。

境界は建物端、自然な閉鎖区画、改装仮囲いなどで表現。必要最小限のシャッターを使い、透明バリアは使わない。閉鎖先に行ける経路、届かないNPC、取れない宝箱を残さない。

## 7. 実装の優先順位とレビューの提出物

1. **現行マップとの差分分析**。スクリーンショットと既存座標を調査し、残すもの／作り直すものを一覧にする。
2. **全体配置の2Dマスター図**。3館、連絡橋、入口、外構、主要動線を座標付きで提出。
3. **B館1F→2F→3F** の歩けるグレーボックスを先行実装。3広場、吹き抜け、上り下りエスカレーターを実移動で確認。
4. B館の店舗ユニット・トイレ・サイン・フードコートを作り込み。
5. A館の三角回遊＋中央吹き抜け、C館の屋外回遊を実装。
6. B1/RF、連絡橋、ナビゲーション、マップUI、NPC経路を統合。
7. レンダリング・LOD・シーン分割・カリングを調整し、多数NPC負荷を測定。

### Codexの各段階の提出義務

- フロア別の上面図（入口、全通路、全店舗、トイレ、吹き抜け、エスカレーター、階段、エレベーター）。
- 代表位置のゲーム内スクリーンショット（プレイヤー視点）。
- 寸法表、店舗数、各階移動手段の一覧。
- プレイヤーがA/B/C全館の各階へ移動できる動作確認。
- スクリプトやシーンの変更一覧、残る問題、次に必要な対応。

## 8. 合否判定

**不合格:** 見た目が小さな商店街、全フロア同型、箱状の店舗だらけ、エスカレーターが壁際にのみ存在、吹き抜けの床が埋まっている、階層の接続が不自然、行けない店舗やエリアがある。

**合格方向:** どの広場から見ても上下3階のつながりが分かる。大規模モール独特の距離感と視線の抜けがあり、複数ルートで目的地に行ける。店舗・トイレ・階層・館が実際に歩いて探索できる。

## 10. Codexへの依頼文

この設計書と添付のSVG図面を優先して、**まずマップの骨格を改善してください。** いきなり全館を装飾するのではなく、現状との差分・実装計画を提示した上でB館の1〜3Fの主要通路と吹き抜けを動作可能な状態にしてください。図面にない細部は建築的に自然な設計案を考案してよいですが、重要な構造と確定仕様を勝手に変更しないでください。
