# 次工程：B館の骨格改修

2026-10-25。0.19時点の状況整理と次の実装範囲。**以下は未実装の計画で、配布マップの変更報告ではない。**

現在の形を完成形にはしない。0.17〜0.19は店舗用途・トイレ・看板・商品・素材を更新したが、建物外形と通路の骨格は従来のまま。実装済みはA館5層、B館3層、C館1層の9/15フロア。先に作成した構造案をゲームへ反映する工程が残っている。

## B館を最初に変える

![B館の構造検討図・未実装](images/mall-b-floor-study.png)

この図は[既存の寸法検討](MALL_PHASE1.md)で作成した設計案。実施設の実測図でもゲームの現状図でもない。300×180mの計画枠は仮値で、既存A/C館への接続と歩行距離を確認して詳細寸法を決める。

| 現在のB館 | 改修する構造 |
| --- | --- |
| 一本の長い直線通路 | 斜めの主回廊と湾曲する副回廊。両方が広場で合流し、別経路を選べる |
| 両側に等間隔の店舗列 | 中央に店舗島、外周に大小の店舗、端に目的地となる大型店 |
| 広場と分岐が少ない | 光・時・翼の3広場を節として配置し、床・天井・採光で区別 |
| 上階も同じ形と店並び | 1Fは服飾/スポーツ/食品、2Fは書店/雑貨/カフェ、3Fは映画/体験/飲食を中心に区画を統合・分割 |
| 細い中央開口と横断橋 | 1〜3階を見通す吹き抜け、周囲の上階回廊、広場に接続する上下動線 |
| 長い橋が通路へ直結 | 2Fの到着ロビーを設ける。A館への既存接続を維持し、C館2F接続の位置を確保 |

3広場の名前、通路幅、大型店の用途は既存案の仮設定。新しい確定仕様に昇格させず、床の収まり・混雑・探索距離で調整する。添付kaze図で確認できないmori/OUTLET全体を再現済みとは扱わない。

## 実装の順序

1. **接続と床を先に決める。** A/Bの1F・2F、B/Cの1Fを維持する接続端点を図面へ重ねる。主回廊、副回廊、店舗島、3広場、上階開口、上下コアを一つの定義へまとめる。空白を放置せず、売場・設備・バックヤード・屋外へ区分する。
2. **B館1〜3階を家具の少ない状態で組む。** 実際に分岐し、回って戻れる床を作る。2/3階の床を開け、広場の上に上下の視線が通ることを確認する。見た目だけ曲げ、経路を旧位置へ残す改修は行わない。
3. **既存データを配置し直す。** 店舗IDと役割を対応させ、店員・着席客・歩行者、什器、照明、看板を新しい区画へ配置する。案内図・18移動地点・宝箱候補・猫の接近経路も更新する。人数と本物の抽選・スキャン仕様は維持する。
4. **保存マップを再生成し、同じ場所で比較する。** 俯瞰の平面、広場から上を見る画角、上階から下を見る画角を旧版と並べる。地図だけ変えた状態や一店舗の展示シーンを、新構造のゲーム画面として提示しない。

## 公開前の確認

- 主回廊と副回廊を通常歩行で一周でき、各店・上下階・館間接続を往復できる。手すりと床開口の衝突が見た目と一致する。
- NPC経路と猫の接近位置が新しい壁・什器と整合する。未到達のNPCや、猫だけが壁を抜ける経路を残さない。
- 宝箱10個を到達・開封可能な候補へ配置できる。移動地点は足場と頭上空間を確認し、訪問前ワープは禁止を維持する。
- 案内図の外形・分岐・吹き抜け・現在地が新しい床と一致する。
- 300人で機能と描画を確認する。クラウドのソフトウェア描画をユーザーのRTX実機FPSとして扱わない。5,000人対応は別の検証工程。

その後、A館の第2回遊路と広場、C館の街路・複数中庭、B館地下/屋上とC館の不足4層を段階的に進める。[全15フロアの用途案](MALL_REDESIGN_PROPOSAL.md)は引き続き計画であり、現在の配布物には含まれない。
