- 時計による動作停止、カートの速度上昇、効果切れ、バッグ中の時間停止と消費禁止。バッグの説明が4列のカード幅に収まること。
- 全域ソナーが移動追従しないこと。超連鎖弾・ブラックホール・天井レーザー・ディスコは1個を消費し、本物を検出しても落下・自動クリアしないこと。アイテム不足時の再使用を拒否。
- 磁石で読書客が移動し、終了後に定位置と着席ポーズへ戻ること。開始時の本物IDが変わらないこと。再プレイで在庫・効果・吹き出しを初期化。

### 維持する基本ルール

初期スキャナーは単体・2秒・6m。実入力で1.8秒では処理せず、2秒超で1人のみ処理。ボタンを離す・対象切替・壁・距離・メニューで途中ロックを破棄。銃購入前の装備・射撃を拒否し、購入後の5発・弾倉・リロード・壁遮断を検査。貫通は3人まで、連鎖は8人・5m間隔・壁で停止・再使用20秒。二段ジャンプの購入条件と着地回復。猫・銃・範囲は本物の通知だけで、最初のスキャナーによる2秒だけが勝利できる。勝利後も残りNPCを消去しない。

5,000人の状態管理と4,999人の処理、本物IDの不変、重複APの防止、最初の1人で本物を発見できること、10,000 seedでの大きな抽選偏りの検知。これは5,000人の描画試験ではない。訪問前・購入前のワープ禁止、訪問後の移動とランの初期化。日本語表示に使用する文字のフォント収録も検査。

## 画面と配布

0.8のLinux release exportから、B館の吹き抜け・家電売場・映画館・生活用品売場、A/B連絡通路・階切替案内図・画質設定を実描画で確認。0.7の記録として、地下食品街・屋上庭園・西駐車場・西側階段・10地点の案内図を実描画で確認。従来の湾曲通路・3層吹き抜け・人物・バッグ等の画像は0.6の記録も保持。画像は`docs/screenshots/`。`--capture-mall`、`--capture-annex`、`--capture-b-wing`は開発用の撮影オプションで、カメラを各階へ移動する。通常プレイに正解位置を移す処理は追加していない。3階への通常移動は別途、物理テストで検証している。

バイナリとソースのZIPはCRCを確認。ソースZIPには`.godot`・`.git`・ゲーム用EXE/PCK・仮想環境を含めない。別フォルダーへ展開したソースをGodotで新規インポートし、ヘッドレス起動を検証。Linux配布ZIPも別フォルダーで起動を検証する。Windowsはrelease exportでのクロスビルドであり、Windows実機での起動確認ではない。公開ZIPはGitHubから取得したものとローカルのSHA256を照合する。

ダミー表示のVSync変更不可警告は既知。0.8の一部ヘッドレス回帰テストでは終了時にAudioStreamWAV/AudioStreamPlaybackWAVのObjectDB残存警告が出た。0.10でも一部の終了時に同警告が再現した。アサーションは成功し、通常の短時間起動では再現していないが、実スピーカーと長時間の音声終了処理の確認は残る。GPUの実機FPS、実際のプレイヤーの操作感、実スピーカーの品質を保証しない。

## 未検証・既知の限界

現版はA館の5階層と西駐車場、B館1〜3階・C館1階と接続通路・300人。B館地下/屋上とC館の残る階層は今後追加する。距離LODと静的描画の空間分割を導入したが、5,000人の実描画・15フロア・平均3時間の実プレイは未検証。

車は静止した簡易モデルで、運転や車両交通はない。屋上と駐車場は限定した開発用区画で、全建物の外装や都市全体の再現ではない。西側階段は見える段の下に滑らかな斜面衝突を使用する。

上階の店舗は1階の再利用。各店舗固有の間取り、搬入と避難動線、上下それぞれの専用エスカレーター等は今後改善する。今版の斜路は上り方向へ動き、歩いて下りることもできる。群衆回避は未実装で、人が重なることがある。店員・買い物・読書等の役割は固定で、商品売買や施設利用のAI、音声会話や分岐会話はない。人物は頭/髪/手のGLBと連続変形する衣服メッシュを共有する構成。髪や衣服の細かな造形、自然な表情、精密な指のアニメーションは制作途中。『8番出口』やペルソナ5相当の品質に達したとは扱わない。

Windows実機、実GPU、異なるDPI/縦横比、Steam Deck/Steamworks、コントローラー、実スピーカーは未検証。写真顔生成、セーブ、キー割当、音量・アクセシビリティ等は販売前に必要。

EXEは未署名。Smart App Controlへの署名対応は解決しておらず、保護機能の無効化は案内しない。公式Godotで開くソース版も配布する。WindowsのポリシーによってはGodot自体も制限され得るため、許可を保証しない。
