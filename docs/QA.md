# 開発版0.1の検証記録

## 環境

Godot `4.6.3.stable.official.7d41c59c4` Standard、Linux x86_64、Compatibility renderer。画面検証はXorg dummy displayとMesa llvmpipeソフトウェアOpenGL。GPU実機性能の結果ではない。音声はDummy出力で、実スピーカーの聴取確認はしていない。

ゲームソースの作成はユーザーの開発指示に基づく。元リポジトリはコミット・ファイルがない状態だった。既存ソースの上書きは行っていない。GitHubでの配布はユーザーの公開許可に基づく。

## 実施済み

- `bash tools/setup_cloud.sh`：固定NumPy仮想環境の準備、Godot import、テスト完了。書込み不可のホーム設定ディレクトリはXDG_CONFIG_HOME/DATA_HOME/CACHE_HOMEを`/workspace`内に指定して解決。再実行でも依存やソースを書き換えない。
- `godot --headless --script res://tests/test_game.gd`：**68チェック、0失敗、終了コード0**。音声停止後にmixing threadの解放を待ち、テスト終了時の一時リソース警告も解消。
- 実際の入力アクションでのプレイヤー移動と壁衝突、物理空間への照準レイ、5発射撃による偽物確定、弾薬消費と1秒リロード。
- NPC全経路点の連結性、120人分の当たり判定、MultiMesh全描画部位のメッシュ割り当て。
- 5,000人状態で4,999人を特殊スキャンし、重複処理でAPを増やさないこと。本物IDが変わらず、本物を落下させないこと。
- 特殊スキャンと猫は本物を通知して勝利させず、通常銃5発でだけ勝利する。1人目が本物でも勝てる。他NPCを勝利時に消さない。
- AP不足・不明スキル・最大強化・猫強化の前提条件・累積価格。
- 壁の向こうも検知するソナー、移動を追従しない位置配列、クールダウン。
- 猫が対象へ接近する前に遠隔スキャンしないこと、20秒のスキャン完了経路。
- ポーズ中の時計停止、Escでの再開、新規ランのAP・本物通知・猫・弾薬リセット。
- 10,000 seedで正解選択の10分割区間に大きな偏りがないこと。乱数選択自体は`randi_range(0, population - 1)`の一様抽選。統計チェックだけで乱数品質の証明をした扱いにはしない。
- 100,000試行の設計試算完了。同じNumPy版・seedで再実行し、JSON結果の完全一致を確認。
- Linux / Windowsのrelease export成功。実行形式はELF64 x86_64 / PE32+ x86_64。
- Linux配布ビルドのheadless起動成功。配布ビルドからもタイトル→ゲーム開始→スキル画面を実描画し、スクリーンショットを取得。元ソースを必要とせずPCKから起動。

描画時のVSync変更不可警告はdummy displayによるもの。クラッシュやスクリプトエラーはない。アプリの速度やフレームレートの製品保証には使用しない。

## ビルド素材の検証

公式 `godotengine/godot-builds` の `4.6.3-stable` からexport templatesをHTTPSで取得。公式 `SHA512-SUMS.txt` とアーカイブ全体のSHA512を一致確認してからLinux/Windows x86_64 release用だけを展開した。TLSやハッシュの検証を無効化していない。

```
da606b61c10157844f8300172df374472665f95015495cb1a7cd132c40ede404faa96cc1016a4b9662db9909ddea69632c4948b2cd11163438dad4808881fb68
Godot_v4.6.3-stable_export_templates.tpz
```

ゲーム配布ZIPにはPCKとGodotライセンス・第三者著作権表示を同梱。ZIPごとのSHA256は`builds/SHA256SUMS.txt`に記録。

## 未実施・既知の限界

Windows実機での起動・入力・描画・音声、Steam DeckやSteamworks、実GPUでのFPS・フレーム時間、全画面・異なるDPI/縦横比、コントローラーは未検証。5,000人の実描画性能と15フロアの到達性、実プレイヤーの平均3時間も未検証。セーブ・顔写真・宝箱等の未実装機能はテスト対象外。

現在のNPCは互いの衝突・群衆回避を行わないため、通路や店舗先で重なる場合がある。行動は歩行と待機に限定。天井の照明と影、キャラクター形状、UI、武器は開発用。マウス感度・音量・キー割当・日本語UI・セーブは販売前に追加が必要。

環境の`install_script`と`start_skill`はドラフト保存済み。ユーザーによる設定の保存・環境の公開、新規タスクでのスナップショット復元を確認したわけではない。
