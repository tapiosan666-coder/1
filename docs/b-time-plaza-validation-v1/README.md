# FIND YOURSELF — B館「時の広場＋周辺店舗街」独立3D検証 v1

本プロジェクトは敷地全体設計v3の確定候補座標を用いた、ゲーム本体と独立した建築検証です。
元のゲーム、NPC、スキャン、AP、セーブ、設計原本を読み込んで動作させたり、上書きしたりしません。
本体への統合は未実施です。ユーザーの画面確認・承認を待ちます。

## 開き方

1. ZIPをすべて展開します。
2. Godot 4.6.3のプロジェクト一覧から、このフォルダーの `project.godot` をインポートします。
3. 素材の初回インポートを待ち、F5で実行します。Pythonのインストールはプレイに不要です。
4. WASDで歩行、クリックしてマウス視点、Shiftで速歩、Escでマウス解除。1/2/3は検査用の階移動です。

階移動キーは検証用です。実際の上下移動は、時の広場西側の1⇄2F、東側の2⇄3Fのエスカレーターを利用できます。
本プロジェクトを既存ゲームにコピーして実行しないでください。別プロジェクトとして開きます。

## 設計との対応

- 1 Godot unit = 1m。元世界座標の X=-429, Z=46 を検証シーンの原点とします。
- 切出し: 世界 X=-512〜-349、Z=-16〜124（163×140m）。1F=0、2F=5.525、3F=10.875m。
- 80店舗区画が切出しに交差します。範囲外には続きの店舗・通路があります。すべてが独立した完成店舗という意味ではありません。
- 元の床・店舗境界・入口・吹き抜け・横断橋・エスカレーター位置を取り込みました。
- 設備核（階段・EV・トイレ内部）は今回の検証対象外で、元の外形に沿って閉鎖しています。閉鎖設備帯は立入り不可の代理ボリュームです。
- 境界にある閉鎖面は検証範囲の終端です。館全体の外壁ではありません。
- 新規の柱、トップライト、素材・意匠、店舗内の造作は、この検証シーンでの提案です。設計原本へは反映していません。
- 店舗の架空ブランドは意匠検証用。実在店舗のロゴ、FF15の資産、他ゲームのメッシュは使用していません。

## 作り込みと残課題

床版の厚み、吹き抜け床端、石床目地、巾木、枠付きガラス、実際に開いた店舗入口、造作棚、商品、天井パネル、間接照明、給気スリット、スプリンクラー、ガラス手すり、金属笠木、エスカレーター側板・くし板・踏段、トップライトを組み立てています。
平面床は穴を保持して三角形分割しており、四角い床を重ねて穴を隠す方式ではありません。

3Dで判明した差分として、出発階のエスカレーター下に残った床欠落を、検証シーン内のみ4区画（各35.52㎡、計142.08㎡）補っています。到着階の開口は保持しています。`source/scene-manifest.json` の `isolated_slab_additions` に位置と面積を記録しました。これは設計反映の確認が必要な変更案です。

描画品質は**FF15級の完成品質には未到達**です。現段階は建築構造と素材の方向性を判断するための初回スライスです。反射プローブ・ベイクGI・高品質間接影・写真由来のPBR素材・店舗ごとの完成内装・汚れや端部の微細な造作・完成照明・最終LODは未施工です。
ガラスは着色透過近似で、屈折・二重反射を再現していません。エスカレーターの踏段は静止表示です。衝突用連続勾配とベルト搬送は実装していますが、実機相当の循環アニメーション・機械制御は未実装です。

## 検証方法と限界

`evidence/walk-results.json` はGodot CharacterBody3D（半径0.30m、高さ1.80m、60Hz）を実際に動かした結果です。経路の途中でテレポート・座標投影はしません。各テストの開始地点設定は行います。
店舗入口、共用通路、4基の上下歩行、自動搬送、吹き抜けの転落防止、床開口と横断橋のレイ検査を含みます。自動操作による物理検証であり、人間によるWindows上のプレイテストとは区別します。入口は中央を通るカプセルの通過を確認し、入口全幅の実測・全配置からの接近・店舗内全位置の網羅は未検証です。

描画はクラウドのMesa llvmpipe（CPUソフトウェア描画）、OpenGL Compatibility、1280×720、MSAA4x、Godotエディタ付属の実行バイナリで実測しています。Releaseエクスポート版は未測定です。NPCは0人です。RTX 4060でのFPSや5,000人時の性能へ換算しません。`render-results.json` の生フレーム時間と測定条件を参照してください。
1F・2F・3Fの主要3視点はウォームアップ12フレーム後に30フレーム、移動は60フレームを計測します。残りの視点は画面確認用でFPSの測定対象外です。短時間のサンプルであり、長時間負荷・温度・ロードの実測ではありません。
1/2/3のワープキーを使わずに上下移動できるかは、物理検査のエスカレーター結果を参照してください。

## 再現

Godot 4.6.3で実行:

```
godot --path .
godot --path . -- --capture
godot --headless --path . --fixed-fps 60 -- --walk-test
```

スクリーンショットはGodotの実ViewportからPNG保存し、生成AIや画像加工を使っていません。
`authoring/build.py` は制作・再生成専用。元リポジトリとShapely 2.2、NumPy、Pillowが必要です。配布データは生成済みであり通常実行では不要です。
`authoring/verify_geometry.py` は生成済みの衝突三角形を元の確定候補データと独立比較します。`evidence/` に検査結果、画面、測定値を保存しています。
