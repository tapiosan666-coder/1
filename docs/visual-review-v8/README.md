# FIND YOURSELF｜v8 代表3エリア・映像品質確認版

**独立したGodot 4.6.3検証プロジェクトです。既存ゲームには統合していません。全館完成版ではありません。**

今回の仕上げ範囲はA館1Fの西側広場～専門店街（16店舗）、B館1F「時の広場」周辺（19店舗）、C館1F南西店舗街～中庭周辺（7店舗）です。42店舗の外観・什器を業種別に更新し、床材・天井・照明・植栽を追加しました。他の階・売場・駐車場はv7の構造検証段階を残しています。FF15級の完成品質に達したとは評価していません。

## 起動と操作

Windows版はZIPをすべて展開し `FIND_YOURSELF_v8.exe` を実行します。ソース版はGodot 4.6.3で `project.godot` をインポートし、F5で起動します。初回はメッシュの読み込み・シェーダー準備に時間がかかります。

- WASD：移動、マウス：視点、クリック：視点操作開始、Shift：速歩、Esc：カーソル／UIを閉じる
- F1：A館代表エリア、F2：B館「時の広場」、F3：C館南西店舗街（検証用の位置移動）
- F：近くの扉、またはEV行先パネル。別階のかごは現在階へ呼び出し、乗り込んで行先を選択
- M：館内マップ。館・階の切替は表示のみ。マップ表示中は移動を停止
- F10：画面設定。初期1920×1080・144FPS上限・VSync ON要求。1440p／4K、30・60・120・144・無制限に対応し、設定を保存

物理更新は60Hzです。初期設定はFPS目標値であり、144FPSの実測達成を意味しません。Windows実機、RTX 4060、Smart App Controlの通過、人間による操作は未検証です。Windows版は未署名です。

## 映像と範囲

Forward+（Vulkan）を基本とし、SSAO・SSIL・SSR、オリジナルの表面色／法線／粗さマップ、局所照明を使用します。Vulkanが使えない場合はGodotのCompatibilityへのフォールバックとなり、反射・陰影の一部が異なります。添付のFPSは実際の計測環境・サンプル数を参照してください。

42店舗を含む代表エリアのみの仕上げです。A/Cの他階、核店舗全体、駐車場の仕上げ、完全な厨房・全商品・最終看板デザイン、建築照明の最終調整は未完了です。ブランド480件に異なる仮店名とオリジナルの図案を用意しましたが、今回の実装対象外の438店舗に最終看板として展開していません。実在ロゴは使用していません。架空名の商標クリアランスは未実施です。

RF-SUPPORT-16は未承認のままです。構造安全性・車両の全旋回軌跡など、v7の未検証事項は継続します。建築図面の合格を、映像品質や人間の実操作の合格とは扱っていません。

## 制作データ

`source/site-v7.json`・`design-v7.json`・館間接続・駐車場・昇降設備は保持。`authoring/dress_v8.py` が既存区画／保護経路から42店舗の仕上げを生成し、`material_maps_v8.py` がオリジナルPBRテクスチャを生成します。`filter_base_v8.py` は対象店舗内の旧什器と対象範囲の箱型植栽だけを除去し、床・区画・開口を変更しません。壁の高さ4.6mと階高の不整合で生じていたA/C等の壁上端の隙間は、同じ壁の頂点を既存スラブ下面へ接続して修正しています。`pack_mesh_v8.py` は面数を落とさずfloat32バッファで配布容量を削減します。

再生成：`dress_v8.py` → `material_maps_v8.py` → `landscape_v8.py` → `filter_base_v8.py` → `pack_mesh_v8.py`。Python依存はNumPy、Shapely 2.2、Pillow。生成済みのファイルを同梱しており、通常の起動にPythonは不要です。メッシュ内装は店舗・材質ごとのバッチにまとめ、仕上げの遠距離描画と局所照明に距離制限を設けています。建物構造をFPS目的で削除していません。

比較用コマンド（ソース版）：先に比較ZIPの `comparison-data/assets` にある2ファイルをプロジェクトの `assets` へコピーします。通常のv8起動には不要です。`godot --rendering-method gl_compatibility --path . -- --v7-visual --capture --output=<出力フォルダー>`。v7保存データのfloat32メッシュ、元の素材・照明を使います。v8は `--capture`、実描画FPSの計測は `--benchmark-v8`、対象店舗の自動歩行は `--headless --fixed-fps 60 -- --walk-v8`。固定FPSによる自動歩行を実描画FPSとして報告しません。

## 今回の見た目の評価
素材・陳列密度・天井器具・植栽・看板の変化を実画面で確認しました。ただし、商品・機器には簡略形状が多く、広い天井と長い壁の単調さ、店舗ごとの固有性、間接光・反射の精度は未完成です。代表42店舗への追加を全館の完成とは扱っていません。

FPSは各エリア8フレーム、約41〜55秒のソフトウェアGPU参考計測です。実GPUの性能は推定していません。停止が混入した初回計測は破棄し、他の検証・圧縮処理終了後の計測値だけを採用しています。
