## 再検査と限界
- 旧v4検査7,810項目を修正版JSONに対して今回再計算。図面の生成・店舗の自動廃止処理は実行していない。
- 追加検査を含め8,377項目、合格8,377・不合格0。共用床と閉鎖帯は全階の計算値0㎡。閉鎖帯/開口の追加判定許容は1e-8㎡。
- 補完の主要成分は各階同じ2箇所。CSV/GeoJSONには数値許容未満の浮動小数点成分も省かず記録。
- 浮動小数点のため他の界面に1e-13～1e-18㎡程度の残差がある。新しい許容は施工上の重複・隙間の許可ではない。
- 既存の店舗/共用床界面は従来基準0.06㎡を保持（最大約0.006318㎡）。店舗区画と入口を勝手に変えていない。店舗間交差0.02㎡、店内経路0.025㎡も従来通り。すべての意図的な図形交差が数学的に0という主張ではない。
- 主188＋副3の店舗入口、設備・乗降口、全店舗から階段核への経路を確認。1m格子と正確な線分判定を使用し、共用歩行域に半径0.45mの余裕を取る。Godotで歩いた結果ではない。
- 元v4、前回最終確認資料とゲームのファイルは維持。今回の新規ファイルはdocs/downloads/toolsの設計用だけ。
