# FIND YOURSELF｜統合品質検証 v14

[単独GodotプロジェクトZIP](../../downloads/FIND_YOURSELF-v14-Combined-Godot.zip) / [v13を全文収録した統合報告PDF](../../downloads/FIND_YOURSELF-v14-Combined-Review.pdf)

Godot 4.6.3で全展開した `project.godot` を開き、インポート完了後F5。初期表示はB館地下食品売場。F9で今回／前回の確認地点、F8で代表店舗、Mで館内マップ、F10で設定を開けます。Windows EXEと分割ZIPは含みません。

建築15層・480店舗IDと移動機能を保持し、共通の床・壁・天井仕上げ、7種類718配置の売場／ベンチ、既存屋上植栽帯を改善しています。ゲーム本体には未統合です。

`source/v14/` に保護対象とのハッシュ比較、モデル置換と旧寸法、植栽の配置実績と支持範囲、GIキャッシュの検証用データを収録。`tests/` は今回の自動経路追従・W/F入力・メニュー等の再検査です。`screenshots/` は実際のGodot Viewportから取得した1920×1080 PNGです。

全店舗の最終美術完成やFF16級品質ではありません。人間の実操作、Windows GPU FPS、構造耐力・避難性能の認定は未実施。RF-SUPPORT-16、C館構造別案、敷地への連続ES移設は未承認です。局所反射プローブは描画安定性のため既定OFF。元の店舗素材参照を保持し、複製・一括加工は撤回しています。
