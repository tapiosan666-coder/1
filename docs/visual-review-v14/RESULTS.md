# v14の結果と残課題

今回の変更は独立検証プロジェクトのみ。既存のスキャンゲーム本体を変更・統合していません。建築・衝突18パック、プレイヤー／ES／EV／扉／設定コード、v13の設計データの合計54リソースは原本と同一です。

- 共通仕上げ：Aの石材、Bのテラゾー、Cの舗装、壁・天井・タイル・木材の描画を更新。
- 売場：食品ゴンドラ、青果台、冷蔵棚、健康用品棚、書店両面ゴンドラ2種、植栽付きベンチの7種類718配置を専用モデルへ置換。旧AABBへ収め、旧衝突を維持。
- 屋上：既存18区画のうち、槽の全範囲で支持床を確認した17区画に縁・土・衝突を備えた植栽槽と168点の植物を設置。BRF-GARDEN-2-BED-4 は4.0×1.4m中3.57㎡の支持床が確認できず槽ごと除外。元の178植物候補からは、直接の床未検出6点に加えて同区画内の4点も見送り、計10点を未設置としています。構造耐力の証明ではありません。
- 台帳：`roof-planting-as-built.json/csv` に178候補・168実配置・10除外、17実施工槽と1見送り槽を分けて記録。
- 照明：現行素材に合わせてGIを再ベイク。コード・素材・配置・地形パックと一致するキャッシュだけ使用。ベイク時のShaderMaterialは一時的なStandardMaterialへ変換し、表示用素材は復元。
- 描画の安定化：インポート素材の複製・一括加工を撤回し、元の素材参照を維持。局所ReflectionProbeは既定OFF。SSR・SSIL・既存店舗照明は維持。複製と各パラメータのどれが引き金か、プローブとの相互作用の完全な原因分離は未完了。

物理試験は今回の形状・衝突を確定した段階で実行。その後に素材・照明を確定し、既存の植栽計画区画に17槽の可視モデルと衝突を追加。影響する屋上経路は別途再検査しています。最終配布候補では初回インポート、通常／C館別案／ESモジュール起動、18幾何パック、7照明キャッシュを別途確認しています。

今回の自動再検査は店舗等945経路、トイレ・地下・屋上のW入力738経路、EV119件、ES40件、Fキー扉300枚、マップ／メニュー26項目が合格。設計上の占有域、物理キャリア、自動経路追従、実際のキー入力、画像の見た目はそれぞれ別の検査です。件数を建築・美術の完成判定へ置き換えていません。

比較画像は同じカメラ位置・向き・画角、1920×1080のGodot実画面。前回v13の画像と、今回の最終素材構成を比較しています。撮影は前回と同じ4描画フレーム待機。報告書にはPDF用の画像圧縮のみ行い、原寸PNGを保持しています。
