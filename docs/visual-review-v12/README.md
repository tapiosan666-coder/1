# FIND YOURSELF v12｜独立施設検証

**ゲーム本体には統合していません。全館完成版ではありません。** v11の滑らかなES移動を維持し、床開口の安全柵・床接合と衝突欠落を修正しました。内装は6業種の代表店舗を更新しました。

## 開き方

1. `FIND_YOURSELF-v12-Godot.zip` を**新しいフォルダへ全部展開**します。分割ZIPではありません。追加データのダウンロードや他版からのコピーは不要です。
2. **Godot 4.6.3 Standard**で、展開した `FIND_YOURSELF-v12/project.godot` をインポートします。
3. 初回の素材インポート完了後、F5で起動します。Python・Blenderは通常起動に不要です。Windows EXEは含めていません。

- WASD／マウス：移動・視点。Shift：速歩。Esc：カーソル。
- F：扉、EVの呼び出し・かご内の行先選択。
- M：館内マップ。開いている間は移動停止。F10：画面設定。
- F1：A館、F2：B館、F3：C館の代表地点。
- **F4：原配置と「C館構造別案・未承認」を切替**。切替時はシーンを再読込します。
- **F7：独立した5層ES乗継ぎ検討シーン**。F4で全館検証に戻ります。各館への移設は未実施です。
- **F8：更新した6業種の代表店舗を選んで確認**。内装の変更箇所へ直接移動できます。
- 初期1920×1080、144FPS上限、VSync ON。物理更新60Hz。設定は保存されます。

## C館別案とES乗継ぎ案

C館は2F・3Fの中央を横切る余剰床とRFの床を整理し、6棟の周辺回廊に接続先を与え、柱梁の視覚的な支持経路を設けた**未承認案**です。店舗ID・売場は維持します。構造耐力・基礎・耐震・避難性能は実証していません。RF-SUPPORT-16も未承認です。

ES乗継ぎ案は、参考写真のように同じ吹抜け脇へ上下各1基×4組をまとめた、B1〜RFの独立構造検討です。中間階の上り・下り乗継ぎ中心線は8.4m。現地の店舗区画や開口へ移植した完成版ではありません。旧配置の遠さと、B/Cの地下・屋上で動くESが不足している問題は、敷地への配置変更として承認待ちです。階段・EVの既存移動は維持します。

## 修正と限界

- 40基の実データから実際の床端を抽出し、意図した乗降口を残して見えるガラス柵・腰壁・金属笠木を追加。必要な箇所だけ小さな床を補完しました。既存の斜面・プレイヤー処理は変更していません。
- 既存ガラス柵の生成層が乗降板の外端まで塞いでいたため、描画・衝突の両方を同じ乗降口形状で切り直しました。乗降板の外から乗り、外へ出る40経路も検査対象です。B館の地下・屋上の未施工12基は案内図を×表示に修正し、実機のない開口周囲に見える安全柵と案内を設けました。
- 全480店舗の境界を点検。売場階など458店舗では描画・衝突を照合し、4店舗・8測点の衝突欠落を、既存の見える壁と同じ面で修復しました。これは全店舗の美観完成を保証する検査ではありません。
- 屋上22区画では通常の店舗壁に相当する境界を検出できず、屋外売場としての意図／未施工の区別を個別に確定していません。通常店舗の境界合格には含めず、囲いを無断新設していません。設計データに残る外壁際・管理帯の用途確認も残っています。
- アパレルC1F-CW-1、生活雑貨A1F-005、美容B1-030、書店A1F-007、家電B1-N03、カフェC1F-CSW-3を試行施工。入口・売場・壁面・レジと通路を区別。全480店舗への展開は未実施です。
- 自動経路検査、Wキーを送る実コントローラー検査、Godot Viewport画像を使っています。人間による操作は今回実施できていません。ユーザーが確認したv11の滑らかなES移動は、コードを保持し再検査しています。
- 描画はLinux llvmpipeソフトウェアVulkanで確認。Windows GPUの実測FPSはありません。144FPS達成やFF16級の品質は主張しません。

比較画像・図面・検査記録は別添Review ZIPにあります。検証プロジェクトはこのZIPだけで起動できます。

C館別案の生成では、各階に属する設備だけを床保持条件に使い、RFの用途のない孤立床38.01㎡を除去しました。店舗の全高ガラスと低い安全柵を分類し、店舗ガラスを誤って切除しない条件へ修正しています。別生成の舗装も残存床へクリップし、浮いた舗装を除去しています。乗降板外端には既存の水平衝突床に沿う金属仕上げを追加しました（衝突追加なし）。
