# FIND YOURSELF v12 独立検証・確認資料

ゲーム本体とv11原本には未統合。全館完成・FF16級品質・構造安全の達成を意味しません。

## 今回の修正

- ES40基の床開口を可視の腰壁・ガラス柵・笠木で保護。複数生成層の柵が乗降板を横断する原因を共通ポータルで修正。外端の金属仕上げは既存衝突床に沿う表示のみです。
- v11のプレイヤー、斜面移動、踏段・手すりアニメーション処理を維持。
- B館地下／屋上の未施工12計画ESを利用不可表示に訂正。未施工開口も可視の柵で保護。
- 4店舗の8測点にあった、見える壁と物理壁の不一致を同じ面で補修。
- アパレル・雑貨・美容・書店・家電・カフェ各1店を試行施工。壁面、中央展示、会計、客席、主要通路を区別。全店舗内装の完成ではありません。

## 承認待ちの別案

C館：余剰上階床・舗装を整理し、6棟の周辺回廊、柱梁を設けた別案。売場と店舗IDを維持。床の保持条件を階別設備に限定し、RFに誤って保持した孤立床38.01㎡を除去。全高店舗ガラスを低い柵と混同しない生成条件へ修正。構造耐力・基礎・耐震・避難性能は未実証です。

ES：ユーザー提供写真を参照し、同じ吹き抜け脇で上下各1基×4組を接続するB1～RF独立モジュール。中間階の設計中心線8.4m。敷地への移設は未施工であり、各館の実際の乗り継ぎ距離が改善したとは報告しません。

F4：C館別案切替、F7：5層ES検討、F8：代表6店舗。通常起動にPython/Blenderや別ZIPは不要です。

## 実画面・性能

画像はGodot 4.6.3 Forward+の1920×1080 Viewportです。beforeはv11、afterはv12、カメラ位置・向き・FOVを一致させています。簡易レンダラーやBlender画像ではありません。描画環境はLinux llvmpipeソフトウェアVulkan、CPU上限4相当。GPU実機の性能を表しません。Windows GPUの実測FPS、人間による手動プレイは未実施。144FPS上限設定を維持していますが144FPS達成とは主張しません。終了時のTexture RIDリーク警告は一部のソフトウェア描画実行で残っています。
