# B館：区画・境界・3D生成の共通契約（v3修正案、未承認）

原本：B館v4.1／敷地全体設計v3。既存ゲームと原図は不変更。独立シーンは**未完成の修正案比較用**です。

## 原因

- `tools/design_b_v4.py` は店舗・通路等を包む外郭BODYを膨張・収縮・簡略化で作り、差分を `residual` として残す。多くの残余には用途・扉・設備仕様がない。
- 店舗・通路・設備核を個別に差し引く処理が、細長い片、鋭角、分離した片を生む。店舗全体の入口到達性だけでは、各売場・在庫片の入口欠落を検知できない。
- v2の3D生成は構造床を外郭全体から作る一方、名前のある共用倉庫などだけを閉鎖し、残余は用途のある構成へ仕上げていなかった。床支持・指定経路の合格では未割当床の品質を保証できない。
- `nav_free` は共用通路のマスクであり、売場も対象外になる。off-navという理由だけで立入禁止・必要な設備空間とは判断しない。

## データを設計する順序

1. 広場・吹き抜け・昇降設備・館間接続と、必要幅を持つ客用／搬入／保守経路を用途付きで確定する。
2. 店舗を「入口・間口・有効奥行き・売場・在庫・専用扉」の組として設計する。区画だけを置いて残りを廊下にしない。
3. 隣接区画間の壁は一つの共有境界として扱う。片側だけのsimplifyや、別々のオフセットでずれを作らない。
4. 曲線、柱型、入口セットバック、設備前室を意味付きの部材として保持する。不要な短辺・鋭角は隣接区画と同時に修正する。
5. 外郭は上記の用途計画と整合させる。外郭演算で余った三角形を、根拠なく機械室・在庫・従業員通路と呼ばない。
6. 部屋・売場・在庫は、それぞれ専用の入口または明示された内部接続を持つ。入口を持たない片を利用可能面積へ計上しない。
7. 細い納まり用のふところは「非居室」として区画所有者を明記する。通路・売場・有効倉庫床へ算入しない。
8. 同じ確定済み区画・開口・床レベルから表示／衝突／案内図／移動データを生成する。未承認案と原本を混ぜない。

## 実装したゲート

`authoring/build.py` は、床の用途帰属が未確定のままの通常出力を `PRODUCTION_EXPORT_BLOCKED` で停止する。
`--review-draft` を明示した場合だけ、未完であることを表示する独立比較シーンを出力する。これは完成判定の回避手段ではない。

現在は5階とも未帰属面積が残るため、**通常出力は不合格・停止が正しい状態**。既存の全館形状を修正済みとはしない。

## 今回の区画再生成案

小規模な余剰領域に限り、隣接店と合わせた外郭を直線化し、公共空間・他店・設備・保守経路を同時に制約する。
既存区画を削る案、面積増が100㎡または25%を超える案、有効頂点が3点超増える案、壁長が3m超増える案、他案と競合する案を棄却する。
単純な近傍割当・Voronoi・全領域のconvex hull化は行わない。2mmの簡略化は頂点数の**評価だけ**に用い、実際の区画は共有境界を保持する。
バックヤードの有効部分は既存の専用扉へ接続する部分のみ。幅1.2m未満の片などは非居室へ再分類し、有効床を水増ししない。

これらは候補を棄却するための基準であり、商業施設として自然であることの自動合格基準ではない。画像・見通し・入口リズム・滞在設備・人間の実操作を別に確認する。

## 維持する機能

地下・屋上の命名済み保守通路、駐車場歩道・車路、設備区画、庭園、避難通路を余剰床として誤抽出しない。
1〜3階の既存搬入仕様は、閉館後の共用通路とEVの利用を含む。店裏の隙間を全て従業員通路とみなす根拠にはならない。

## 残る設計作業

広い未割当領域は、店舗街ごとの必要面積・搬入・設備負荷から再設計し、外郭縮減や店舗の奥行き変更を比較する必要がある。
現時点で各階数千㎡の残余を設備需要で説明できない。大きな壁や仮の機械室で隠さない。
本体統合・全館の完成出図は、全域の用途帰属、内部各領域の入口、構造・避難・設備、Godot実画面・人間の実操作を確認した後とする。

## 店舗内部の役割とガラス

- 店舗区画、売場、在庫、非居室の納まり代を別の領域として保持する。在庫面をショーウィンドウへ流さない。
- ガラスと不透明壁の開口切欠きには同じ売場前面マスクを使う。在庫を除外しただけで不透明壁の穴を残さない。
- 各在庫成分には専用扉か明示した内部連結が必要。独立した微小片を在庫能力として算入しない。今回の比較案は売場/陳列へ返す規則で、元売場を減らさない。
- ガラス生成の境界線検査だけでなく、出力メッシュの三角形投影と在庫を独立照合する。80区画の監査結果を保持する。
- 従業員用扉は通常閉の操作可能な扉として扱う。開けた状態で内部が見えないと保証しない。スタッフ専用操作/AI権限は別の実装課題。
- 床開口の所有階を明示し、エスカレーターは到着する上階の勾配部を開口とする。出発床・櫛板・乗降踊り場を機械投影から一括で引かない。
- 昇降設備の移設/増設、店舗統合は承認済み設計と分離した案として保存する。未施工機器を操作可能な設備として案内しない。
