## 調査と設計案

`source/root-gap-review/` にB館B1/1F/2F/3F/RFの全階調査があります。
`issue-register.csv` は516件の問題・確認候補の座標、店舗ID、原因、対応方針を収録します。数値候補すべてを建築的欠陥と断定していません。
5行に集約した微小片の個別座標は `micro-fragment-register.csv` に別表で記録し、件数・面積を二重計上しません。
`GENERATION_RULES.md` は原因と再発防止契約。`refined-enclosure-proposals.json` は6か所の未承認案で、3か所だけが現在の3D範囲内です。

原因は、用途計画と一致しない外郭差分、区画への逐次ブーリアン処理、各内部領域の入口検査不足、3D床と未割当領域の扱いの不一致です。
通常の3D生成は未帰属床が残る場合に停止します。`--review-draft` だけが未完の比較シーンを出力します。
現状では各階の未割当床が残り、**本番出力は停止する状態が正しい結果**です。
6候補のうち、検証範囲内B1-066/B2-022/B3-028で区画自体を再生成。壁の継ぎ足しではありません。原本への反映・本体統合は未実施。

## 検査の区別

- `evidence/root-contract-results.json`：原図の保護・修正案の用途帰属・境界・既存入口保持・通常出力停止の検査。全館の建築合格ではない。
- `evidence/walk-results.json`：実際のCharacterBody3Dを用いた自動物理検査。人間による実操作ではない。
- `evidence/independent-verification.json`：原本・v1/v2の保護、実行版ハッシュ、宣言済みの修正案との整合、床・静的衝突の照合。
- `evidence/before-v1/`・`before-v2/`・`after/`：実Godot Viewport PNG。姿勢・FOVは `source/final-cameras.json`。22/23は既存バックヤード内から撮影し、扉を自動的に開けた検査状態。通常プレイ画面との違いを記録。

図面検査・自動歩行・実画面の評価を分離しています。Windows上の人間の実操作、RTX4060、NPC1000/5000人、全売場の全位置、避難・構造・MEP・設備能力は未検証。
切出しは世界X=-512〜-349、Z=-16〜124（163×140m）。原点は世界(-429,46)。49完全区画は3階合計。B館全体では188区画（1〜3F）。
v1から引き継ぐエスカレーター下床142.08㎡は独立シーン内の案で、原図へは未反映。
エスカレーターの衝突は連続勾配面の近似。AOは静的頂点陰影で、拡散GIではありません。

## 素材と再生成

建築・造作・商品・看板・本・ポスター・数値生成PBRマップは本プロジェクトのオリジナル。実在店舗ロゴ・外部ゲーム素材・写真・HDRIは未使用。
Noto Sans CJK JP はSIL OFL1.1、Godot4.6.3はMIT。原文は `licenses/`。Blender/PyMuPDF等は制作専用で実行バイナリは同梱しません。

制作再現は元リポジトリの固定原図とShapely2.2/NumPy/Pillow等が必要です。通常実行には不要です。
`root_gap_audit.py` → `refine_enclosure_proposals.py` → `build.py --review-draft` → `choose_hinges.py` → `expanded_inputs.py`。
`bake_ao.py`をBlenderで実行し入力ハッシュを検査してgeometry-lit.jsonをgeometry.jsonへ置換します。原本・v2への上書きは禁止。
