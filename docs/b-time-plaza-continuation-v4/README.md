# FIND YOURSELF｜B館 継続検証 v4（ゲーム本体へ未統合）

前回v3の途中だった裏方室・共用倉庫の入口・バックヤードの作業条件を追加調査し、過去依頼46項目を同じ台帳へまとめました。
建築設計B館v4.1/敷地v3と、独立検証v4は別の版番号です。原図・元ゲーム0.24.0・独立v1/v2/v3は変更していません。

## 今回進んだこと

- 既存9室の入口・室内経路が旧B館座標のままだった不具合を発見。輪郭は世界座標で、点だけローカル座標でした。独立データで(-714,-30)mを正しく適用し、二重変換を拒否する型・座標系チェックを追加。
- 前回の「最寄り共用倉庫」の選定は、誤った入口座標を使用しており訂正対象です。`source/followup/all-191-current-area-ledger.csv`を新しい台帳として使用してください。
- 188店舗から同階の共用倉庫の客用通路側入口まで、図面上の経路を再計算。B1/RFの3店舗は同階倉庫なし・垂直搬送未検証。経路が見つかることを搬入・在庫運用の合格にしていません。
- 独立3DではS-1-T（管理・清掃）、S-2-L（共用倉庫）、S-3-T（管理・清掃）の3室を、閉鎖代理ブロックから既存輪郭に沿う壁・不透明扉・内部経路へ復元。管理室を店舗共用倉庫に転用していません。各室の棚10台は仮配置で、容量や仕上げの完成ではありません。配布前に棚板・支柱の衝突不足を修正し、身体の高さで金属衝突を物理レイ検査しています。
- S-2-Tは入口が切出し外なので、閉鎖代理形状を維持。勝手な別入口は追加していません。
- 前回の在庫作業条件56区画を向き・配置刻みも見直して検査。8区画（回転4、刻み改善4）は同じ面積内に作業矩形が収まります。48区画は引き続き検討対象で、配置不能の厳密な証明ではありません。
- 隣接未割当床への24案のうち22案は角数/壁長を悪化させるため不採用、2案だけを未承認候補として保存。売場・店舗境界は一切変更せず、これらの拡張案は3Dに反映していません。

## 検証の区別

- 実Godotの自動物理検査と、図面上の188経路・作業矩形・拡張案を分離。
- 実スクリーンショットはv3/v4の同じカメラ・FOV・1280×720・MSAA4x。新室の内部画像は比較前が存在しないためafterのみ。
- 人間による実操作・RTX4060上の性能・在庫/搬入運用・防火/構造/衛生の合格は未検証。
- NPC0人のソフトウェアGPU llvmpipe参考FPSを、Windowsや1000/5000NPCの性能へ換算しない。
