# FIND YOURSELF — B館「時の広場＋周辺店舗街」総合検証 v2

既存ゲームとB館v4.1・敷地v3・v1検証プロジェクトを保護し、独立したプロジェクトで生成不良と店舗表現を修正しました。本体には統合していません。

## 現在の判定

**生成・通行の修正と、図面変更が必要な問題を区別しています。建築全体の完成判定ではありません。FF15級のリアルさにも未到達です。**

- 既存の床形状・吹き抜け・エスカレーター位置・店舗区画・入口位置は変更していません。
- 巾木と壁の同一面への重複、壁上端の16〜33.5cmの開き、ガラス足元の約10cmの未閉鎖、実際の区画境界に沿わない旧ガラス線を修正。
- v3の外周壁再構築で失われた既存バックヤード間仕切りを、元の売場・バックヤード境界から復元。
- 56か所の既存バックヤード開口に扉を構築。吊り元と開いた葉の干渉を確認し、B1-022・B2-022は壁沿い引戸としました。開口位置・1.6m幅は維持。
- 店舗用途に応じた客席、カウンター、レジ、棚、本、靴、衣服、化粧品、旅行用品、楽器等を制作。完全区画49のうち49区画、交差区画80のうち74区画に什器があります。内装は初回品質であり、全店完成とは扱いません。配置状況は `source/fitout-coverage.csv` を参照してください。
- 原図の細かな折れ、未割当床候補、区画統合案、範囲外のB2-026の分離部分は、**未承認の設計確認事項**として残します。大きな壁で埋めたり、新しい通路を作ったりしていません。

## 開き方

1. ZIPをすべて展開します。
2. Godot 4.6.3で、このフォルダーの `project.godot` をインポートします。
3. 初回インポートを待ち、F5で実行します。Pythonは通常実行に不要です。
4. WASDで移動、クリックしてマウス視点、Shiftで速歩、Escでカーソル解放、Fで近くの見えているバックヤード扉を開閉します。
5. 検証用1/2/3キーで階を選べます。4基のエスカレーターでも上下移動できます。

元のゲームに上書きしないでください。既存ゲーム・セーブ・NPC・スキャン・APを読み込むプロジェクトではありません。

## 検査の区別

`evidence/walk-results.json` は、実際のGodot CharacterBody3D（半径0.30m、全高1.80m）を60Hzで動かした自動操作の結果です。通常経路に加え、入口の左右・中央、店舗内部、売場→バックヤード、閉じた扉、天井、接合部、エスカレーターの移動を含みます。
検査開始時の配置以外に、経路途中のテレポート・到達点の投影はしません。

初回拡張検査の753/854の記録も保存しています。範囲外への誤った試験目標は対象外へ分類し、開いた扉の干渉は吊り元・引戸で修正しました。対象外を合格へ振り替えていません。

`source/expanded-qa-inputs.json` の保守的な自由空間分割は、実歩行結果とは別です。家具予約域＋0.32mを用いた解析で、孤立候補等が残ります。すべてを移動不能と断定していません。指定サンプル以外の全位置、人間によるWindows上の操作、車椅子、混雑、RTX4060での性能は未検証です。

`evidence/independent-verification.json` は原本保護、図面不変、モデルと静的衝突形状、床の幾何比較、実行版ハッシュを照合します。設計確認候補と未検証事項を別ステータスで記録し、全項目を一括合格にしません。

## グラフィックとエスカレーター

素材は数値生成の石・塗装・木・金属・布・革PBRマップ。環境光、店舗の局所光、ボックス投影反射、静的頂点AOを使っています。**AOは拡散GIや光の多重反射の実装ではありません。** 写真由来のスキャン素材・完成ライトマップGIは未使用です。

踏段はインスタンス形状が閉ループを移動し、乗降部で水平になり、内部で反転して戻ります。手すりは丸みを持つ連続形状と、同速度で動くゴム表面。固定くし板は移動踏段の溝に対応させています。表面速度は0.5m/s。
**衝突は歩行の安定性のため連続勾配・乗降面で近似します。各踏段との厳密な剛体接触は未実装です。** この機械的近似は、静的な壁・床と表示位置の不一致とは区別しています。

`evidence/animation/animation-results.json` とMP4は、Godot実Viewportをシミュレーション時刻8Hzで保存したものです。動画の8fpsを実際の描画FPSと読み替えないでください。

FF15級へ向けて、素材の精度、拡散GI、店舗固有の完成造作、屋内の生活感、LOD・実機性能調整が残ります。形状数・自動検査の件数だけで美術品質の完成を判定していません。

## 制作再現（通常実行には不要）

元のリポジトリとShapely2.2・NumPy・Pillowが必要です。
`authoring/build.py` → `choose_hinges.py` → `expanded_inputs.py`。
Blenderで `authoring/bake_ao.py` を実行すると `assets/geometry-lit.json` を生成します。入力ハッシュを確認して `geometry.json` と入れ替えます。
`audit_mall.py`・`route_exposure.py` は原設計を読み取って分析し、原本へ書き込みません。

```
godot --path .
godot --headless --path . --fixed-fps 60 -- --walk-test
godot --path . -- --capture --output=res://evidence/after
godot --path . -- --animation --output=res://evidence/animation
```

設計原本・本体への統合は行わず、図面変更案と検証シーンの確認を待ちます。
