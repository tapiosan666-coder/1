# 0.2 — 初期スキャナーと確定方法の更新

## ユーザー指示による確定仕様の変更

- 初期装備を銃から手持ちスキャナーへ変更。1回で対象にできるのは1人、必要時間は約2秒。
- 銃はAPで途中購入する装備へ変更。初期装備として配らない。
- 銃・猫・範囲スキャンで本物が見つかっても通知だけ。**初期スキャナーで本物を調べることが唯一のクリア条件。** 初期装備は銃購入後も1キーで使用できる。
- 等確率で開始時に決めた本物を変更しない。最初の1人が本物でもクリアできる。

## 実装上の仮設定

- 初期スキャナー：6m、同一対象を左クリック長押しで2秒。視線を外す、遮蔽、距離超過、ボタンを離す、装備切替、ポーズで途中進捗をリセットする。弾薬・リロード不要。
- 銃：120人版400 AP。人数に合わせた総APの約1/3（最低400）とし、5,000人ロジックでは16,670 AP。これは購入時期を試すための仮価格で、製品版の調整完了を意味しない。他のスキルへAPを使えば購入は遅れる。
- 1：初期スキャナー、2：購入済みの銃。銃は5発・30発弾倉・1秒リロードを継承。銃強化は購入後だけ解放し、初期スキャナーの2秒には影響しない。
- 中途半端な銃の命中進捗を、初期スキャナーの確定に持ち越さない。本物を銃で何回調べてもクリアしない。

## 見た目の改善と限界

- 画面内にディスプレイ・ボタン・センサー・手袋を備えた手持ちスキャナーを追加。実時間の進捗を道具とHUDに表示。
- 箱形の人物を丸い立体の部位へ変更し、成人に近い頭身・顔の目鼻・耳・手・靴を追加。全員の顔パラメータは共通のまま。
- 石材風の床シェーダー、目地、天窓、日光と影、店舗の暖色照明・商品、細かな植栽を追加。
- **写実品質の完成ではない。** 人物は手続き生成の簡易メッシュで、フォトリアルな肌・髪・衣服や本格的な歩行リグは未実装。次は適切な権利を持つ人物モデル・スキニング・素材制作、服の質感、自然な群衆回避、店舗の内装密度を進める必要がある。
