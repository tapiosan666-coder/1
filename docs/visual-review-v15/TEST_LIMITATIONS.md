# 検証の範囲と限界

- 幾何検査：登録区画と用途、面積、壁の床+1.15m断面等を検査。全高さ・全店舗の建築美観を保証しません。
- 物理経路追従：実衝突を使うCharacterBody3Dの自動経路追従。人間の自由操作ではありません。
- W入力検査：元のプレイヤー制御へキー入力を注入し、ES乗降・乗り継ぎ・橋・柵を検査。経路検査は各物理tickで向きを補正。C館のアクセス橋はコンベヤーを停止して通行を確認し、ES自体の乗降は別試験でコンベヤーを有効にしています。柵試験は床端から1m内側に立ち、実際の辺に直角に接近します。代表点の試験であり、全境界の連続保証ではありません。
- 実画面：Godot 4.6.3 Forward+、Linux llvmpipeソフトウェアVulkan、1920×1080。カメラ位置・視線・FOVを比較メタデータに記録。人間の操作録画ではありません。
- Windows GPU性能：未計測。撮影用のソフトウェアレンダリング時間をゲーム用GPUのFPSと換算していません。
- 144FPS：設定上限。達成を実証していません。
- EV、ES：通常版の制御コードを保護。物理60Hzで再試験しましたが、全描画FPS・全入力タイミングの保証ではありません。
- 480店舗：境界監査は全区画、代表内装設備は6業種・7追加配置とカフェの注文台置換。480店すべての美術品質を完成させたという意味ではありません。
- 225区画の短辺・鋭角候補は欠陥確定ではありません。屋上22区画は開放用途を含み、閉鎖壁の欠落と単純に判定していません。
- 約5,609.83㎡の幾何残余は、公開された用途不明通路と同義ではありません。躯体・設備帯との対応付けが一部未完了です。特にC館地下を継続確認します。

変更前の結果・途中で見つかった不具合と、最終再試験の結果を混同しないよう、提出testsには最終の実行結果を収録します。数値上の合格のみで商業施設として自然、またはFF16級品質に達したとは判断していません。
