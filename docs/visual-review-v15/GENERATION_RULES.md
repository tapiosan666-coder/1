# 再発を避ける設計・生成ルール

1. 店舗ID・区画・入口座標は原本を保持し、構造別案の床・共用領域は別データとする。
2. 床版だけでなく、全有効仕上げレイヤー・天井・手すり・衝突を最終床形状へ揃える。建物本体の衝突配列も除外しない。旧三角形と新生成の床・柵を識別し、撤去済み支柱の見えない衝突を残さない。
3. 境界三角形は重心判定や頂点3点だけで残さず、三角形全体の包含を判定。水平面はポリゴン交差、平面投影が線になる垂直面は線区間で分割し、UV・法線等を補間する。垂直な天井端だけが空中に残らないようにする。
4. 手すりの縦面だけを撤去しない。水平な笠木・金属レールも一体で扱う。最終床端から新しい柵を生成する。
5. エスカレーターの全機械平面投影を全階へ残さない。実際の乗降床と、店舗街へつながるアクセス経路を定義する。
6. 手すりの切欠きは実乗降口・実橋幅に限定。旧歩行経路の全体を切欠きへ転用しない。館外からの実接続位置を検出し、内部回廊の端に落下口を作らない。公共床と機械本体の安全形状を両方検査する。
7. 余った床を自動的に倉庫や通路へ分類しない。登録済み駐車・搬入・設備・躯体帯と照合し、判定不能は未確認として残す。
8. 細い隙間の数値抽出と欠陥の確定を区別する。正規の店舗前共用床・管理通路を壁で塞がない。
9. 什器は業種別の役割と既存占有範囲・売場動線を検査し、追加モデル数を店舗完成の基準にしない。
10. 未使用の衝突配列は三角形集合の一致を証明した上で差分化。見た目や通行性能を落としてファイルを小さくしない。

屋上支持や新しい柱・梁の構造安全性は、見た目・カプセル歩行だけでは証明できません。構造計算・基礎・耐震・避難は未検証です。
