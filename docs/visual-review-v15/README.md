## 構造変更の扱い

C館では2階に棟間の回遊路を残し、3階は各棟の階段・EVで利用する独立ギャラリーへ整理。既存ESの降り場を孤立させないため、CE12・CN23へ専用アクセス橋を追加しました。屋上は店舗・設備核の屋根と必要な入口前床を維持。支持部材は配置検討で、構造耐力・基礎・避難の実証ではありません。

ES敷地別案は1F〜RFのみ。地下候補は167.86㎡の車路と駐車4区画に干渉したため未施工。通常版の地下駐車・搬入を保持しています。RF-SUPPORT-16、BRF-GARDEN-2-BED-4の移設案も未承認です。

## v13・v14との統合範囲

地下51店舗、屋上22区画、60トイレ、17植栽槽・168植物、従来の専用商品モデルと素材・ライセンスを継承しました。有効な通常版16建築パックと旧別案2点の原本、主要制御をSHAで照合し、今回の変更・継承・未完了を同じ資料にまとめています。過去の検査結果を今回の再検査として再掲していません。

配布ZIPでは使わなくなった旧C別案パック2点を除き、新C案を差分収録しています。旧案の原本はv14の配布物を保持し、改変していません。
