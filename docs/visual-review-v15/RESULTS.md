# FIND YOURSELF v15｜確認結果
独立検証プロジェクトのみ。通常版の15層・480店舗区画と主要制御を保護し、C館案とES敷地案は別シーン・未承認です。ゲーム本体へ統合していません。
## 主な変更
- C館：2F回遊・3F独立店舗棟・必要なESアクセス橋・RF屋根範囲を整理。水平面だけでなく垂直な天井端も分割。旧衝突と新しい床・柵を区別し、見えない旧支柱を除去。
- 柵の切欠き：旧歩行経路全体ではなく、最終床と外部接続経路の最初の交点に限定。内部回廊の落下口を閉鎖。
- B館ES：西吹き抜けに1F〜RFの連続配置を敷地別案として収録。地下は車路・4駐車区画との干渉により未施工。滑らかなプレイヤー制御は変更していません。
- 代表業種：試着室・展示マネキン・雑誌展示・化粧品テスター・家電実機展示・バリスタ設備・食品レジ。カフェ注文台も専用化。全店の内装完成ではありません。

## 実画面と性能
33枚のGodot実Viewport PNG、同一カメラ16組を収録。1920×1080 / Linux llvmpipeソフトウェアVulkan。144FPSは設定上限。Windows GPUの実測FPS、VSyncの実モニター同期、人間による自由操作は未検証です。
## 未完了・承認待ち

- 地下ESの再配置、RF-SUPPORT-16、BRF-GARDEN-2-BED-4の支持床上への移設案。通常版では未承認状態を維持。
- 全480店の個別内装、商品の種類・表示、鏡面反射、部門構成、A/B館の長い壁・天井の最終美術仕上げ。
- 約5,609.83㎡の幾何残余と用途台帳の対応付け。露出した用途不明通路と同義ではなく、特にC館地下の躯体帯との照合が未完。
- 車両の全旋回軌跡・駐車操作は未検証。台数や歩行検査だけで車両動線を合格としていません。

FF16級の環境品質には到達していません。構造検証と代表設備の段階であり、全館完成版ではありません。
