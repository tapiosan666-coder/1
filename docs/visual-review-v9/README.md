# FIND YOURSELF｜v9 代表3エリア・映像検証版

独立したGodot 4.6.3プロジェクトです。ゲーム本体には統合していません。全館完成版ではありません。

## 今回の変更

- A館1F：格子天井と間接照明、石材床と真鍮インレイ、店舗別ファサード、書店の売場案内・表紙陳列、休憩席・案内板。
- B館1F「時の広場」周辺：木製ルーバー天井、店舗別の木・左官・セージ色の仕上げ、休憩席・植栽・案内板。吹き抜け・通路を維持。
- C館1F南西店舗街・中庭：店舗別外壁と軒、舗装、屋外カフェ4卓・8席、街路灯・案内板・休憩席。
- 写真由来の木材テクスチャとCC0の実形状チェアを追加。石材のアルベド・法線・粗さはオリジナル制作。床には既存静的形状から計算した近距離接触AOを使用。GIの完成や実測照度を示す処理ではありません。
- 三角形・素材属性・衝突面を維持した頂点共有化。建物を簡略化する処理ではありません。家具は共有メッシュと距離フェードを使用。

仕上げ対象はv8と同じ42店舗（A16・B19・C7）を含む代表範囲です。店舗数は増やしていません。他階、駐車場、館間接続、既存の昇降設備はv8を維持しています。RF-SUPPORT-16は未承認のままです。

## 起動と操作

Windows版はZIPをすべて展開し、`FIND_YOURSELF_v9.exe` を開きます。Godot版は4.6.3で `project.godot` をインポートしF5で起動します。初回の読み込み・シェーダー準備には時間がかかります。

- WASD：移動、マウス：視点、クリック：視点操作開始、Shift：速歩、Esc：カーソル／UIを閉じる
- F1：A館、F2：B館、F3：C館の代表エリアへ移動
- F：従業員扉／EV操作、M：館内マップ（表示中は移動停止）、F10：画面設定
- 初期設定：1920×1080・144FPS上限・VSync ON要求。1440p／4K、30・60・120・144・無制限を選択・保存可能
- Windows版は未署名です。署名・Smart App Controlの通過、Windows実機動作はこのLinux環境では検証していません。

## 確認範囲と限界

提出画像は実際のGodot Viewportから1920×1080で取得し、v8保存画像と同じ位置・向き・FOVで比較しています。自動物理検査は人間による実操作とは区別しています。Windows / RTX 4060実機は未検証です。ソフトウェアGPUの描画計測から実GPUのFPSを推定していません。144FPSは設定上限であり、達成保証ではありません。

商品・衣料・植栽には簡略形状が残り、反射・間接光、店舗固有の細部、遠景の単調さは引き続き改善が必要です。FF15級の最終品質に到達したとは評価していません。代表3エリアの確認後に全館展開を判断する段階です。

## 再現用データ

通常起動には同梱ファイルだけで足ります。比較元のv8画像は比較ZIPに収録。`--capture`で同一9視点の撮影、`--benchmark-v8`で固定FPSなしの描画時間計測、`--headless --rendering-method gl_compatibility --fixed-fps 60 -- --walk-test`で自動物理検査を実行できます。名称互換のbenchmark引数はv9を測定します。

新規制作スクリプトは `authoring/*v9.py`。メッシュ再生成に使う旧形式の非インデックスpackは、比較ZIPの `authoring-inputs/assets` をGodotプロジェクトの `assets` にコピーしてから使用してください。通常の起動には不要です。第三者モデルの原配布GLBはREADME内の公式URLから取得して `assets/vendor` に置きます。未使用のソファ候補は実行版には含めていません。
