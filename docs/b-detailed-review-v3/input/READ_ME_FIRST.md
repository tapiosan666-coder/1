# FIND YOURSELF B館：詳細平面図・承認レビュー用資料

この成果は**ゲーム用の建築設計案**です。Godotのシーン／ゲーム本体は一切変更していません。

## 収録図面・表

- `FIND_YOURSELF_B_1F-3F_DETAILED_PLAN.pdf`：各階の建物外周・売場境界・店舗入口・内部主路・バックヤード・吹き抜け・エスカレーター・設備核と設備核詳細・QA結果。
- `B_tenant_ledger.csv`：198店舗のID、用途、間口、奥行、入口座標、予定内部動線。
- `B_old_to_new_mapping_PROPOSED.csv`：旧B館38店舗と各階広場の世界座標を基点とした新ID候補。
- `B_provisional_coordinate_transform.json`：3広場を拘束点とした旧世界X/Z→新ローカルX/Zの仮アフィン変換。
- `B_completed_plan_geometry.json`：各階の正確な2D区画・出入口・設備室・昇降機開口予定座標の機械可読データ。
- `B_geometric_checks.json`：幾何学的検査結果。
- `B_review_checklist.json`：試験集計と未検証事項。

## 重要な制限

**新案は平面幾何で検査済みでも、実歩行検証済みではありません。**ゲームで歩いた・3D当たり判定を通したと解釈しないでください。

1. A/B・B/Cの接続は、旧版から確認できた **1F歩行路と2F橋** の構成を描きました。新ローカル座標を既存Godotワールド座標へ確定する作業は残っています。3Fには旧版にない接続を捏造していません。
2. 旧→新店IDは**一意の距離最小割当による移設候補**です。ゲーム側で「元店舗IDが本当に同じ役割か」を照合して承認する必要があります。
3. エスカレーターの上下階対応は同一局所座標で統一し、乗降口の平面接続を調べていますが、上下の3D高さ・開口抜き・衝突確認は未実施です。
4. 通路一体性、店の接近、店舗区画重複の平面検査は実施。実測安全基準・避難・バリアフリー適合を保証する図面ではありません。
5. トイレは前室・洗面・個室4室を描きましたが、多目的トイレや男女別構成、手洗いへのバリアフリー経路は別途決定が必要です。
6. 店舗内部の細かな棚・スタッフ専用搬入路や、全店を結ぶバックヤード回廊はゲーム側の詳細内装段階。図面の薄橙部分は各店舗専用バックルームです。
7. 大型館の三角形に見える未利用空間は建築用の空地／非公開エリアとして表現。実際の商業施設としての用途決定と外周処理は承認前の確認対象です。

## 次の承認プロセス

図面の各階で店舗密度・吹き抜け・エスカレーターを視覚承認し、A/B・B/Cの既存シーン接続座標と多目的トイレ等の追加仕様を照合するまで、ゲーム本体の変更を禁止します。
