# 10万回のプレイ時間試算

## 結果の位置付け

これは**未実装の5,000人・15フロアの完成版を想定した集約シミュレーション**です。120人のGodot開発版のプレイ時間を10万回実測した結果ではありません。個別NPCの3D経路、店内の見落とし、実プレイヤーの心理・操作・休憩は再現していません。

固定seed `20261023`、NumPy `2.3.5`、100,000試行。詳細な仮定と結果は [balance-results.json](balance-results.json)、計算は [simulate_balance.py](../tools/simulate_balance.py) に保存しています。

3時間超9.202%、6時間超0%（この有限のモデル・標本内のみ。現実の上限を保証しない）。発見順位の平均2,497.364人、1人目での発見19試行。通常銃以外での検出56.257%、発見アイテム平均2.996個。

**目標平均180分は未達です。** この結果を理由に正解の確率や場所を変えたり、最初の一定時間は見つからないようにしたりしません。探索・施設の密度・能力の購入タイミングを実プレイで検証し、有意義な探索内容を増やす方向を検討します。値を180分に合わせるための未検証の係数調整は行っていません。

## モデルに含めた要素

- 真の人物を固定し、遭遇順位を1〜5,000の一様乱数として抽選。遭遇順は交換可能・重複処理なしと仮定する。元の正解を途中で移さない。
- 命中率はプレイごとにBeta(12,6)、30〜95%に制限。銃は初期5発、毎秒6.25発、30発・1秒リロード。APで1発まで強化。
- 4種類の購入順を抽選。10 AP/偽物を獲得し、実装と同じ基本価格と段階価格を使う。猫・移動・ソナー・特殊スキャンにAPを配分する。
- NPC移動を探索時間係数0.85〜1.35として近似。個別の3D移動は計算しない。
- 店内探索5.5秒/人＋基本探索3.8秒/人。混雑減少で探索時間が増え、ソナーと移動強化で軽減する。50人単位でばらつきを加える。
- 猫1匹、20/12/6秒、稼働率65%。範囲スキャンは局所密度のPoisson分布と25秒クールダウン、稼働率55%で近似。
- 333人ごとをフロア移動として65秒を加算。訪問済みフロア間の戻り経路をファストトラベルで15%軽減する。初訪問移動は飛ばさない。
- 6通常・3レア・1伝説の宝箱。発見率55/65/80%。8アイテムを等確率で仮抽選。攻撃系の100〜200人を密度で減衰し、使用は次バッチまで温存。補助系は180秒の探索時間軽減で近似。
- 猫・範囲・アイテムが本物に当たる場合は15〜90mを接近し、通常銃の必要命中とリロード余裕を追加する。

宝箱の位置はこの試算では到達可能な遭遇順位上と仮定し、3Dマップの到達保証を検証したわけではありません。磁石等の個別挙動は簡略化しています。広域ソナー・時間停止・カートの有効時間等は新規の試算用仮定であり、確定仕様ではありません。

## 再実行

```bash
/workspace/.venvs/find-yourself/bin/python tools/simulate_balance.py \
  --trials 100000 --seed 20261023 --output docs/balance-results.json
```

同じPython/NumPy版とseedで結果は再現可能です。今後はGodot側に遭遇・命中・移動・能力・宝箱の時刻ログを追加し、十分なプレイテストから分布を更新します。
