# A館 詳細設計 v1

設計資料のみ。Godot本体とB館v4.1は変更していません。
5層(B1/1F/2F/3F/RF)、三角回遊の3専門店街＋中央核店街、3広場、3設備核、24エスカレーター機器を計画。

主図面は downloads/FIND_YOURSELF-A-Detailed-Design-v1.pdf。
geometry.json は World XZ metres、階高はB基準。店舗入口・裏室・棚帯・主路・共用床・床開口を収録。
checks.json は図面検査のみ。実歩行・ゲーム画像・法的建築認定の結果ではありません。
旧ID対応は旧40区画＋地下食品7＋フードコート4、補助サイン/読書施設2参照。比較点の定義をCSVに明記。
全実寸はゲーム用設計値。公式kazeの3広場/専門店街とアンカー/階別用途を参考にしたオリジナル構成。
B1/RFは実在施設にないゲーム独自の計画。機械型式・商品小物・施工/防火基準・群衆負荷は未検証。
