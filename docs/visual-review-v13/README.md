# FIND YOURSELF v13｜v12＋公共設備・地下・屋上 統合検証版

このZIPだけで起動できます。前回のv12を別に用意する必要はありません。Windows EXEは含みません。既存のスキャンゲーム本体には未統合です。

1. ZIPを新しいフォルダへ**全部展開**します。
2. Godot **4.6.3 Standard**で `FIND_YOURSELF-v13/project.godot` をインポートします。
3. 初回インポートが完了したらF5。通常起動にPython、Blender、追加データのダウンロードは不要です。

## 確認のしかた

- WASD／マウス：移動・視点。Shift：速歩。F：個室・多目的トイレ・階段などの扉、EV。
- **F9：今回更新したトイレ・地下店舗・屋上など15視点と、全60か所のトイレへの確認メニュー。** メニュー表示中は移動停止。移動ボタンは検証用で、ゲーム本体のファストトラベルではありません。
- M：館内マップ。F10：画面設定。F1・F2・F3：各館代表地点。
- F8：前回の代表6業種店舗。F4：C館構造別案・未承認を切替。
- F7：前回のB1～RF連続ES検討シーン。F4で全館へ戻る。
- 初期1920×1080、144FPS上限、VSync ON、物理更新60Hz。設定は保存します。

## v12から保持したもの

全15層、480店舗ID、館間連絡、駐車場、階段・EV・既存ES、マップと画面設定を保持。ES開口の見える柵・乗降口修正、4店舗の衝突欠落修正、代表6店舗、C館余剰デッキを整理した未承認別案、5層ES乗継ぎの未承認モジュールも同梱しています。

## v13で追加・修正したもの

- 全60設備核のトイレ：個室領域全体を高さ85cmの箱にしていた生成不良を除去。便器、洗面台、小便器、手すり、紙ホルダー、壁・床仕上げ、照明と案内を個別に生成。
- 240の通常個室＋60の多目的トイレ。A/B館の未生成だった個室扉120枚と、全館の多目的トイレ扉60枚を追加。既存C館個室扉120枚も保持。
- 多目的トイレは膝下空間のある洗面台、支持手すり、非常呼出コードを配置。直径1.5mの転回領域は設計検査の対象です。建築・福祉設備の法令適合認定ではありません。壁付けベビー設備は閉じた表示で、展開操作は未実装。
- **地下51店舗（A31・B2・C18）**：食品・医薬品・生活用品・書籍・スポーツ・修理・受取の用途別に、会計、壁面、中央売場を配置。売場・バックヤード・店舗区画は維持。会計カウンターは全51区画に配置。
- **屋上22区画（A15・B1・C6）**：設計用途どおり、屋外カフェ・軽食テラス・ガーデンショップとして整備。会計・受付、屋外席、パラソル、園芸商品展示を配置。通常の囲い壁を持つ室内店舗としては扱いません。
- A/C館の地下・屋上にロッカー／休憩席18か所。B館の狭い連絡廊下には家具を押し込まず案内表示を設置。B館屋上の既存3前庭には休憩席12台と案内図表示を追加。
- 地下・屋上の客用床仕上げは実際の水平衝突床へ切り取り、開口の上に見た目だけの床を作らないようにしました。C館構造別案の屋上支持範囲も考慮しています。

## 完成扱いにしない項目

公共設備と未施工だった地下・屋上の基本内装を進めた版です。全館の最終美術完成、FF16級品質、Steam製品版の完成を意味しません。

- 地下の設備・搬入・大型管理区画の詳細、既存の用途確認候補（細い帯やC館残余帯）、全店舗の最終商品表現とサインは継続課題です。
- C館構造別案と各館への連続ES配置は未承認。実際の館のESを8.4mの乗継ぎへ移設した版ではありません。B/C館の地下・屋上ES不足は、階段・EVで代替できる部分と未施工を区別しています。
- **RF-SUPPORT-16は未承認のまま**です。支持力・基礎・耐震・車両軌跡の認定は行っていません。
- 洗面鏡は金属反射材で、専用の平面反射カメラは未実装。水栓・ベビー設備・家具に操作機能はありません。
- 自動経路検査、実コントローラーへのW/F入力、Godot Viewport撮影を使用。人間の実操作とWindows GPUでのFPSは未検証。144FPS達成は主張しません。
