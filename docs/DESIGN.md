# FIND YOURSELF — 開発仕様と実装範囲

## 確定仕様（ユーザー指示）

中心目的は「同じ顔の5,000人から、1人の本当の自分を探す」。本物は開始時に等確率で固定し、位置・判定の後付け変更、最低時間の強制、確率操作を禁止する。目標平均3時間は設計目標であって保証ではない。最初の1人でのクリアを認める。

最終目標はSteamで販売可能なPCゲーム。イオンレイクタウンは構造上の参考のみとし、実在施設・店舗・ロゴの完全再現はしない。動物の探索助手は猫だけとする。NPCの自然さと同じ顔による異様さを重視し、不自然なギャグを足さない。

### 判定と成長

- 顔は写真アップロード生成または手動パーツ調整。全員同じ顔、服・持ち物・行動は個体差。写真は将来的にも送信先と保存方針を明示して扱う。
- 通常銃は初期30m、同一人物5発、弾倉30発、リロード約1秒、予備弾無制限。
- 偽物は足元の床開口・落下・消滅。効果音、ヒット、コンボ、APを明瞭にする。基本10 AP。
- AP強化の4系統：銃（命中数・射程・リロード・弾倉・貫通・拡散・連射）、猫（探索速度・スキャン速度・範囲・追加）、探索移動（ダッシュ・スライディング・二段ジャンプ・エアダッシュ・フック・カート・訪問済み地点のファストトラベル・ソナー）、特殊スキャン（範囲・連鎖・ビーム・衝撃波・ブラックホール・広域）。購入済みはそのラン中継続。
- 猫は初期約20秒/人。通常銃以外による本物の検出は通知だけ。プレイヤーが通常銃を当てて確定する。本物発見後に他のNPCを消去しない。
- ソナーは15→30→50→80→120m。壁・床・天井越しの発動時点の位置のみ表示。移動を追従せず、本物表示も同一。
- 宝箱は毎回到達可能地点へランダムに10個（通常6・レア3・伝説1）。使い切りアイテムは人間磁石・超連鎖弾・時間停止時計・ブラックホール・全域ソナーチップ・スーパーカート・天井レーザー・ディスコフィーバー。密度が十分なら強い攻撃系は100〜200人程度。
- 終盤の疎なNPC探索には情報・移動・ソナー等で対処し、単調な射撃反復にしない。

## この開発版のスコープ

初版は0.1、**A館1階の検証用セクター・120人**。これは上記の最終人数や階数を変更する決定ではない。短い検証サイクルで操作と判定を固めるための開発用設定。5,000人を120人に変更して製品化するという意味ではない。

| 段階 | 現在の実装 | 未実装 |
| --- | --- | --- |
| 1 基本 | FPS・射撃・NPC個別ID・固定本物・5発判定・落下・再プレイ | 対象PCでの操作感テスト、演出の製品品質化 |
| 2 成長 | AP・4系統9強化・範囲・ソナー・猫1匹 | 貫通/拡散/連射、追加猫・指示エリア、連鎖等、残りの移動スキル |
| 3 マップ | オリジナルA-1Fアトリウムと8店舗 | A/B/C本館、15フロア、連絡通路、ファストトラベル |
| 4 探索 | 経路移動・店先待機、現在地表示 | 10宝箱・8アイテム、着席・食事・会話・施設利用、探索率 |

写真からの顔生成は未実装。手動調整は肌3色・髪3色・顔幅に限定し、鼻・目等の細かなパーツ調整は未実装。NPCは同じ形状と顔パラメータを共有し、服装6色と歩行速度・目的地を変えている。持ち物・会話・映画館の行動まで完成したという扱いにしない。

## 初版固有の仮設定・提案

以下は実装を動かすための仮設定で、確定した製品仕様への変更ではない。

- ソナーの表示4秒・再使用12秒、範囲スキャンの再使用25秒。
- 範囲スキャン半径8/12/16m。猫の強化後スキャン時間12/6秒、近くの未処理NPCを自律選択。
- 猫と範囲スキャンは検出時に偽物を確定スキャンし、本物への通常命中進捗を加算しない。
- 必要命中数を下げたとき、既存の途中進捗は保持する。購入操作だけでは確定せず次の通常命中で判定する。
- スキル価格は `IdentityRun.SKILLS`、段階nで基本価格×n。終盤の経済設計は今後調整する。
- ポーズ・強化・案内図ではゲーム時間とNPCを止める。UI・進行状況のセーブはまだない。
- 全員同一の箱形アート・合成音はオリジナルの仮素材。製品品質の3Dキャラクター、アニメーション、サウンドへの差し替えを予定する。

## 技術方針

Godot 4.6.3 Standard / GDScript / Compatibility renderer、マウス・キーボード向け。外部の有料アセット・API・写真送信処理は使用しない。

- `IdentityRun`：正解ID、通常命中進捗、確定済みフラグ、AP、強化の唯一の管理元。5,000人の状態でも同じロジック。
- `Crowd`：表示と経路。部位ごとのMultiMesh、個体ごとのArea3D判定。現在は全個体を毎物理フレーム更新するため、大規模化には更新頻度・有効領域の分離が必要。
- `Mall`：到達可能なNPC経路グリッドと衝突付きの手続き生成。現在は平面のみ。
- `main`：射撃レイは壁で遮断、ソナーは状態の距離検索。能力別に同じ管理元へ判定を依頼する。
- `ScannerPlayer`、`FindHUD`、`ScanAudio`：操作、UI、合成効果音。HUD以外の進行はポーズされる。

将来の本物IDの保存はセーブファイル内に固定し、ロードで再抽選しない。NPCを別階へ移動しても同一IDを保持する。Steam実績・クラウドセーブ・設定変更と判定ロジックを分離する。

## 販売前の完了条件

15フロアの実地到達性、全宝箱の到達保証、5,000人でのフレーム時間とメモリ、最低/推奨PC、長時間・終盤・セーブ復帰・ウィンドウ/入力/音量/アクセシビリティのQA、顔写真の扱い、日本語を含むローカライズ、アセット権利・ライセンス表示、ストアページ素材、Steamworksの実機確認が必要。現版に対して「Steam販売品質に到達」「平均3時間を実測」とは表現しない。
