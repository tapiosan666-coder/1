# FIND YOURSELF — 開発仕様と実装範囲

## 0.2で更新された確定仕様（追加ユーザー指示）

初期装備は銃ではなく、1人に約2秒かける手持ちスキャナー。銃は中盤にAPで購入する装備へ変更。銃・猫・複数一括スキャン・特殊アイテムで本物が見つかっても通知にとどめ、クリアには最初のスキャナーで本物を調べる。この節は初版の「初期装備は銃／通常銃でクリア」を置き換える。等確率で固定した本物と、1人目でクリアできる原則は維持。

開発用の仮設定は、長押し2秒、単体、射程6m、中断で進捗リセット、1/2で装備切替。銃の価格は120人版400 AP、5,000人のロジックでは16,670 AP（人数に応じて総APの約1/3、最低400）。購入タイミングの実測は未完了であり、製品の確定価格ではない。銃の強化は銃購入が前提。初期スキャナーの確定時間は銃強化で短縮しない。

人物を丸いメッシュと顔パーツへ変更し、天窓と影・床シェーダー・店舗照明・植栽を改善。写実品質の人物・服のテクスチャ・スキンやアニメーションは今後の制作対象。

## 0.4の追加実装・仮設定

貫通弾（銃購入後150 AP・最大3人・壁で停止）、連鎖（180 AP・E・5mごとに最大8人・壁で遮断・20秒）、二段ジャンプ（80 AP・空中1回・着地で回復）。本物は特殊手段では通知のみ。初期スキャナーの確定時間を短縮しない。価格・距離・人数は調整用で確定仕様ではない。

人物品質の最終目標はペルソナ5程度の作り込まれた表現。現版は独自の簡易メッシュの輪郭・衣服・陰影・歩行を整える段階であり、専用人物アセットや表情の制作は未完。

## 0.5の追加実装・仮設定

ファストトラベルは100 AP、5つの案内ポイントへ2m以内まで実際に近づくと訪問を記録、Mから訪問済み地点のみ選択。価格・記録半径・ポイント数は今回の仮設定。上階の回廊は建築景観として追加した段階であり、探索できる上階を完成したとは扱わない。人物モデルと店舗構成の詳細はART_AND_LAYOUT.md参照。

## 0.6で実装した追加ユーザー指示

長い箱型の通路を湾曲する構造へ変更。1階から3階まで中央が吹き抜け、上階の店構えと人々を見られる。上階を景観だけにせず、1〜3階とも実際に店舗へ入って探索できる。同じ店舗の再利用を認める。近づいたNPCには日本語の吹き出し。地下・屋上・駐車場・別館・館間の連絡通路は後続の実装予定。この節が0.5の「上階は景観のみ」を置き換える。

今回の開発用人数は120人を維持し、1階64人・2階28人・3階28人に分配。各階12専門店、上階の店員と買い物客、2本のエスカレーターと回廊の橋を追加。全館・5,000人へ拡張する前の検証範囲であり、完成版の規模を変更する決定ではない。

## 0.6の新しい仮設定

宝箱は到達可能な経路点で6m以上の間隔を空けて10個。通常6個から磁石・時計・ソナー、レア3個から超連鎖弾・カート・ディスコ、伝説1個からブラックホール・天井レーザーを抽選。種類別の中身の組合せと以下の効果値は開発用の仮設定。

| 使い切りアイテム | 現版の挙動 |
| --- | --- |
| 人間磁石 | 18m内から経路で移動できる人を10秒集め、元の位置・役割へ戻す |
| 超連鎖弾 | 40m以内の照準相手から、8mごとに壁で遮断、最大200人 |
| 時間停止時計 | 人の移動・役割動作を12秒停止。プレイヤーは移動可能 |
| ブラックホール | 前方付近から18m・最大200人、遮蔽を検査 |
| 全域ソナーチップ | 残っている全員の瞬間位置を8秒表示。同一表示で本物を区別しない |
| スーパーカート | 30秒間、移動速度1.7倍。カートの運転物理は未実装 |
| 天井レーザー | 40m以内で狙った地点付近から14m・最大200人、遮蔽を検査 |
| ディスコフィーバー | 12秒間、2秒ごとに周囲16m・最大20人ずつ、遮蔽を検査 |

全攻撃系アイテムはSPECIAL判定を共有。本物は通知だけで落下させず、初期スキャナーで確定。200人は上限であり、0.6時点の120人版で200人を処理した実測という意味ではない。消費アイテムはスキルとは別の在庫で、Gで宝箱・Iでバッグ・Xで選択中のアイテムを使用する。メニュー中は在庫を消費せず、時間効果も停止し、新しいランでリセット。

吹き出しはカメラ前方の約3.2m以内、壁・階で遮られない相手から1人分だけ表示。店員・買い物・読書・飲食休憩・会話・お手洗い・歩行ごとの短文で、本物のIDを参照しない。音声会話や分岐会話ではない。

## 0.7の追加実装・仮設定

A館の開発用区画をB1F・1F・2F・3F・屋上へ拡張。入口の西側階段で5階層を歩いて接続し、その1階から西駐車場へ通じる。従来の3層吹き抜け・回廊・店舗・エスカレーターを維持。地下は7つの食品カウンターと食品棚、屋上は植栽と休憩席、西駐車場は静止車両と歩行者通路。別館と館間の連絡通路は後続の予定。

今回の検証用人数は180人（地下28、1階・駐車場75、2階31、3階31、屋上15）。役割は店員49・買い物54・読書2・着席18・会話6・お手洗い6・休憩10・歩行35。正解はこの180人から等確率で開始時に固定する。完成版の5,000人や館ごとの人数を変更する決定ではない。180人版の銃は既存の人数比例式で600 AP、訪問済み移動は100 AP。価格・面積・配分は開発用の仮設定。

西側階段は見える段と滑らかな斜面の衝突を組み合わせる。各階の踊り場と折り返しの経路を3次元で接続し、猫や磁石でも経路を使える。通常の階移動でワープしない。エレベーター、車の運転、車両交通、天候、昼夜変化は未実装。屋上と駐車場の人には場所に応じた短い日本語吹き出しを表示。

ファストトラベルは従来の7地点に地下食品街・屋上庭園・西駐車場を追加して10地点。各2m以内の訪問記録を必要とし、未訪問の地下・屋上にも移動できない。宝箱は到達可能な5階層の経路点から計10個を抽選する。毎回すべての階へ1個以上置く仕様ではない。

## 0.8の追加実装・仮設定

移動中の継続的な重さを受け、描画負荷の削減を優先。静止した什器・建物を28m×24m程度の区画と階ごとにまとめ、色を頂点データへ統合。人物は近距離の詳細モデルと遠距離の簡易モデルを切り替え、描画姿勢の更新を30Hzへ制限する。位置・経路・個別の衝突判定は維持し、本物を消したり選び直したりしない。全館のオクルージョンやストリーミング、5,000人の実地性能保証までは実装していない。

B館は1〜3階の約184mの通路、吹き抜けと回廊、各階8店舗。1階奥は家電、2階奥は生活用品、3階奥は18席の映画館。A館2階西側階段からガラス張りの連絡通路へ入り、B館2階へ歩いて移動できる。1階にも駐車場側から歩行者用接続を設ける。B館の地下・屋上とC館は後続工程。

今回の人数は300人（定位置267・歩行33）。B館に122人の固定役割を追加し、歩行客は到達可能な経路を使う。正解は全300人から訪問前に等確率で固定。銃価格は従来の人数比例式で1,000 AP。人数・配置・価格・描画距離は開発用の仮設定で、製品の5,000人を変更する決定ではない。

案内図には階の切替と15個の移動地点を追加。地図で別階を表示しても訪問扱いにしない。100 APの移動スキルと実訪問が必要。ミニマップは周囲だけを表示する。

画質はEscから軽量・標準・高画質を選択し、選択を端末の設定ファイルへ保存。軽量は3D解像度75%、太陽の影なし、人物の詳細18m/表示100m。標準は100%、MSAAなし、影40m、人物26m/140m。高画質は100%、MSAA 2x、影70m、人物38m/190m。ゲームの進行セーブは未実装。設定画面に使用中GPU名を表示する。比較計測の条件と限界はPERFORMANCE.md参照。

建物・衝突・経路を事前生成した`assets/world/mall.scn`を同梱。開発時は対象スクリプトのハッシュが不一致なら再生成へ戻るため、変更後は`tools/build_world.gd`で更新する。配布パッケージの作成時にもハッシュを検査する。

描画負荷を抑えるため既定人数は300人のまま。B館の買い物客30枠を各階から分散してC館へ再配分し、C館に店員8・買い物14・着席6・会話2の計30人を配置する。全体は定位置267・歩行33を維持する。これは新しいランを始める前の配置設計であり、プレイ中に本物やNPCを別館へ再配置する処理ではない。本物を全員から等確率で開始時に固定し、初期スキャナー2秒でのみ確定する原則を維持。銃は人数比例式で1,000 APのまま。

訪問済み移動はB・C連絡通路・C館屋外広場・C館テラスを追加して18地点。案内図は5列で目的地を並べ、5階層を閲覧できる。未訪問場所は地図を見るだけでは解放されない。宝箱10個の到達可能な抽選先にもC館を加える。毎回C館に宝箱を保証する設定ではない。

面積・人数・移動地点・価格は引き続き開発用の仮設定。製品の3館各5階層・5,000人を変更する決定ではない。人物は既存の詳細/簡易モデルを継続使用し、美術の最終品質を達成したとは扱わない。

## 0.9の追加修正（ユーザー指示）

猫がNPCの座標へ近づこうとして、家具と経路の関係で旧1.1mの開始条件を満たせず止まる問題を修正。近くの経路点から2.2m以内・高さ差0.6m以内・壁とガラスで遮られない位置を選び、経路で移動する。到達点が見つからない対象は短時間保留して他の相手へ向かう。経路を毎秒先頭へ戻す挙動も抑え、1更新で複数の到達済み点を消費できる。配備時はプレイヤー付近の通行可能な経路点へ置く。

猫の処理時間は接近して見通しがある間に20→12→6秒。対象へ移動する時間は別に必要。画面左上に探索・移動・スキャンと経過秒を表示し、前足を動かす。本物を検出しても通知のみで、初期スキャナーによる確定ルールは維持。距離・高さ・再探索条件は開発用の仮設定。

2・3階の主回廊はA館3m→4m、B館5m→6mへ少し拡張。吹き抜けの幅はA館8m、B館4mを残す。床・ガラス手すり・回廊を結ぶ橋・猫や歩行客の経路を更新。店舗・階段の幅を全面変更したという意味ではない。

スキル画面は装備/猫/探索移動/特殊の4タブ。カード選択は購入せず、右側の詳細と購入ボタンで確定する。現在/次の効果、取得レベル、前提装備、AP不足、最大レベルを表示する。購入条件は判定ロジックと共通化。14スキルの価格・段階数は今回変更していない。

## 維持する全体仕様（ユーザー指示）

中心目的は「同じ顔の5,000人から、1人の本当の自分を探す」。本物は開始時に等確率で固定し、位置・判定の後付け変更、最低時間の強制、確率操作を禁止する。目標平均3時間は設計目標であって保証ではない。最初の1人でのクリアを認める。

最終目標はSteamで販売可能なPCゲーム。イオンレイクタウンは構造上の参考のみとし、実在施設・店舗・ロゴの完全再現はしない。動物の探索助手は猫だけとする。NPCの自然さと同じ顔による異様さを重視し、不自然なギャグを足さない。

### 判定と成長

- 顔は写真アップロード生成または手動パーツ調整。全員同じ顔、服・持ち物・行動は個体差。写真は将来的にも送信先と保存方針を明示して扱う。
- 購入する通常銃は30m、同一人物5発、弾倉30発、リロード約1秒、予備弾無制限。
- 偽物は足元の床開口・落下・消滅。効果音、ヒット、コンボ、APを明瞭にする。基本10 AP。
- AP強化の4系統：購入装備・銃（命中数・射程・リロード・弾倉・貫通・拡散・連射）、猫（探索速度・スキャン速度・範囲・追加）、探索移動（ダッシュ・スライディング・二段ジャンプ・エアダッシュ・フック・カート・訪問済み地点のファストトラベル・ソナー）、特殊スキャン（範囲・連鎖・ビーム・衝撃波・ブラックホール・広域）。購入済みはそのラン中継続。
- 猫は初期約20秒/人。初期スキャナー以外による本物の検出は通知だけ。プレイヤーが最初の手持ちスキャナーで2秒調べて確定する。本物発見後に他のNPCを消去しない。
- ソナーは15→30→50→80→120m。壁・床・天井越しの発動時点の位置のみ表示。移動を追従せず、本物表示も同一。
- 宝箱は毎回到達可能地点へランダムに10個（通常6・レア3・伝説1）。使い切りアイテムは人間磁石・超連鎖弾・時間停止時計・ブラックホール・全域ソナーチップ・スーパーカート・天井レーザー・ディスコフィーバー。密度が十分なら強い攻撃系は100〜200人程度。
- 終盤の疎なNPC探索には情報・移動・ソナー等で対処し、単調な射撃反復にしない。

## 開発版固有の仮設定・提案

以下は実装を動かすための仮設定で、確定した製品仕様への変更ではない。

- ソナーの表示4秒・再使用12秒、範囲スキャンの再使用25秒。
- 範囲スキャン半径8/12/16m。猫の強化後スキャン時間12/6秒、近くの未処理NPCを自律選択。
- 猫と範囲スキャンは検出時に偽物を確定スキャンし、本物への銃の命中進捗を加算しない。
- 必要命中数を下げたとき、既存の途中進捗は保持する。購入操作だけでは確定せず次の通常命中で判定する。
- スキル価格は `IdentityRun.SKILLS`、段階nで基本価格×n。終盤の経済設計は今後調整する。
- ポーズ・強化・案内図ではゲーム時間とNPCを止める。UI・進行状況のセーブはまだない。
- 全員同一の手続き生成アート・合成音はオリジナルの仮素材。製品品質の3Dキャラクター、アニメーション、サウンドへの差し替えを予定する。

## 技術方針

Godot 4.6.3 Standard / GDScript / Compatibility renderer、マウス・キーボード向け。外部の有料アセット・API・写真送信処理は使用しない。

- `IdentityRun`：正解ID、銃の命中進捗、確定済みフラグ、AP、強化の唯一の管理元。5,000人の状態でも同じロジック。
- `Crowd`：表示と経路。部位ごとのMultiMesh、個体ごとのArea3D判定。位置・経路・衝突は全個体を管理し、描画は30Hzで距離と視野に応じて詳細/簡易/非表示を切り替える。5,000人への大規模化にはAI更新頻度・有効領域のさらなる分離が必要。
- `Mall`：到達可能なNPC経路グリッドと衝突付きの手続き生成。現在はA館の地下・1〜3階・屋上と西駐車場、B館1〜3階・C館1階と接続通路。論理平面をMallCurveで湾曲させ、描画・衝突・人物・経路・案内図を対応させる。フロアの外形は接続した領域を結合して生成し、全経路の連結と固定NPCのスキャン可能な立ち位置を検証する。
- `main`：射撃レイは壁で遮断、ソナーは状態の距離検索。能力別に同じ管理元へ判定を依頼する。
- `ScannerPlayer`、`FindHUD`、`ScanAudio`：操作、UI、合成効果音。HUD以外の進行はポーズされる。

将来の本物IDの保存はセーブファイル内に固定し、ロードで再抽選しない。NPCを別階へ移動しても同一IDを保持する。Steam実績・クラウドセーブ・設定変更と判定ロジックを分離する。
