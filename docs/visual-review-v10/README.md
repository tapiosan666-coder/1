# FIND YOURSELF v10｜環境グラフィック再設計・独立検証版

配布修正版：必要なデータを含む1ファイルです。

- [Godot統合版ZIP](../../downloads/FIND_YOURSELF-v10-Godot-All-in-One.zip)：新しいフォルダにすべて展開し、中の `project.godot` を開いてF5。
- [Windows統合版7z](../../downloads/FIND_YOURSELF-v10-Windows-All-in-One.7z)：すべて展開し、中の `FIND_YOURSELF_v10.exe` を起動。

どちらも追加データのコピーや、分割ファイルの結合は不要です。Windows 11では7zを右クリックして「すべて展開」できます。以前の分割配布は旧配布形式です。


ゲーム本体には統合していません。写真相当の商業施設表現・FF15級の最終品質を達成した完成版とは扱いません。

## 起動

Windows統合版を新しいフォルダへすべて展開し、`FIND_YOURSELF_v10.exe` を起動します。データの追加コピー・CMDによるEXE復元は不要です。Godot統合版はZIPをすべて展開し、同じフォルダにある `project.godot` を開いてF5で起動します。

- F1：A館、F2：B館、F3：C館の代表地点
- WASD：移動、マウス：視点、Shift：速歩、Esc：カーソル／UIを閉じる
- F：扉・EV、M：館内マップ（表示中は移動停止）、F10：画面設定
- 初期1920×1080、144FPS上限、VSync ON要求。1440p／4Kと30・60・120・144・無制限に対応し、保存・再起動復元を維持
- 「C館_構造別案_未承認.cmd」は、上階回廊を縮小する**別案**を開きます。通常版の設計を承認・上書きする操作ではありません。別案はマップにも未承認と表示

Windows実機はこの環境では検証していません。実行ファイルは未署名で、Smart App Controlの通過は保証していません。

## 制作方法を変更した点

提供された店舗画像4点と公式フロアガイドの外観画像を実際に開いて分析しました。2枚目は建築CGとして区別しています。実在店のロゴはゲームへ転用していません。新規の外部写真収集にはネットワーク制約があり、未確認の資料を参照済みとして扱っていません。C館中庭の地上からの多角度写真は未取得です。

v9の天井格子・ルーバーを増やす制作を止め、店舗正面と陳列を置換しました。

- B館の「入口線」と「正面全体」の混同、C館で正面データ形式の違いにより仕上げが適用されなかった問題を修正。現在の売場／客用通路の境界から正面を算出
- 店舗の開口・ショーウィンドウ・ファサード・立体店名を一体で生成。店舗ID・区画と元の入口座標を維持し、非耐力の正面開口幅は差分台帳へ記録
- Blenderで、縁の面取り・紙の厚み・服の立体的なしわ・曲げ木の椅子・カップの内側・コーヒー機器・パンケースなどを制作
- CC0／CC-BYの実形状モデルを採用。繰り返し商品は共有メッシュ、MultiMesh、距離制御とGodot標準LOD生成を利用。地被植栽は空間ごとに分けて描画
- 床・壁のPBR材質、売場奥までの照明、局所VoxelGIと反射プローブを調整。GI・プローブが環境光を過度に抑える初回設定は実画面を見て修正
- C館は中庭の地表・植栽と、独立棟ごとの外壁・店舗正面の仕上げを更新

店内の置換範囲は既存42店舗を含む代表エリアです。C館の遠景11店舗は外観のみ更新し、内装は未施工です。店舗数は増やしていません。他階の詳細内装や駐車場の仕上げは対象外です。既存15層・昇降設備・連絡通路を維持し、RF-SUPPORT-16は未承認のままです。

## C館の構造別案

2F・3F・RFで、既存店舗区画、階段・EV・ES、元の経路を保護したうえで、余剰の回廊・デッキを縮小しています。RFは直下の店舗上の屋根床も保持。新しい床面積を追加せず、境界にガラス手すりを生成し、連絡橋の横断箇所を開口します。

6棟の屋根形式と支持材は視覚検討案です。構造計算、耐荷重、排水、実建築の避難性能は未検証です。RF公開床の減少など、用途の再評価が必要な変更も残ります。通常版へ無断で確定していません。詳細差分は `source/v10/C-deck-option.json`。

## 品質評価と未完成部分

見た目の改善を、歩行検査の合格や物体数だけで評価していません。原寸の実Godot画像とv9比較で確認してください。

不足は、衣料の布目・縫製の細部、樹木／植物の種類、店舗ごとの専用商品・什器、遠景の構成と独自内装の密度です。C館は三層の回廊・連絡が景観へ強く出る点も継続課題です。実在アウトレットの地上写真、専用環境アセットのアート制作、Windows GPUでの照明・反射・LODと性能確認が必要です。

最終提出画像はGodot Viewport、1920×1080、3D描画スケール1.0です。制作途中の低解像度プレビューや暗すぎた試行画像は提出比較へ採用しません。

描画はLinux／llvmpipe（ソフトウェアGPU）でのみ計測します。Windows／RTX 4060のFPSは未計測で、144FPS達成を主張しません。CPUでの描画に加え、GI・反射・高密度売場の負荷があります。NPCは0人です。人間による実操作は未検証で、自動物理歩行とは区別します。

## Godotでの利用・再生成

Godot 4.6.3で `project.godot` をインポートしてF5で起動します。通常起動には同梱ファイルだけで足ります。WindowsでC館案を開く場合は、実行引数 `--c-open-proposal` を追加します。

`authoring` にBlender・形状生成のスクリプト、`source/v10` に設計差分と配置を収録。形状生成をやり直す場合のみ、比較ZIPの `authoring-inputs/assets` 内にあるv9入力packをプロジェクトの `assets` へコピーします。輸入モデルを再変換する場合は公式出典の原GLBを取得してください。VoxelGIの再ベイクはForward+描画経路で `-- --bake-gi`、C館案は `-- --bake-gi --single=C --c-open-proposal`。

`-- --capture` はv9と同一の9視点、`-- --capture --single=C --c-open-proposal` はC館案の3視点、`-- --capture --single=EXTRA` は追加視点。`-- --benchmark-v8` は引数名の互換を残したv10描画計測です。`--draft` は制作中だけの描画スケール0.5で、提出画像・FPS計測には使用しません。

## 統合版の配布修正

以前の本体・データ分割は廃止しました。この1ファイルに必要なマップデータを収録しています。容量制限に収めるため地形データの圧縮を変更していますが、展開後の幾何・衝突・メタデータは元のv10とバイト単位で同一です。内容や画質を削減していません。新規グラフィック改修ではありません。旧v10の検証結果とFPSは旧版の測定値で、統合版の再測定値とは区別します。統合版ではデータ同一性と展開後の起動を別途確認します。

Blenderの生成処理で `.pack.gz` を再生成した場合は、同梱の `authoring/unified_compression_v10.py` を実行して `.pack.zst` へ変換します。通常起動にはPythonは不要です。
