## v9で起きていた問題と制作方法の変更

B館は入口線を正面全体と取り違えていたため、長い店舗正面に対して局所的にしか仕上げが適用されませんでした。C館は正面データ形式が異なり、正面仕上げの生成対象から外れていました。現在の売場と客用通路の境界から正面全幅を求め直し、元の店舗区画・ID・入口座標を維持したまま非耐力の正面を再制作しました。開口幅の変更は店舗別台帳に記録しています。

床・壁のPBR、ガラスの見え方、売場奥の照明と局所GIを更新しました。既存の天井格子やルーバーを増やす制作は止め、書棚・本・衣服・ハンガー・カップ・カフェ機器・椅子などを、曲線や面取りを使うBlenderモデル／許諾条件を確認したglTFモデルへ置換しました。原材の実測スキャンPBRではなく、床・壁の一部はオリジナルの作画材質です。

C館構造別案は、元の店舗と経路を保護しながら上階の余剰デッキを縮小する比較案です。原本へは反映していません。荷重・支持・排水・避難の検証がなく、承認済み建築案ではありません。

## 品質目標へ向けて足りない制作物と環境

業種別の高品質な商業什器、商品パッケージ・食品・衣料の細部、植物の種類、店舗ごとに設計した展示とライティングが必要です。既存区画を埋めるだけの家具配置では、写真相当の空間には届きません。遠景と大きい天井面も追加の環境アート制作が必要です。

C館は現地の地上写真を複数方向から確認する作業と、必要な上階動線を精査した別の建築検討が必要です。承認前の構造変更で解決したことにはしていません。

Windows GPUと人間による継続歩行が利用できません。Linuxのllvmpipeによる少数フレームの描画測定、自動物理歩行、画像の目視確認を区別しています。144FPSは設定上限で、達成確認ではありません。
