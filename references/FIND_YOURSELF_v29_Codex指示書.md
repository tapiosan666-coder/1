## A・B・C館 1F全体の連続した商業空間化（建築不具合修正とは別開発）

**制作基準：添付された `1-FIND_YOURSELF-v28-Godot.zip`。v28のGodotプロジェクトを新規作業コピーして進めてください。**

この指示書はショッピングモール本体を前進させるためのものです。v26〜v28で繰り返した「2〜5地点の補修を一つのバージョンとする方式」をやめ、**A/B/C館の1F主要動線を全区間まとめて改修**してください。

併せて同梱の `FIND_YOURSELF_v29_画像付き参考資料.pdf`、`実写参考リンクと権利注意.md`、`v28基準_1F139店舗チェック表.csv`、ユーザー提供看板写真を必ず確認してください。資料の模式図は正確な地形図ではありません。配置・区画・店舗IDは常にv28プロジェクトの実データを優先します。

# 1. 最重要成果物と数量の根拠
v28に収録された `source/v22/store-status.csv`（v28のZIP内の店舗台帳）を抽出すると、1Fは**A館52店舗、B館69店舗、C館18店舗、合計139店舗**です。これは既存データ上の対象数であり、新たに店舗を増やす指示ではありません。

**最重要完成条件**：A/B/C館それぞれの1Fで、主要出入口から主要通路・広場・連絡通路まで実際に歩き、**長い未制作区間／無地壁の連続／同一店頭の反復／空っぽに見えるショーウィンドウがない**こと。

### 今回達成する3階層
- **全館1F共用部100%：** 実際に通れるすべての主要経路について床・天井・柱・照明・案内・休憩設備・店舗正面を連続した品質で整える。一本道の代表写真だけで「全館」を主張しない。
- **1F全139店舗の通路側：** 各店舗のブランド看板、店舗正面、ウィンドウ、通路から見える商品展示、入口まわりを業種に合わせて整える。店舗ID・業種・既存ブランドを維持。
- **重点24店舗の内装奥：** A館8・B館12・C館4を候補として、入口だけでなく中央・奥・レジ・什器まで高品質化。ただし**通路側139店舗の整備を犠牲にしない**。困難なら実完成数と保留IDを報告し、すべて完成と書かない。

「すべての139店舗の内部全域がハイエンドに完成」とは今回の目標を混同しない。1Fの見える範囲の広域完成を優先する。

# 2. A館1F（52店舗）｜都会的な専門店街
- 主要動線は大判タイル・アクセント帯・細かな目地・適切な反射を作る。床の巨大な単色面をなくす。
- アパレル、靴、バッグ、コスメ、生活雑貨などでファサードを差別化。店舗入口の幅、照明、ロゴサイズ、ガラス率、ウィンドウ展示に差をつける。
- 店内を通路から見ると、マネキン／ハンガー／陳列台／ショーケースなど**業種固有の立体物**が見えること。
- 壁面装飾・広告・天井照明・設備グリル・植栽とベンチを連動させる。売場の中央が空白に見えない配置。
- カフェ／書店／家電なども各業種らしい奥行きを持たせる。

# 3. B館1F（69店舗）｜大型広場・吹き抜け・にぎわい
- 大空間の開放感は残し、広場周囲の**店舗正面・床模様・イベント機能・休憩エリア**を作り込む。
- フード、カフェ、専門店、物販の陳列密度を各店ごとに変える。同じ棚を列ごとコピーするだけの生成は不可。
- 時の広場のようなイベント性を参考に、催事ブース、サイネージ、ベンチ、植栽、総合案内の役割を明確化。既存の愛知県フェアは保持。
- 吹き抜けの空間は埋め尽くさない。必要な安全手すり以外の不自然な囲いを新設しない。
- B館西側連続ESと既存ES・EVの**構造上の修正は別ブランチ**で対応し、今回無関係に削除／置換しない。すでに指摘された問題は未解決一覧へ記載。

# 4. C館1F（18店舗）｜オープンモール・中庭・テラス
- A/B館と同じ屋内箱型モールにしない。開放された屋外通路、軒、植栽、テラス席、敷石・石畳、屋外ショーウィンドウを主体とする。
- **C館中央に箱型の二重自動ドア・風除室を新規設置しない。** 既存の箱型入口の除去・建築修正は修正ブランチへ明示的に引き継ぎ、今回の広域制作を停止しない。
- 店舗個別の入口は必要。屋外区画からの店舗出入りと、A/B館との連絡区画の内外境界は区別。
- ドッグラン・キッズスペース・メロンパンキッチンカー・既存植栽の位置を保持。ドッグランの細かな地形修正は別ブランチで扱う。
- 屋外らしい照明、排水目地、舗装の素材切り替え、ベンチ、日除けで構成する。

# 5. 1F全体で必須の「商業施設らしさ」
## 店舗の手前〜奥の3レイヤー
1. 正面：ブランドサイン／入口枠／ガラス／ポスター／ショーウィンドウ。
2. 中央：立体の商品棚、展示台、商品種別、独立した什器、業種に合った照明。
3. 奥：背景の壁面陳列、レジ、試着室、家具、メニューボードなどの存在が自然に分かる。

遠くから見ても店舗種類が識別できること。商品数の増加や小物の多重複製だけでは未完成。

## 共用部
- 床：館別の素材、目地、ライン／円弧のアクセント、広場と通路の境界、入口のマット。
- 天井：ダウンライト、ライン照明、折上げ、梁・柱・空調吹出口、非常放送、適切な明暗。
- 柱・壁：商業広告、フロアガイド、展示、消防設備、ベンチ／植栽一体什器、休憩スペース。
- 看板：ユーザー提供写真のように**施設名・大きなピクト・矢印を横長の板へ横並びで配置**。距離表示（○m）は入れない。実際のWC/EV/ES/ATM/駐車場/出口の座標と方向を照合。
- A/B館の二重自動ドアは**実際に建物内外を区切る外壁の出入口のみ**。館内中央に入口のような箱型構造を新設しない。
- 安全：非常口誘導灯、消火器、屋内消火栓、警報設備などは不自然な障害物として置かず、実際の壁・天井・通路と整合させる。

# 6. 内装アート制作手順と実装
1. **まず1Fの歩行可能ルート・店舗台帳・既存ファサード・未完成な共用区画を全館抽出し、ルートを分割してIDを付ける。** 経路ID・ワールド座標・撮影ポイントを定義する。
2. A/B/C館の**各1つの連続ゾーン**で仕上げの品質基準を確立する（店頭数店だけでなく、通路・床・天井・広告・店内可視領域をまとめる）。
3. その基準をモジュール化して**残り全1F主要ルートおよび店舗正面139店舗へ展開**する。種類の異なる店を同一モデルの色替えだけで済ませない。
4. モジュールは店舗IDと業種情報から参照。素材・什器・モデルを必要に応じて共有し、ドローコールやメモリ増大を抑える。
5. その後、指定した重点店舗24店を優先して内装の奥まで作り込む。
6. 外観・売場を変えた箇所ごとに、ナビゲーション、入口幅、床接地、ローダーの境界、NPC通行を検証。

全139店舗の既存ブランド名、既存480店舗ID、15層の構造は勝手に改変しない。追加するときは新規ブランドと既存店舗の対応を必ず台帳に記録。

# 7. 不具合修正作業と分離するルール（重要）
- v29は**メイン制作ブランチ**とし、v28をタグ／バックアップしてから開始。
- B館のES・EV混在、ES下面の仕上げ、C館中央の不要エントランス、C館ドッグラン地形などは**別の修正ブランチ／チケット**で管理。必要な構造変更は今回勝手に同時実施しない。
- 同じデータファイルやシーンを変更する場合は、先に差分・影響範囲を比較してから統合する。古いZIPをまるごと上書きしない。
- 必要な修正が別途未完了でも、1Fの商業空間制作を止めない。両作業の進捗を混同しない。
- 彼女の同行AI、会話、ご機嫌、買い物、荷物、スキャンなどゲーム本編の処理は今回実装禁止。
