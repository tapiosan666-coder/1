# FIND YOURSELF v16 — 独立した建築・空間密度の検証版

Godot **4.6.3**で、このフォルダの`project.godot`を開いてインポート完了後に**F5**で起動してください。ZIPは新しいフォルダへ**すべて展開**してください。旧版への上書き、別データの追加、ZIPの結合は不要です。Windows EXEは収録していません。

- **F9**：v16の更新地点と従来の地点へ移動。地下・屋上も選択できます。
- **F1 / F2 / F3**：A・B・C館。WASD移動、Shift速歩、マウス視点。
- **M**：館内マップ。表示中は移動停止。新施設・催事も表示します。
- **F11**：B館・時の広場の「あいち 食と手しごと市」をON/OFF。OFFでは屋台の描画と衝突を無効化します。再開位置に人が重なる場合は再開を拒否します。
- **F**：扉・EV操作。ドッグランでは二重ゲートを一枚ずつ開閉します。
- **F4**：C館構造別案。**未承認**。通常版と切り替える独立シーンです。
- **F6**：B館西広場の連続ES敷地別案。**未承認**。通常版と分離しています。
- F7：ES単体の検討。F8：代表店舗。F10：画面設定。Esc：カーソル。

初期1920×1080、144FPS上限、VSync ON、物理60Hz。FPS上限は実測性能を保証しません。Windows GPUでのFPS、人間による実操作は今回未検証です。

主な追加範囲は、A館西広場・専門店街の案内と休憩、既存映画館・ゲームセンターの入口、B館3広場の催事・休憩、C館の遊び場・二重ゲート式ドッグラン・メロンパンキッチンカー、3館の既存地下店舗・屋上区画の一部です。**15層・480店舗全体を新規に仕上げた版ではありません。** 更新していない部分も残っています。

C館の通常版には従来の上階デッキが残ります。開放型のF4別案を通常版へ統合していません。RF-SUPPORT-16、B館屋上の未確認支持箇所を承認扱いにしていません。C館屋上の水上庭園はレビュー内の**未承認コンセプトのみ**で、通常版・F4のどちらにも実装していません。

キッチンカーの売買・調理、映画チケット販売、こどもや犬のゲーム処理は未実装です。遊具の製品安全性、車両搬入・旋回、建築構造・避難・排水性能は実証していません。これはNPC・スキャン・AP・セーブを含むゲーム本体とは別のプロジェクトです。

`source/v16`に配置・省略候補・設計検査、`authoring/v16_*.py`に専用モデル・画像・配置の制作処理、`licenses/v16-original-assets.txt`に素材の説明を収録しています。共通の形状・移動処理を保護し、新規什器は`commons_v16.gd`で別に生成します。
