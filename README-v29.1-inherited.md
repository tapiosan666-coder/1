# FIND YOURSELF v29.1｜v29継続改修・独立検証版

v29を保護した別フォルダのプロジェクトです。Godot 4.6.3でproject.godotを開き、インポート完了後F5。Windows EXE・分割ZIP・追加Data ZIPは不要です。

今回の重点はA1F-002（家電）、A1F-044（衣料）、B1-040（ベーカリー）、C1F-CE-3（キッズ）の4店舗です。建物の外郭・店舗区画・入口は変更していません。v29の全1F完成条件はまだ未達です。

専用のベーカリーケース、コーヒーカウンター、カフェ家具、衣料ラック、キッズ用低いラック、家電体験展示を制作。看板2店舗は実際の不透明な梁・壁への支持を確認し、元ブランド画像を再配置しました。旧家具が建築メッシュ内に含まれ、現行店舗台帳だけでは全家具を把握できないことが分かりました。今回の配置検査はその旧形式も含めます。

F9先頭の18地点で対象店舗を確認できます。WASD移動、Shift速歩、F扉/EV、Mマップ、F4/F6構造比較、F11催事、F12買い物客、N人物比較、P表情は保持。初期1920×1080、FPS上限144、VSync ON。実測144FPSを意味しません。

15層・480店舗ID・ブランド・43人の試験NPC・人物モデル・建築データは保持。既存のスキャンゲーム本体には統合していません。RF-SUPPORT-16、水上庭園などの未承認事項は引き継ぎます。

全139店舗を今回再制作したものではありません。大型店舗の全売場の完成、FF16級品質、人間の実操作、Windows GPU性能は未達/未実施です。詳細な実施範囲・実Viewport比較・自動検査結果はReviewを確認してください。

source/v291が新しい店舗配置の正本です。旧source/v29は保管。新モデルに組み込まれた商品は個別購入用SKUではなく、購入処理は実装していません。変更したラックの旧商品レコードのみ引退させ、表示と台帳を一致させています。

`--v29-baseline`で同じプロジェクトからv29の景観を比較できます。制作元はauthoring/v291_models.py、v291_layout.py。通常起動にBlenderやPythonは不要です。

最終再検査：主要233区間・店舗内42経路の自動衝突検査、4店舗各1代表経路の実プレイヤー自動往復を両版で通過。人間の操作検証ではありません。画像は18視点×2版、衣料修正後の7視点を撮り直して統合。看板の小さな下段表記、Cキッズ店の旧マネキン、B入口の見通し、大型店全体の密度は残課題です。
