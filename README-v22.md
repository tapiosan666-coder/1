# FIND YOURSELF v22｜独立建築検証版

v21の実配布ZIPを基準に、15層・480店舗・43人と女性モデルを保持した改修です。既存ゲーム本体へ統合していません。全店舗へ暫定内装を展開しましたが、全館の最終美術品質を達成した版ではありません。

- 店舗: 480 / 什器: 7,114 / 独立商品: 63,867
- 地下51店舗・屋上22区画を保持。各階状況は `Review ZIP内 tables/floor-status-15.csv`。
- 同じ位置・角度のGodot Viewport比較32組。画像は1920×1080、Godot直接保存。
- 図面は `Review ZIP内 drawings/v22-Floorplans-and-Sections.pdf`、480店監査は `Review ZIP内 tables/store-audit-480.csv`。
- Windows EXE・追加Data ZIP・分割ファイルは不要です。

## 起動

Godot ZIPを新しいフォルダに完全展開し、Godot **4.6.3** で `project.godot` を開いて初回インポート後F5。`.godot` は自動生成されます。初回読込は素材展開と全館構築に時間がかかります。

通常起動はA/B連続ES+C新構造を適用した独立統合候補です。F4=C旧別案比較、F6=B旧別案比較、再度押すと統合候補へ戻ります。F9=地点選択と独立水景、M=マップ、F10=設定、F11=催事、F12=NPC表示。WASD/マウス、Shift速歩、F=扉・EV。水景はF1で通常版へ。初期1920×1080・上限144・VSync ON・物理60Hz。保存済み設定がある場合はF10で確認してください。

## 実装変更

- **配布版固有の二重陳列**: v21配布ZIPには圧縮JSONしかなく、raw JSONの存在確認で旧陳列の除去が無効になっていた。読み込み済みの正式台帳を根拠に除去する方式へ変更。境界・床・バックヤード壁は除去対象外。
- **描画整理**: 不透明な静的建築を同一材質・48m単位で結合。結合前後の三角形数を一致確認。細かい商品は45m以内を原モデル、45〜110mを簡易遠景とする。ガラス・キャラクター・建物形状の簡略化は行わない。遠景切替の見え方は要追加評価。
- **A・B連続ES**: Bの採用方針を反映した独立版へ、Aの位置別検討を追加。Aは世界座標(330,0,-39)。1F〜RF、旧上階スロットの床を復元し、新開口・手すり・2方向の既存回廊接続を整合。既存の地下ES・駐車場は維持。移動処理のコードは保持。
- **C新構造**: 採用された2F回遊・3Fギャラリー案とB/A変更を三角形差分で合成。同時適用時に片方の衝突形状が戻る問題を防止。支持床の無い旧ソファ2点は新構造側のみ表示/衝突とも除去。支持力・基礎・排水・避難計画は未認証。
- **480店舗**: 元業種・ブランド・区画・入口を維持し、商品と什器を独立配置。12代表店を継承、他店舗へ業種別暫定配置。大型21区画は入口偏重の旧補充を撤去し売場全体へ部門を再配置。レジ一体化や小型什器を用い入口を保護。480店の美術完成とはしない。
- **用途の補正**: 文具・園芸・旅行雑貨等14店舗の汎用商品の混入を修正。書籍、衣類、食品、家電、化粧品、靴、眼鏡、楽器、玩具、園芸等を専用形状に分離。衣類のハンガー展示は底面支持検査から明示除外。
- **愛知県フェア**: 6食品+3工芸の9ブースを向かい合う2列へ再配置。子の商品・POPも同じ変換で移動。入口看板、ステージを維持。入口脚の複数ポリゴンを扱えないF11再表示判定も修正。
- **ドッグラン**: メイン動線に見えた旧位置から中庭端へ48構成物をまとめて移設。二重ゲート・サービス設備は維持。実床・カプセルで確認した153.32mの既存歩行経路へ誘導。新しい無目的な道路や床は作らない。
- **館内サイン**: 実天井へ2点の支持確認ができた33面は横長天吊り。15面は屋外/屋上の補助案内。Cのトイレ内部を公開アンカーに混入させた原因を修正し、入口前へ移動。1面は自然に置けず非表示。165案内経路は毎起動実衝突で再確認。
- **客用ルートと搬入線**: 旧main_routeは約全店でバックルーム内部が終点。施錠壁を客用通行不良と誤認しないよう、元搬入参照を残し、売場内で連続する区間を客用ルートとして別定義。初回の不合格資料も診断として残す。
- **独立水景**: 独自の三葉形浅水盤・3.3m回廊・ガラス手すり・3本の緩勾配接続をBlenderで制作。F9から独立シーンへ。屋上・通常C館には配置しない。水深0.10mの水だけで約0.981kPa、その他の構造荷重・防水・排水は未検証。

## 検証の読み方

図面の面積・ポリゴン、Godot実衝突のカプセル/レイ、自動CharacterBodyの重力付き歩行、実画面の視認を区別します。**人間による実操作は未実施です。** 代表経路の合格を全床・全方向の保証へ拡張しません。初回診断の不合格ファイルは経緯として保持しており、最終結果と混ぜて合格数を作っていません。

最終検査は `site-verified`、`products-verified`、`interiors-verified` + `customer-body-verified`、`NPC-final`、`commons-verified`、`variants-final`。構造変更後の移動証拠は `movement`、`rounded-transfers`、`guards`、`C-galleries`、`elevators`、`floors-verified`（旧診断は `floors` + `CRF-customer`）、`dog-final`。商品底面検査は一点支持であり接触面全体の保証ではありません。吊り衣類は別扱い。

連続ES12便・丸み付き乗換24経路・縁押し46箇所、EV21基98停車+21帰還、C回廊8接続を自動物理で検査しています。`movement`/`rounded-transfers`末尾に残る旧ドッグラン経路の失敗をESの合格へ数えないでください。ドッグランは新しい `dog-final` が最終結果です。C屋上の初回代表線は正規管理室へ入ろうとして止まり、`CRF-customer`で客用終点を修正して再検査しました。

## 未完成・未検証

- Windows GPUでの60FPS・144FPSは未確認。Linux llvmpipeの計測は原因比較用でありWindowsの性能値ではない。
- 480店舗に暫定売場を実装したが、全店の美術完成・全売場の自由歩行を保証していない。機械的に見える陳列、空白、均一な壁・照明は残る。
- 店舗境界の物理検査と、建築として自然に見えるかは別。Aの指摘座標付近を含む見え方の改善は継続評価が必要。
- B 1F〜3Fの用途所有権レビュー候補741.19㎡が残る。既存の公開床/閉鎖帯の差分を自動的に新施設へ転用しない。薄い公共領域245候補は角部などの誤検出を含み、全てを欠陥と断定していない。
- C採用案・A/B新ESの支持力、基礎、避難、防火、排水の専門的安全性は未検証。RF-SUPPORT-16・BRF-GARDEN-2-BED-4は正式承認しない。
- 独立水景は設計検証シーン。高品質の最終背景・屋上支持・荷重・排水は未完成。屋上へ統合しない。
- 遠景商品LODは簡易シルエット。切替の見え方、長時間の実機性能、全方位の自由探索は追加検証が必要。
- 人間による操作検証は実施できていない。自動CharacterBody、カプセル照会、図面検査、実画面の確認を別々に記録する。
- F4/F6は過去別案と統合版の比較用。比較版ではA新ESを含む全変更が同時に有効ではない。通常起動のmain.tscnがv22統合候補。
- 既存ゲームへの統合、スキャン、AP、セーブ、人物モデル・行動の制作、外周道路・駐車場再配置は実施していない。

## 性能

`Review ZIP内 tables/performance-comparison.csv`と`performance-status.json`を参照。Linux Vulkan llvmpipeソフトウェアGPU、短い2フレーム試料の比較です。共有クラウド環境の負荷変動もあり、CPU/GPU時間は厳密な実機ベンチマークではありません。CPUレンダー時間、実描画数、ソフトウェアGPU時間等を記録します。画面を横へ動かす試験は物理歩行ではありません。ユーザーのWindowsで約30FPSとなった場面と同一GPUでの再現・60FPS達成は未確認です。
