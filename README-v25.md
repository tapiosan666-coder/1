# FIND YOURSELF v25 独立検証プロジェクト

Godot 4.6.3でこのフォルダのproject.godotを開き、初回インポートが終わってからF5。Windows EXEや追加Data ZIP、ファイル結合は不要です。.godotは初回に生成されます。

F9で検証地点を選択。先頭に今回の5店舗の入口・中央・奥が並びます。A1F-039アパレル、A1F-051大型書店、B1-046カフェ、A2F-018化粧品、A3F-012ゲームセンターです。その他の店舗はv24の状態を維持しています。

M館内マップ、F11催事切替、F12既存43NPC切替、N人物比較、P表情比較、F4/F6構造比較、従来のEV/ES/階段・扉操作を保持。画面は1920×1080、144FPS上限、VSync初期ONです。144FPS実測達成を意味しません。

新しい専用什器・商品・ブランド広告・床壁の仕上げ・吊り照明を5店舗に制作。既存設備の接近位置と192検証経路を保護しています。共用部は既存のA館案内筐体1、B館瀬戸焼ブース1、C館キッズ広場ベンチ2の仕上げのみ変更し、全館完成とはしません。

依然として一部に広く平坦な床、単調な壁や本の見え方、簡素な什器が残ります。FF16級の美術品質は未達です。自動検証と人間による操作は異なり、人間の実操作・Windows GPU性能は未検証です。旧来の設備接近未解決2件もReviewに記載しています。

本編のNPC・スキャン・AP・セーブは変更・統合していません。RF-SUPPORT-16等の未承認状態は元のデータから変更していません。構造別案の扱いはv24を継承しています。

authoring/v25_*.pyにBlender制作元、source/v25に配置と検証用データ、assets/v25に新素材を収録。既存素材のライセンスはlicensesとTHIRD_PARTY_NOTICESを参照してください。sourceのFYJZ .json.zstはGodot内の読込処理で直接展開され、手作業の解凍は不要です。

初回インポートの互換対策として、旧資料CSV5件のインポート種別を翻訳から保持に変更しています。CSV本文と建築データはそのままです。
