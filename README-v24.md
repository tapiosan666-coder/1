# FIND YOURSELF v24 — 店舗仕上げ・設備検証

独立した建築・内装検証プロジェクトです。FIND YOURSELF本編のNPC大量処理・スキャン・AP・セーブは読み込みません。

1. ZIPを新しいフォルダへすべて展開します。追加Data ZIPや結合操作は不要です。
2. Godot 4.6.3でこのフォルダの `project.godot` を開きます。
3. 初回のGLB/画像インポートが終わったらF5を押します。初回の読み込みには時間がかかります。
4. F9の先頭に重点30店舗の入口・中央・奥の確認地点があります。自由歩行と組み合わせて確認してください。

WASD：移動、マウス：視点、Shift：速歩、F：既存扉・EV、Esc：カーソル、M：館内マップ、F9：確認地点、F10：画面設定、F11：催事、F12：試験NPC ON/OFF。N/Pの人物比較・表情操作も維持。人物モデル・アニメーションの追加改修は行っていません。

標準1920×1080／FPS上限144／VSync ON／物理60Hz。144FPSは設定値であり実測保証ではありません。Windows GPUの性能・人間による操作検証は未実施です。

## 今回の範囲

v23単一ZIPを展開したコピーが唯一の基準。元の15層・480店舗ID・ブランド・原業種・売場区画・建築パック・43人NPCを維持しています。

30店舗に床・実壁面上の仕上げ・広告・支持を確認した照明の候補を適用しました。業種別の商品コレクション、書棚、宝飾展示、受取/作業設備などを更新。専用のコーヒーカウンターは4店舗に適用しています。

**30店舗すべてを最高品質に完成させた版ではありません。** 装飾の密度・商品の造形・売場の自然さ・照明・鏡表現には残作業があります。FF16級への到達は主張しません。レビュー画像と残課題を確認してください。

未承認の構造案はv23から状態を変更していません。v22のABC統合候補、F4/F6の比較、水上庭園・RF-SUPPORT-16等の承認判断も変更していません。

## 設備データ

`source/v24/retail-plan.json.zst` が店舗・什器・商品の座標の唯一の正本です。FYJZヘッダー付きZstandardをゲーム内で展開します。大容量の未圧縮JSONを別途用意する必要はありません。

`shopping-index.json` はID参照中心の読み取り用索引、`shopping-physics.json` は実際の検証結果、`shopping-body-routes.json` は自動歩行経路です。`shopping_catalog_v24.gd` は読み取り専用APIで、座標の二重管理や購入処理は実装していません。旧API名も互換入口として残しています。

接近位置の立ち検査は半径0.34m・高さ1.8m、経路と自動歩行は既存プレイヤーの衝突・移動処理です。検証済みの経路がない設備は利用人数0とし、使える設備と誤認させません。全売場の自由な歩行、全角度の接触、人物アニメーションの手足まで保証する検査ではありません。

## 素材・再生成

`assets/v24/` と `authoring/v24_*.py` に今回のオリジナルモデル・図案・制作スクリプトがあります。書籍32点は8ジャンル×4タイトルの表紙/背表紙バリエーションで、32種類すべてが異なる形状という意味ではありません。PBR木材は既存CC0素材、文字は既存Noto/OFLを使用。新しい外部有料アセットは取得していません。追加素材の出典は `licenses/V24-ASSETS.md`。

制作スクリプトは工程別です。`v24_retail.py` はv23正本から初期案を再生成するため、最終の設備移動・カフェ差替え・台上衣類補正を上書きします。完成状態での実行は不要です。最終差分は `source/v24/*changes*.json`、`local-equipment-adjustments*.json`、`folded-merchandise-corrections.json` に保存しています。

実行環境によっては自動テスト終了時にGodotのPagedAllocator解放警告が出ます。テスト結果の合否とは区別し、Reviewに記載しています。
