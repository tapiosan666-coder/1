# 描画負荷の参考観測

Linux llvmpipe (LLVM19.1.7,256bits)、Vulkan Forward+、1920×1080、144FPS設定上限、VSync。各条件2フレームの準備後3フレームだけを採取。同じカメラで人物なし／43人の実物理動作を比較。43人はシーン全体の人数であり、全員が画角内に描画されている意味ではありません。

書店の人物なしでは中央値ドローコール1771→1785、描画プリミティブ約228万→275万。今回の書籍陳列で形状負荷は増えています。NPCありの場合の差もCSVに記録。ソフトウェア描画の時間は1フレーム数秒で、144FPSには達していません。これはWindows/RTX4060等の実ゲーム性能を示しません。

キャッシュ順序・初期フレーム・CPU負荷と初回キャッシュ等の影響を含む非常に短い観測です。FPS改善や滑らかな体感を証明するベンチマークとして扱わないでください。静的／ビデオメモリは旧新モデルのキャッシュを含むプロセス全体で、店内だけの増分ではありません。NPCのシミュレーション進行秒数も生データに含み、描画FPSと物理ステップを混同しないようにしています。

今後はWindows GPUで長時間測定し、書籍の中距離LOD、商品束の統合、衝突メッシュの単純化を評価する必要があります。
