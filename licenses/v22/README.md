# v22 素材の出典

v22で追加したモデル・広告は、収録Blender/Pythonスクリプトで作成したオリジナルです。実在ブランド・商業作品の固有資産は使用していません。外部の新規3Dモデルをダウンロードしたとは報告しません。

木材・舗装等の既存PBR素材、字体、Godot、MakeHuman由来人物等は元のライセンスと出典を保持しています。`licenses/vendor`、`licenses/v10`、`licenses/v20`、`licenses/v21`および各台帳を参照してください。人物アセットは改変していません。新規原形状と第三者由来のテクスチャの条件を混同しないでください。

この台帳は出典記録であり、既存第三者素材の権利を新たに付与するものではありません。
