# B館1F TERRUNE TOKYO 第2出入口検討案

対象は生活雑貨店 B1-032。館の地下階はB1だが、この店舗IDの階は **1F**、床高さは0 m。通常版の入口は尖った区画端 (186.043, −45.495) にある。v32の未承認案の壁中心は (178.996, −39.181)。座標はGodotのX・Z、単位はm。

## 別案を歩く

Godotエディターでプロジェクト直下の `TERRUNE_additional_entry_proposal.tscn` を開き、F6でこのシーンを実行すると、追加開口の前に立つ。通常起動は `main.tscn`。

- 共用床から売場へ2.40 mの有効幅、2.63 mの有効高を確保。ガラス下端・ガラスの厚み・縦方立・対応する衝突面を同じ境界で切り、左右・上端を金属枠で納めた。上部の既存水平材と床は継続する。
- 売場側0.2～1.0 mの帯を占めていた壁面陳列2台（B1-032-V31-006、007）を別案で取り下げ、中央売場・レジへの入口前を空ける。通常版には元の陳列がある。既存正面入口、会計位置、バックヤード入口、建物の外郭は従来の設計。
- 外側床は平坦。通常版では候補中心とその左右の胴体高さに実際のガラス衝突がある。別案の確認では中央から売場主通路、逆方向、左右端からの進入、従来入口から店舗奥への5経路をGodotのプレイヤーカプセルで通過。開口と床、両脇のガラスを23本の物理レイで検査。人間による操作と混雑時の体験は未検証。
- 案内図・NPC経路・店舗の代表入口座標は現行の正規入口を指す。承認後に補助入口を経路データへ加える段階が残る。通常営業用の自動扉を備える案ではなく、既存の商業区画の間口を開放する案。

## 再検査

プロジェクトルートから実行する。Godot 4.6.3を使用する。

```sh
godot --headless --fixed-fps 60 --path . --script res://authoring/v36/entry_study/verify_entry.gd -- --out=/tmp/terrune-study
```

通常側の確認は同じコマンドに `--normal` を追加する。描画と衝突の別案リソースだけを再生成する場合は、インポート済みプロジェクトのForward+環境で `godot --path . --script res://authoring/v36/entry_study/bake_entry.gd` を実行する。
