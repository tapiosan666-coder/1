# 大型店の編集ポスター

大型食品店 VELORIA ATELIER、衣料店 LUMEVA ROOM、映画館 CERAVA GALLERY のために制作した。原画は本プロジェクトで生成した架空の人物・衣装・食品・風景で、3本の映画も架空の作品。衣料のパターン画、青果とパンの挿絵、文字組みは Python と Pillow による独自制作。写真提供元・商用作品のポスターや実在ブランドは使用していない。

再出力はこのディレクトリから `python posters.py anchor-master.png ../../../assets/v36/anchor-editions`。シートは1296×576、横に432×576の印刷面3枚。日本語にはNoto Sans CJK（SIL Open Font License）、欧文にはDejaVu Serif（DejaVu / Bitstream Veraライセンス）の字形を画像に焼き込んだ。フォントファイルは同梱していない。原画と編集用コードはGodot起動時のインポート対象外。
