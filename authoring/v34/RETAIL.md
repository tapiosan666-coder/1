# v34 重点売場・1F環境仕上げ

| 区画 | 施工内容 |
|---|---|
| A1F-001 RIVORA STUDIO | 青果の木箱、瓶詰め商品、パンを用途別に作り直した。食品売場の主通路は木の天井ルーバー、暖色の連続照明、青果／ベーカリーの吊り表示で順路を読み取りやすくした。34か所の既存什器を入れ替えた。 |
| A1F-002 SUVEL STUDIO | 同型のキッチン・書斎展示を一部入れ替え、スピーカーを比較できる台と、画面と入力機器を試せる撮影・編集展示を設けた。青灰色の天井レールと案内表示を主通路に合わせた。什器入替は2か所。 |
| B1-032 TERRUNE TOKYO | 尖った区画端の既存入口を使用する。入口で折れる実動線に細い床の帯を沿わせ、入口の外側に専用店名板を取り付け、店内に売場の吊り表示と暖色照明を追加した。陶器と布の展示台3か所を作り直した。v32の追加開口案は資料として保持する。 |
| C館1F北広場 | 店舗前の既存通路と中庭を結ぶ位置に植栽と休憩帯を設けた。制作資料は `source/v34/c` に収録。 |

親の `sales_v32.gd` を継承する `sales_v34.gd` が、`source/v34/retail-edit.json` の対象IDへ既存什器と同じ平面位置・向きで新規GLBを設置する。展開時に配置の外形を検査する。元データの床・壁・レジと既存の通行経路はそのまま使用する。新規什器の底面は既存の仕上床に合わせる。衝突に商品一個ずつのポリゴンを使用せず、什器本体の占有範囲に12三角形の衝突メッシュを用いる。

GLB再生成はプロジェクトルートで以下を実行する。

```sh
blender -b -t 2 -P authoring/v34/build_retail.py
```

撮影位置は `source/v34/art-cameras.json` に収録。新規什器・天井仕上げ・表示の制作に外部の形状やロゴは使用していない。既存リソースの出典はプロジェクトの従来記録を参照。

今回の施工は3店舗と北広場が対象。A館の深部には従来の什器があり、全139店舗・全館の美術が完成したと判断する工程ではない。B1-032の古い外向き画像は当時の記録として保持し、今回は追加開口を仮定せずに同一視点の比較と実歩行で検査する。
