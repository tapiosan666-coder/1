# FIND YOURSELF v26｜建築仕上げ・出入口の独立検証版

正式基準は v25 完全プロジェクトです。Godot 4.6.3 Standardで `project.godot` を開き、初回インポート完了後にF5を押してください。外部API、追加Data ZIP、Windows EXEは不要です。既存のスキャンゲーム本体には統合していません。

## 確認する場所

F9の先頭から、A館専門店街、B館物産展・時の広場、C館中庭、各館の二重自動ドア、C館軒下、A館天井近景を選べます。既存の5店舗を含む確認地点も残しています。WASDで移動し、出入口に近づくと外側・内側のドアがそれぞれ開きます。プレイヤーと既存NPCを検知し、しきい値内に人がいる間は開放を保持します。

## 案内と設備

入口3地点と代表広場3地点に、実データ由来のフロアガイドを配置します。1Fの実店舗・共用部・設備位置、各階の実在店舗IDと業種、現在地を示します。全店の詳細は既存のMキーの館内図で確認できます。

天吊り案内板は既存ナビ経路から表示内容を引き継ぎ、実天井の支持を確認して制作しています。新設設備による経路干渉は、現時点の衝突形状で再探索して矢印と距離を更新します。C館の2経路はこの再探索対象です。

天井の煙感知器・スプリンクラー、壁付けの消火栓箱・発信機・消火器、入口誘導灯・センサー・傘袋台、出入口周辺の避難方向図を追加しています。避難方向図の赤線はその出入口から屋外までの局所経路です。全館の避難計画や法令適合を保証する図面ではありません。

## できていないこと・制約

- 代表3エリアを起点に、支持を確認した主要通路の一部へ展開しています。全15層のすべての天井・柱・壁・消防設備が同じ密度で完成したものではありません。
- 共用部の既存休憩席・植栽・案内所・物産展等を維持しています。フードコート全域や全出入口の再制作はしていません。
- v25から残る接近不良2件（`V22D-A1F-001-department_island-6402`、`V23-C3F-CE-1-capsule_corner-145`）は未解決です。
- 屋上支持等の未承認項目、F4/F6の構造別案、水景ランドマークの独立設計シーンの扱いは維持しています。
- LinuxのllvmpipeソフトウェアOpenGLで検証しています。Windows実機・実GPU性能・144FPS・人間の実操作は未検証です。SSIL/SSRはこの描画環境で利用できず、v25/v26とも同条件です。
- 既存の一部検査終了時にはPagedAllocatorの警告が残ります。終了時警告を修正済みとはしていません。
- 彼女AI、音声会話、購入・荷物持ち、スキャンゲーム本編、NPC増殖は実装していません。

## 開発検査

```bash
godot --headless --editor --import --quit
godot --headless --script res://qa_architecture_v26.gd
godot --headless --script res://regression_retail_v26.gd
godot --headless --script res://regression_approaches_v26.gd
godot --headless --script res://regression_variants_v26.gd
# 実際のディスプレイがある環境で、v25/v26を順番に撮影する
godot --audio-driver Dummy --script res://review_v26.gd -- --v25-baseline
godot --audio-driver Dummy --script res://review_v26.gd
```

検証用スクリプトの結果は `evidence/` 配下に出力します。必要なら `--qa-output=...` または `--review-output=...` で変更できます。描画測定時は並行して別の描画プロセスを実行しないでください。

Review ZIPの `index.html` はオフラインで開けます。加工していないGodot実画面、同一視点の比較、開閉連番、検査結果、性能の生サンプル、未完成事項を収録しています。

ドアの開閉連番だけはNPCを非表示にし、プレイヤー座標の入力を制御して空の扉を検証しています。43人を表示する通常の比較画面・性能測定とは別条件です。実NPCによるドア開放は自動テストで別に検証しています。
