# FIND YOURSELF v30 制作途中版

**v30完成版ではありません。G1・G2・G4に大きな未完項目があります。ゲーム本体には統合していません。**

## 今回の実装
- F1/F2/F3でA/B/C館。Mでマップ、Fで扉/EV、Escで設定。通常の比較キーを停止し、8比較シーンをReviewへ退避。共有モデル/15層/480ID/43NPCは保持。
- 全階の共通案内を横並びに変更。48面・165案内先の経路検査、全ロード済みLabel3Dの距離表示0。支持場所がトイレ内になるC屋上の1面は設置しない。
- 31MBの一括ナビを37タイルへ分割し、必要なタイルだけ読み込む。**これだけでFPS改善済みとはしない。**
- C館の箱状風除室を生成元で除去。消防設備は実壁・接近経路を確認して設置する処理へ切り替え。
- 旧B西ESの撤去後も残っていたシャフト開口を復旧。上下機械の間のサービス溝も含む上下1組の正規開口範囲から、1F94.72㎡・2F189.44㎡・3F94.72㎡を元の床高さで一体再メッシュ化。下面と衝突面も生成し、旧縁の金属面1384三角形を除去。新しい板の上貼りではない。現用ESや本来の吹き抜けの縁は今回の対象外。

## 検証の限界
275経路はカプセル掃引/床支持検査。別の8件はCharacterBody3Dのmove_and_slideを使った自動往復歩行。人間の実操作ではない。
Godot4.6.3、1920×1080、Forward+の実Viewport画像を収録。ユーザー画像の位置から撮影角度を推定し、その**同一の推定視点**をv29.4/v30で使用。元画像と完全に同じ向きだとは主張しない。

ソフトウェアGPU llvmpipeで、全層ビルダー完了までv29.4約130.2秒/v30約126.8秒を各1回測定。描画ループを撮影前まで抑制した検証用起動で、通常操作時のコールド起動3回ではない。差は有意な改善判定に使えない。Windows GPUのFPSは未計測。144は設定上限。

## 起動
Godot ZIPを新しいフォルダへ全展開し、Godot4.6.3でproject.godotを開いてF5。初回は素材インポートが必要。EXE・分割ZIP・追加データZIPは不要。
開発者検証は --developer 指定時だけF8/F9/F10/F11/F12/N/Pを利用可能。F4/F6/F7の旧構造比較は通常プロジェクトに含めない。

外部アセットの新規取得なし。元プロジェクトの素材・ライセンスを継承。追加の看板レイアウト・床再生成コードは独自制作。ゲームロジック追加なし。
