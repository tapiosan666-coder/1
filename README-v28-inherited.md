# FIND YOURSELF v28 — 建築・地形・設備整合 独立検証

公開済みv27（`cb467d661211a1bb0dd0fdc23f8ee3182b6839b0`）が基準です。既存ゲーム本体・正式な建築原本に統合していません。Godot **4.6.3**でZIPをすべて新しいフォルダに展開し、`project.godot`を開き、初回インポート後にF5で実行してください。Windows EXEは含みません。

通常起動ではB館西の新連続ESが見える位置から開始します。上り・下り6基（1F～RF）と中央・東の独立8基を維持し、旧西4基の退役を保持しています。新西ESは上り下りを幅4.07mの閉じた一体外装で覆い、中央の黒い開放スリットを除去しました。

**実行画面のF6**は旧B配置との比較へ切り替えます。旧西4基と独立8基が表示され、新連続ES6基は比較中のみ非表示です。RFへは既存EV・階段を使います。もう一度F6で通常版へ戻ります。比較シーンは旧全館構造を使用し、A/Cも比較用構造です。F4のC構造比較も維持しています。いずれも正式構造の採用ではありません。

Cドッグランの中心(-77,-245)と基本配置は維持しています。L-3の旧地表・旧衝突を切除し、0.5m格子の地形と同じメッシュから衝突を生成しました。草地・柵・二重門・舗装を同じ高さへ合わせ、矩形の別板と縁石を廃止。二重門はFで開閉し、一方の開放中はもう一方を開けられません。

B館は実外壁、C館は共用ギャラリー外周へ二重自動ドアを接続しています。C館の内扉の先は既存コアを貫通せず、横へ曲がって共用廊下へ入ります。床の見た目と摩耗層の衝突面を一致させ、上部パネルは実庇の下面へ接続。入口を隠していたB館広告は縦横比を保って縮小し、開口の両側へ移しました。

吊り看板は大きな独立矢印・ピクトグラム・2.5m以上の通過高さへ改善。既存消防設備を入口側壁へ追従し、代表3地点に天井直付の放送グリルを設けました。480店舗ID/内装、43NPC/v20女性モデル、15層、駐車場、館間通路、キッズ・キッチンカー、M/F9/F11/F12、床模様を保持しています。買い物AI・会話・購入処理は実装していません。

F9から改修位置へ移動できます。Review ZIPの`index.html`に同一視点比較、配置台帳、地形断面、実歩行・ドア検証、性能、未解決項目を収録しています。Windows実GPU・人手による全館長時間試験・構造/防災の法規認証は未実施です。既知の店舗内設備立位2件と旧構造比較版の案内4経路抑制は残しています。正常系の自動検証を全操作・全経路の保証とは扱っていません。

# FIND YOURSELF v27 — ES外装・芝生ドッグラン 独立検証

通常起動はA/B/C統合構造候補。F6はB西ES単独の構造別案、F4はC単独の構造別案へ切り替えます。もう一度同じキーで通常候補へ戻ります。いずれも正式建築採用ではありません。

- 15層、480店舗、43NPC、店舗内装、既存EV、v26二重自動ドア・館内案内・防災設備を維持。新しい買い物AIは含みません。
